# 工具与模型适配

本目录记录某个工具、模型、版本如何接收本项目的创作材料。当前没有已核验的模型能力表，不能据此声称某平台支持特定功能或价格。

为实际采用的工具复制[模型适配记录模板](模型适配记录模板.md)，填写官方来源、访问入口、版本和核验日期。输入图片数量、时长、分辨率、运镜控制、音频、种子、负面提示词和导出能力等，未知时明确标“待核验”。

先确认作品需要什么，再选择工具。官方文档说明、账号界面观察、本地检查、实际生成测试分别记录；文档提到功能不等于当前账号已经可用，写出提示词也不等于平台效果已经验证。

实际发送前检查记录是否仍适用。遇到模型或入口变化时重新核验受影响的字段，不依靠旧记录推断最新能力。API 密钥、验证码和账号凭据不写入此目录。
