# AIGC 创作助手使用说明

建立日期：2026-09-30。Skill 名称 `aigc-creator`，显示名“AIGC 创作助手”。当前是平台通用版。

## 下载和安装

仓库里的 [skills/aigc-creator](../skills/aigc-creator/SKILL.md) 包含完整 Skill：主入口、调用配置和 4 份参考文档。提示词库及作品模板在仓库其他目录；完整工作流需要同时保留本仓库，单独安装 Skill 不会下载这些资料。

Windows / PowerShell 首次安装：

```powershell
# 先进入你希望存放项目的目录；已有仓库就跳过 clone，进入现有 AIGC_Lab 根目录
git clone https://github.com/nanjiang976-ui/AIGC_Lab.git
Set-Location -LiteralPath '.\AIGC_Lab'

# 尊重已设置的 CODEX_HOME；默认安装到当前用户的 .codex\skills
$aigcSkillBase = if ([string]::IsNullOrWhiteSpace($env:CODEX_HOME)) {
    Join-Path $env:USERPROFILE '.codex\skills'
} else {
    Join-Path $env:CODEX_HOME 'skills'
}
$aigcSkillTarget = Join-Path $aigcSkillBase 'aigc-creator'
if (Test-Path -LiteralPath $aigcSkillTarget) {
    throw '同名 Skill 已存在，请按下方更新说明比较版本，不要覆盖本地修改。'
}
New-Item -ItemType Directory -Path $aigcSkillBase -Force | Out-Null
Copy-Item -LiteralPath '.\skills\aigc-creator' -Destination $aigcSkillTarget -Recurse
```

本次已为原工作电脑安装过，无需重复执行首次安装。在 Codex 中打开克隆后的 AIGC_Lab 项目；如果新 Skill 尚未出现在技能列表，重启 Codex 后再检查。输入 `$aigc-creator` 明确指定，或直接描述图片/视频创作需求。

首次安装检查：目标目录应有 `SKILL.md`、`agents/openai.yaml` 和 `references` 下的 4 个 Markdown 文件。直接打开仓库的 `skills/` 目录不等于已经安装；不要同时复制到多个自动发现目录，以免出现同名重复条目。

## 从一句想法开始

例如直接说：

> 我想做一部关于一只猫守着旧书店的短片，想要温暖但有一点孤独，你先通过提问帮我把故事丰富起来。

Skill 会读取已有项目资料，每轮默认只问一个关键问题；回答后更新梗概、画面或设定，再推进下一步。信息已经足够，或你说“先给一版”“其他你决定”时，会收束提问并开始生成材料。单图走更短流程，不强加完整剧情。

希望明确指定时可说：

> 请使用 $aigc-creator。我要做【图片/视频/漫剧】，大体想法是【内容】。先每次问我一个问题，逐步扩展，最后给我可发送提示词。

这个 Skill 已配置 `allow_implicit_invocation: true`，描述覆盖 AIGC、图片结构、故事扩展、分镜、角色一致性和提示词入库。隐式匹配取决于请求与描述，不保证任何一句话都触发；显式指定可消除本轮选择歧义。新 Skill 尚未出现在当前会话已加载清单时，重启 Codex，再在新聊天确认可以选到。调用机制依据 [OpenAI 官方 Skills 说明](https://learn.chatgpt.com/docs/build-skills)，2026-09-30 查阅；尚未在用户重启后的真实会话中验收自动触发。

仓库的 `skills/aigc-creator/` 负责保存和分发源文件，用户级技能目录中的副本供 Codex 调用，两处不会自动同步。Skill 会定位你当前打开的 AIGC_Lab 仓库，不依赖原作者的电脑路径。安装过程不修改全局配置、不增加后台定时任务。

## 常见用法

| 你想做什么 | 可以直接发送 |
|---|---|
| 从模糊故事开始 | `请使用 $aigc-creator。我想做一个关于老人每天去海边等人的短片，请每次问一个问题，帮我完善。` |
| 单张图片 | `请使用 $aigc-creator。我想做一张雨夜旧书店的插画，温暖又有一点孤独，先帮我确定构图，再给图片提示词。` |
| 信息完整，直接产出 | `请使用 $aigc-creator。做一条15秒、三镜头各5秒的视频：白猫走到桌前、抬头看灯、原地趴下。写实温暖风格，16:9，无对白。不要再问，先给通用版提示词，只交付文字。` |
| 继续既有作品 | `继续 WORK-001，从需求卡的下轮起点和连续性台账恢复，先检查待解决问题。` |
| 只修改部分镜头 | `把这部作品第3镜头的围巾改为蓝色，保留旧版，指出受影响的后续镜头和参考图。` |
| 保存作品但不进公共库 | `这次不入库，作品资料照常保存。` |
| 只讨论，不写文件 | `只在聊天里草拟，不保存文件、不入库。` |

未明确请求实际生成时只准备提示词；有生成请求时再核验平台能力与已有授权。自动调用不等于自动生成媒体、自动花费或自动发布。

## 一次创作会留下什么

| 内容 | 保存位置 |
|---|---|
| 用户明确内容、草案选择、下轮起点 | 作品 00_创作需求.md |
| 故事、角色、服装、场景和道具 | 作品 01_故事与角色设定.md |
| 剧情与对白 | 作品 02_剧情脚本.md |
| 镜头内容、时长与实例化提示词 | 作品 03_分镜表.csv |
| 本轮可复制的图片/视频提示词 | 作品 04_生成提示词/本次发送.md |
| 内部参考映射、参数、模块 ID 与审查 | 作品 06_修改与验收.md |
| 系列或视频连续性 | 作品 07_连续性台账.md |
| 分段时长、剪辑衔接与实际生成记录索引 | 作品 08_分段与衔接.md |
| 跨作品通用模块 | [提示词库](../02_提示词库/README.md) |

仍在讨论的内容与可发送正文分开。没有参考图片也能先准备角色母版和关键帧生成提示词；实际图片路径只有拿到文件后才填写。没有明确调用生成工具的要求时，只交付文字材料。

## 视频一致性怎么处理

先固定人物、衣装、场景布局和道具，再规划各段起止状态。每次生成后比较实际终帧与计划，确认后段从哪里接；始终对照原始母版，避免只传尾帧导致错误累积。修改母版或上游镜头后，重查依赖它的下游镜头。

片段按剧情与可剪辑切点拆分，不默认等于平台最长时长。工具支持参考图、首帧或首尾帧时再采用对应方式；平台未定就先写通用规划。不能从“同一个人物”这句话推导画面已经一致。

连续性包括外观、服装、持物手、空间方向、动作阶段、光色和声音。成片时长另扣实际转场重叠，例如三段各保留 5 秒，两处各重叠 0.5 秒，实际为 14 秒。模板提供更完整的时间轴填写例子。

这些是降低漂移和返工的工作方法；具体模型是否保持一致，必须在实际生成后逐段检查。当前尚未生成真实作品验证效果。

## 自动积累与可控制范围

每次创作先检索库，之后抽取新的通用表达，查重、归类并写来源/版本/状态。不收完整私人故事，不因只换角色名就新增；没有新价值时零新增。首批和未生成测试的新模块均写“未实测”。

你可以随时说“这次不入库”“只在聊天里讨论”“继续上次作品”“只改第 3 个镜头”或“停止提问，先给一版”。最新明确要求覆盖默认流程。

验证分为 Skill 结构、项目文本契约、离线行为演练和真实媒体效果；前三项即使通过，也不代表已出图、出视频或得到用户审美认可。

## 更新和维护

1. 在仓库根目录先运行 `git status --short`，处理或保存已有工作，再用 `git pull --ff-only` 更新；拉取有冲突时停下处理，不强制重置。
2. 比较仓库 `skills/aigc-creator/` 和已经安装的同名目录。若安装副本有自己的改动，先逐文件备份到技能发现目录之外的位置，再合并差异，不覆盖丢失。
3. 只同步已确认变更的文件到安装副本；保留未处理的自定义内容，不批量删除目录。之后检查 6 个文件、引用及技能列表，未刷新时重启 Codex。
4. 维护者应以仓库副本为版本管理入口；如在安装副本中改进，先回同步到仓库再提交。推送仓库不会自动更新其他电脑已安装的副本。

项目结构检查：在仓库根运行 `python -X utf8 scripts/validate_project.py`。安装环境若带有 skill-creator 的 quick_validate.py，可用它检查 `skills/aigc-creator`；不要求为了安装这个纯指令 Skill 配置生成平台 API、密钥或下载模型。
