填写约定：

- ID 使用 EXP-001 起；版本从 v001 起，沿用 ID 的方法实质变化时递增为 v002、v003 等，并保留旧版来源。
- 状态仅用“候选 / 已在指定范围验证 / 待复验 / 停用”；验证范围明确文本/流程、媒体或用户确认的偏好，不用笼统 PASS。
- 适用条件写必要输入与关键限制；来源链接指向仓库内真实记录的具体章节，详细记录内保留方法、反例与历史。
- 尚无验证证据时写明“来源已记录，效果未验证”，日期填“未验证”；不能引用空模板或模拟演练冒充实测。
- 复用去向写已有模块 ID + 版本及链接、模板或模型适配记录；尚未沉淀写“未沉淀”，无适用去向写“不适用及原因”。
- 空表即零条；添加真实条目后同步更新上方的当前登记情况，不保留失实的“没有登记”说明。
