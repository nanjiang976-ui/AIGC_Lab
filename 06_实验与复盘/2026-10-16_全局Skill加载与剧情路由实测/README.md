## 测试案例

《钥匙在谁手里》是Agent自拟的测试需求，未作为用户确认作品建档：林乔急着出门，误以为陈默藏了公用钥匙。许岚从自己右袋取出钥匙，承认忘了归位，交给林乔。林乔道歉，陈默没有马上回应。

25秒、16:9、写实、纯文生视频。采用5个镜头，是为了分别呈现质问、受伤、证据来源、所有权交接、关系余韵。没有真实图片或成片作为输入，不虚构参考文件。

| 镜头 | 目标时长 | 本镜任务 |
|---|---:|---|
| EP01_SH001 | 4秒 | A的预设质问，建立三人位置 |
| EP01_SH002 | 5秒 | B反问后抿唇垂眼，表现受委屈 |
| EP01_SH003 | 5秒 | C从右袋取出唯一钥匙组并承认疏忽 |
| EP01_SH004 | 6秒 | C递出，A接稳，C松手，A独持 |
| EP01_SH005 | 5秒 | A道歉，B沉默移开目光，C低头 |

硬切重叠0秒，目标净长4+5+5+6+5=25秒。不是平台已支持这些片长的声明，也不是实际音频或动作测时。

## 连续性与构图要点

钥匙组只有一把银钥匙、一金属环、一块无字红色长方牌，作为整体依次经过：C身体右袋 → C右手独持 → A/C两只右手短暂共持 → A握稳 → C松手退出 → A右手独持。A/C左手和B双手均不加入交接。

C身体右侧口袋与画面左右分开描述；相机保持南侧。第2镜胸上近景把低位手留在画外，第3镜拍至大腿中部看清取物，第4镜肩下至大腿中部覆盖完整手部交接，第5镜宽景保留A腰前钥匙。计划状态与未来真实生成状态分开记录。
