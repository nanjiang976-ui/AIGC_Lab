# 角色音色独立执行 · aigc-audio 1.3.0

## 原请求

我的写实小城短片有两个虚构人物，六十岁修钟师傅老周讲中文四川话、成都口音，声音偏低沉略沙哑但咬字清楚；三十岁女儿周岚讲中文普通话、标准普通话口音，声音清亮克制、语速稍快。我希望先在LibTV为每人生成专属音色，后面低声或哭泣时仍是同一个人。只给每人的完整音色设计提示词、试听文本、我要怎样在LibTV生成并选用，不要生成媒体。还没有实际音色ID和样音，模型未选。本轮不要写剧本或BGM。

## 实际完整答复

下面是两位角色各自的音色设计正文、独立试听文本和 LibTV 生成／选择说明。音色正文用于建立声音身份，试听文字用于检查正常说话、低声和含泪时能否听出同一人。试听句是临时测试内容，不是短片剧本或已确认情节。

当前为未建档短片的声音首稿，仅依据本次请求：写实小城风格、两位虚构人物及明确的年龄、语言、口音和听感要求。没有可复用的真实样音、音色 ID 或选定模型。以下是完整的通用自然语言版；LibTV 当前账号入口和模型字段尚未核验，具体平台适配、生成、试听与跨句复用均未执行。

### 老周：完整音色设计提示词

声音关联：`CHAR-001 老周 → VOICE-001 v001`。用途为角色对白及后续同角色发声；身份来源为文本设计的虚构新音色。实际样音、平台节点、音色 ID 和用户选用结果均为待生成／待选择。基础语速暂按自然、从容处理，这是可调整的设计选择。

复制以下正文到实际支持自然语言音色设计的入口：

```text
为写实小城短片中的虚构人物“老周”设计一名六十岁男性的专属说话音色。主要语言为中文四川话，采用自然、生活化的成都口音，整句按四川话的语音和语调说出。声音处于男性中低音区，音色低沉，带轻微、自然的沙哑颗粒，保持清楚的字头和完整的字尾。共鸣厚实而贴近，发声有支撑，沙哑程度以每个字仍然容易听懂为准。年龄感来自沉稳的共鸣、略粗的声带质感和自然呼吸，听感结实、平和。

基础语速自然从容，短句利落，长句在语义处自然停顿，像修钟师傅在安静的小店里对面前的人说话。成都口音落在真实的发音和日常语调上，表达朴实，语气温和而有分寸。可听辨识点是稳定的中低音底色、轻微沙哑颗粒、清晰咬字和成都话语调。

建立以平静自然说话为基准、可供后续对白重复选择的声音身份。后续低声说话时，保持原有年龄感、音色底色、口音与咬字习惯，通过减小发声力度、缩小语调起伏和贴近的气息表达；后续含泪或哭泣时，保持这些身份特征，以呼吸不稳、短暂停顿和轻微尾音颤动表达情绪。情绪变化属于同一个人的表演变化。试听以干净、清楚的单人人声呈现。
```

### 老周：独立试听文本

先以平静自然的说话状态读第一段，作为选音色的基准。其后两段分别用于低声和含泪测试。表演说明放在入口实际支持的独立控制处，不作为要朗读的台词一起粘贴。

**正常说话：**检查成都话是否自然、沙哑是否影响清晰度，以及长短句切换。

```text
你先坐一哈，莫着急。这只钟走得慢，我再给你看一看。小螺丝就在右手边那个盒子里头，你帮我拿过来嘛。钟摆稳了，声音才听得清楚。好，等它再走一圈，我们再看。
```

**低声：**轻声对近处的人说话，保持清楚咬字和原有中低音底色。

```text
你先坐一哈，莫着急。我听得到，你慢慢说。外头冷，把门关到嘛。
```

**含泪：**努力维持说话，呼吸略有断续，句末轻颤，台词仍能听清。

```text
你先坐一哈，莫着急。我本来想跟你好好说的。等一哈……让我把这口气缓过来。
```

开头同一句在三种状态中重复，便于直接比较身份是否漂移。文字中的日常词语只提供发音材料，成都口音仍须由你实际试听判断；不能凭出现“莫”“一哈”等词就认定方言已经合格。

### 老周：在 LibTV 生成并选用

1. 进入你当前账号实际提供的音频／语音相关入口，先查看模型完整名称与版本、能否用文字设计新音色、是否支持四川话及成都口音、生成结果能否保存为可复用声音。当前没有选定模型，暂不指定按钮名称、参数值或点击路径。
2. 如果入口支持文字创建音色，将“完整音色设计提示词”放入音色描述字段，将“正常说话”试听文本放入试听／合成文本字段；语言或方言选项只选择界面实际提供的匹配项。若只有一个输入框，先确认它是否支持分别表达音色描述与朗读文字；未确认时不要把两段直接混贴，以免描述本身也被朗读。
3. 先试听基准候选，优先选中“成都话自然、低沉略沙哑、字清楚”的版本，再用这个实际选项测试低声和含泪文本。情绪控制只用当前模型实际支持的表演字段或语法；没有相应控制时，表演测试记为待核验，不虚构情绪开关。
4. 选定后，建议将样音命名为“老周_四川话成都口音_基准_v001”，这是建议的保存名，不是已存在的音频。记录实际完整样音名、模型／版本、平台真实节点，以及入口确实提供时的音色 ID。下一句先选择同一实际声音，再更换台词及表演；不要每句重新凭同一段描述创建新音色。
5. 若当前入口只有预设音色，就先从实际预设里试听最接近的候选，记录为“预设候选”，不要称作已经生成了专属音色。若只有参考音频复用入口，本轮尚无样音可绑定；待取得并选定真实样音后，再核验这个模型接受何种参考与怎样绑定。若不支持成都话或固定声音复用，该入口还不能满足完整目标，应选择另一个实际支持的入口后再生成。

### 周岚：完整音色设计提示词

声音关联：`CHAR-002 周岚 → VOICE-002 v001`。用途为角色对白及后续同角色发声；身份来源为文本设计的虚构新音色。实际样音、平台节点、音色 ID 和用户选用结果均为待生成／待选择。中音偏明亮、轻微自然气息是依据“清亮克制”补充的首稿设计，可在试听后调整。

```text
为写实小城短片中的虚构人物“周岚”设计一名三十岁女性的专属说话音色。主要语言为中文普通话，采用标准普通话口音，整句使用普通话。声音清亮、自然，处于女性中音偏明亮的音区，音色有清晰的明亮核心和适度厚度。发音位置集中，字头清楚，句尾收束干净，气息轻而稳定，整体听感成熟、贴近生活。

基础语速稍快，连续表达流畅，仍保留词句边界和必要的换气。情感表达克制，重音集中在真正要传达的信息上，语调起伏适度，像对面交谈时认真说明一件事。声音的可听辨识点是清亮的中音底色、清楚利落的咬字、稍快但从容可懂的节奏，以及收得住的句尾。

建立以平静自然说话为基准、可供后续对白重复选择的声音身份。后续低声说话时，保持原有年龄感、音色底色、标准普通话口音和咬字习惯，通过降低发声力度、减小语调起伏和增加贴近的气息表达，仍保留可辨认的明亮核心；后续含泪或哭泣时，保持这些身份特征，以吸气、短暂停顿、轻微声音颤动和偶尔的呼吸断续表达情绪。情绪需要时允许局部放慢，基础音色和人物身份持续一致。试听以干净、清楚的单人人声呈现。
```

### 周岚：独立试听文本

以下三段分别用于正常、低声和含泪状态，表演说明与朗读文字分开放。

**正常说话：**语速稍快，信息清楚；检查数字、长句、转折和句尾是否自然。

```text
爸，你先听我说完。我把车票和钥匙都放在桌上了，明天上午九点出发。时间还来得及，我们一件一件处理。你是不是把眼镜放进抽屉了？好，我看见了，就在那本蓝色的笔记本旁边。
```

**低声：**力度变小，贴近说话，保留明亮核心和清楚的普通话发音。

```text
爸，你先听我说完。我就在这里，你慢慢说。这件事，我们可以一起想办法。
```

**含泪：**努力控制情绪，吸气后继续说，允许停顿和局部放慢。

```text
爸，你先听我说完。我刚才……只是太着急了。你等我一下，我能把这句话说清楚。
```

三段重复同一句开头，用于比较音色；哭泣时的语速不必机械保持稍快，但听感年龄、明亮底色和咬字习惯应仍能让你认出周岚。

### 周岚：在 LibTV 生成并选用

1. 查看当前语音入口是否支持文字设计新音色、标准普通话及保存复用，并记录实际模型完整名称与版本。不要因为同一画布里存在老周的音频，就假定周岚会自动形成另一个稳定声音。
2. 有独立音色描述与试听文字字段时，分别粘贴周岚的设计正文与“正常说话”文本；语言选择界面实际支持的中文普通话项。没有独立字段时，按该入口官方支持的输入方式适配，不把音色设计误作台词。
3. 先选出“三十岁听感、清亮克制、稍快但字清楚”的基准候选，再固定这个实际声音测试低声与含泪文本。用实际支持的表演控制改变力度、呼吸和停顿；如果基准已经合适但情绪样本明显换了人，先保留基准，调整受影响的表演或换用支持该声音复用的入口，不重新定义角色身份。
4. 建议保存名为“周岚_标准普通话_基准_v001”。选定后记录实际完整样音名、真实节点、模型／版本，以及入口确实提供时的音色 ID。后续对白始终先选这个实际声音，再输入当句台词和当句情绪。
5. 只有预设时，先试听并登记“预设候选”；只有参考音频路线时，先取得真实选定样音，再核验参考输入及复用方式。若当前模型只能每次独立生成声音，重复相同设计文字不足以证明身份稳定，需要换到实际支持声音复用的入口才能继续验证完整目标。

### 怎样确认两个人物可以继续复用

在 LibTV 内为每个人连续试听“正常 → 低声 → 含泪 → 正常”，重点比较年龄感、口音、音色底色和咬字习惯。最后回到正常状态，可帮助判断变化来自一时表演还是声音身份已经漂移。选音色时也确认两人容易区分：老周的成都话、低沉略沙哑，与周岚的标准普通话、清亮利落，分别成立。

你选中样音后，只需保留实际样音全名和真实节点／音色 ID（平台提供哪个就记哪个），以及哪些情绪已经试听满意。没有音色 ID 也可先记录选定样音；这仍不代表后续任意模型都能引用它。用于后续视频前，另行确认该视频入口是否接受这一声音 ID 或真实音频参考；若只能独立配音，则按实际能力处理对白和口型。一条画布连线不自动证明声音身份会传递。
