一次先验证一个明确问题，例如“减少同一镜头动作数量后是否更连贯”。尽量固定其他输入，保留原始发送文本、参数、参考图和实际输出，避免只保存挑出的最好结果。

区分未执行、执行失败、结果不符合预期与结果满足条件。没有生成时可记录文本检查，但不能把它写成平台生成实测通过。

复盘结论分为本次观察、可能原因、适用范围和下一次验证。可复用提示词结构可以按 [入库规范](../02_提示词库/入库规范.md) 以“未实测”状态进入公共库；只有真实证据支持的结论才能标记为“实测可用”。项目管理规则的改变记入[决策记录](../spec/decisions.md)，不混入具体作品的发送正文。
