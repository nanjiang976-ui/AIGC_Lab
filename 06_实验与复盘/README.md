- [2026-10-16 全链路Skill训练](2026-10-16_Skill链训练/README.md)：原始行为基线、独立实际执行、问题与修订、工具验证；媒体生成另行记录。

用[实验记录模板](实验记录模板.md)记录提示词或工作流改进。建议命名为 `日期_实验主题.md`，关联作品、版本和镜头编号。

创作前先查[经验索引](经验索引.md)，只读取与本轮问题相关的条目；结束后将使用效果与下一步写入作品修改记录，有新结论或反例才更新索引。完整方法、状态和回写顺序见[持续迭代规则](../spec/持续迭代.md)。索引允许为空，旧试用记录不会自动变成已验证经验。

实际使用见[持续迭代使用指南](持续迭代使用指南.md)及[《先做一小步》两轮闭环记录](2026-10-16_WORK-003_持续迭代闭环.md)：v001 空索引开工、独立复盘登记候选、v002 先读回再试用及限定文字范围的验证。媒体未生成，观众效果未验证。

已有记录：[2026-09-30 AIGC 创作 Skill 本地验收](2026-09-30_AIGC创作Skill验收.md)，包含 60 条模块检查、独立文字演练和未实测边界。

一次先验证一个明确问题，例如“减少同一镜头动作数量后是否更连贯”。尽量固定其他输入，保留原始发送文本、参数、参考图和实际输出，避免只保存挑出的最好结果。

区分未执行、执行失败、结果不符合预期与结果满足条件。没有生成时可记录文本检查，但不能把它写成平台生成实测通过。

复盘结论分为本次观察、可能原因、适用范围和下一次验证。可复用提示词结构可以按 [入库规范](../02_提示词库/入库规范.md) 以“未实测”状态进入公共库；只有真实证据支持的结论才能标记为“实测可用”。项目管理规则的改变记入[决策记录](../spec/decisions.md)，不混入具体作品的发送正文。
