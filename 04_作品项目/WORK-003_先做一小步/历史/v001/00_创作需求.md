# 《先做一小步》创作需求 · v001

## 用户已确认与本轮边界

来源：2026-10-16 本聊天，用户选择“新建20秒AI主题短片《先做一小步》，用于你的AI内容账号”。用户要求用真实创作跑通持续迭代，先检索经验、创作后复盘回写，再由下一轮复用；本轮只准备文字和提示词，不调用媒体生成。

| 项目 | 本作品要求 |
|---|---|
| 一句话想法 | 一位总在收藏教程的虚构创作者，终于让 AI 帮自己起一个头，再亲手改掉三个字，完成今天的一项小任务 |
| 观众与用途 | AI 内容账号短片；面向想试 AI、常把准备当开始的普通人，留下“先做出一点，再继续”的行动感 |
| 形式与交付范围 | video / prompts；5 个设计镜头，完整参考资产图片正文、逐镜首帧和动态草案、声音与后期计划 |
| 规格 | 成片计划 20 秒；9:16 竖屏；中文画外音，中文字幕与屏幕文字后期合成 |
| 基调与风格 | 写实生活感、低饱和蓝与米白、白天柔光；表演克制，不使用技术奇观表现 AI |
| 已有素材 | 无实际参考图、视频、音轨或品牌界面；参考资产与首帧均为文字候选 |
| 固定要求 | 只做文字；保持标题与 20 秒目标；AI 贡献与人的选择有因果；不作收益、速度或能力保证；不把剧情当用户真实经历 |
| 可用工具与资源 | 本轮交付通用自然语言提示词，无指定生成工具；不安装模型、不联网生成、不合成声音；成本为零次生成调用 |
| 制作输入路线 | 尚未选定平台与入口；保留参考资产 → 首帧 → 视频的制作设计，不把 prompts 范围推断为已选择纯文生 |

## 决策状态

| 状态 | 内容与来源 |
|---|---|
| 用户已确认 | 题目、AI 账号用途、20 秒、真实创作闭环、prompts 范围、禁止媒体生成 |
| Agent 工作假设 | 单人虚构剧情；角色小岚；9:16 写实；“收藏→问 AI→选开头→改三个字→勾选完成”的情节；全部外观、具体文案、旁白和画风。用于可修订第一稿，不等于用户审美确认 |
| 执行前仍需落实 | 实际图片/视频平台与入口；画幅/时长支持；真实角色母版和首帧；屏幕跟踪合成质量；旁白实读、声音素材授权。它们不阻碍完整通用文字创作 |

## 本次完成条件

1. 交付 5 镜，计划时长 3+4+5+5+3=20 秒，全部硬切、画面重叠 0；尾标题叠加于第五镜，不再增加片长。
2. 每镜都有相机、角色/主体、画面三要素和可核对的入口、出口、切点；选择与修改来自可见 AI 候选。
3. 提供角色必要视角、场景与道具的图片正文，5 张静态首帧正文，5 段完整通用动态草案；不省略资产与首帧，不捏造图像绑定。
4. 参考文件留空；“本次发送”只放可独立复制的图片正文。实际图生视频输入未齐，视频文本留草案；标明平台适配、生成、视觉审查、播放均未执行。
5. 实际完成创作前经验检索；独立复核后保存第一轮事实与限制，保留原稿供下一轮比较，不为了演示迭代故意写差。
