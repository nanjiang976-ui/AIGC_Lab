# 提示词交付模板

作品的 `04_生成提示词/本次发送.md` 保存本次可发送的提示词，按分镜表中的镜头 ID 分段。每个镜头用标题标明编号，再用独立代码块承载正文；单图也保留镜头编号。复制到生成工具时只取对应正文，不带管理讨论。

交付前核对：

- 主体、场景、画面或动作、构图与光线已经明确。
- 角色、场景与镜头编号能够对应；同一设定没有互相冲突的描述。
- 图片提示词只描述画面；视频提示词明确时间内的变化。
- 参考图及其用途已记录；不会把参考图的全部内容默认为需求。
- 语言、比例、时长、模型参数与工具实际能力匹配；未知能力保持待核验。
- 没有未替换的占位符、备选方案或向工具提问的管理说明。

需求、设定、脚本、分镜及发送正文中的创作输入仍有“待确认”时，不能进入 `PROMPT_READY`；内部记录中明确写为未执行的生成或复盘事项，不因此被冒充为创作输入已经完备。

内部记录放在 `06_修改与验收.md`：本次镜头清单、采用的工具及模型、界面参数、参考图映射、假设、待确认项、未采用方案和修改理由。不要将这些管理讨论追加到“本次发送”。

提示词准备完成仅说明输入材料可用。未经实际生成与检查，不得把效果、角色一致性或工具能力写成“已验证”。
