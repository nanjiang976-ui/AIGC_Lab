# 生成结果与证据

当前模板未运行生成。空目录、提示词文本或执行计划不能作为生成成功的证据。

实际生成后，保存素材与必要的执行记录，文件名包含镜头编号和版本，例如 `EP01_SH001_v001.png`。若有多次尝试，再追加尝试编号，保留旧版本。

- 成功记录应能对应提示词版本、工具、模型、参数、生成时间与实际文件。
- `project.json` 中的 `generation.evidence` 使用作品目录内真实且非空文件的相对路径，例如 `05_生成结果/实际文件名.png`。不填写示例文件名或不存在的文件，不使用绝对路径、越界路径、符号链接或 Windows 重解析点。
- 工具执行完成不等于画面验收通过；人物一致性、动作、构图、文本、声音等由审查单独记录。
- 交付范围为 `prompts` 时可保持 `generation.status` 为 `NOT_RUN`；提示词审查通过不代表已经生成图片或视频。

引用参考图时，先将获准使用的素材复制到本作品新建的 `参考素材/` 中，并在分镜表与设定中登记来源。作品引用必须位于本作品目录内；不要把参考图当作本次生成结果。
