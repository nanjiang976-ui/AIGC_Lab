# 角色设定表

将每个角色登记到作品的 `01_故事与角色设定.md`。编号如 `CHAR-001`；同一角色跨镜头使用相同编号。

| 字段 | 内容 |
|---|---|
| 角色编号 / 名称 | {{编号与名称}} |
| 叙事功能与目标 | {{角色想要什么，阻碍是什么}} |
| 外观固定项 | {{年龄段、脸型、发型、身形等}} |
| 服装与配件 | {{服装编号、材质、颜色、配件及佩戴位置}} |
| 行为与语言 | {{常用动作、说话习惯、情绪表现}} |
| 可变项及触发条件 | {{例如情节允许的服装变化}} |
| 不得改变 | {{跨镜头必须保持的特征}} |
| 参考素材 | {{来源、文件路径、参考用途}} |

场景用 `SCENE-001`，重要道具用 `PROP-001`。为场景记录空间关系、时间、天气与光线；为道具记录尺寸、颜色、持有者和位置。只填写影响当前作品的字段，不为了完整而虚构设定。
