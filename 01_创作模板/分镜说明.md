# 分镜说明

每行对应一个可单独生成的镜头或一张图片。先写画面与叙事作用，再转换为图片和视频提示词。

`03_分镜表.csv` 使用 UTF-8，字段顺序固定如下：

| 字段 | 填写规则 |
|---|---|
| `shot_id` | 作品内唯一，如 `EP01_SH001`；单图也使用镜头编号 |
| `duration_seconds` | 数值；图片填 `0`，video/comic 镜头填大于 `0` 的秒数；comic 指有时间轴的漫剧，静态条漫使用 image |
| `scene_id` | 对应设定表中的场景编号 |
| `character_ids` | 角色编号以英文分号分隔；无角色留空 |
| `description` | 主体、动作或状态、景别、构图、情绪与叙事信息 |
| `dialogue` | 对白、旁白及说话者；没有则留空 |
| `image_prompt` | 描述单个静态画面；保持角色与场景设定 |
| `video_prompt` | 描述动作顺序、主体与镜头运动、起止状态；单图填“不适用” |
| `reference_files` | 作品目录内的参考文件相对路径，多个用英文分号分隔；无参考留空 |

CSV 单元格含逗号、换行或双引号时，用双引号包裹，内部双引号写两次。保持表头不变，不在 CSV 中插入说明行。

参考文件必须真实存在且非空。公共素材先复制到作品目录内并记录来源，再填写路径；不使用绝对路径、`../` 越界路径、符号链接或 Windows 重解析点。

视频镜头的时长、动作密度与对白长度应匹配；工具不支持的运镜、时长或输入方式应调整方案并记录。连续镜头检查人物位置、视线方向、服装、持物、光线与动作衔接。镜头编号应同时用于提示词和生成结果文件名。
