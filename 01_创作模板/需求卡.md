# 创作需求卡

复制作品模板后，将以下内容填写到作品的 `00_创作需求.md`。

| 项目 | 填写内容 |
|---|---|
| 一句话想法 | 谁在什么情境下，遇到什么冲突或看见什么画面 |
| 目标观众与用途 | 给谁看、希望留下什么感受、用在哪里 |
| 作品形式 | 图片（含静态条漫）/ 视频 / 有时间轴的漫剧 |
| 本次交付范围 | `prompts`：脚本与提示词；`media`：还需生成素材与画面验收 |
| 规格 | 图片数量或集数、时长、比例、语言、字幕需求 |
| 创作基调 | 情绪、节奏、画风；参考的具体属性 |
| 已有材料 | 剧情、人物、参考图、素材及来源 |
| 固定约束 | 必须保留、必须出现、不得改动的内容 |
| 资源约束 | 时间、可接受成本、可用生成工具 |
| 本次完成条件 | 可观察、可核对的交付标准 |

未知信息标“待确认”；确实不需要的项目标“不适用”；确认没有的内容标“无”。三者不能混用。先补齐会影响创作方向的信息，其余假设应明确记录。
