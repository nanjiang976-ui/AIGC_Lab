# 创作模板

先明确作品目标和交付范围，再写故事、分镜和生成提示词。模板不是已完成作品；`{{...}}` 和“待确认”需要在交付前处理。

- [需求卡](需求卡.md)：把想法变成可执行的创作任务。
- [角色设定表](角色设定表.md)：固定角色、服装和连续性约束。
- [分镜说明](分镜说明.md)：说明逐镜头 CSV 的填写方式。
- [提示词交付模板](提示词交付模板.md)：分开整理发送内容与内部记录。
- [连续性台账模板](连续性台账模板.md)：固定角色、服装、道具与场景，逐镜头记录计划/实际起止状态和变更影响。
- [分段生成与衔接模板](分段生成与衔接模板.md)：区分镜头与生成片段，核算成片时长并规划切点、参考和后期声音。
- [作品模板](作品模板/)：新作品的完整起点，复制到 `04_作品项目/WORK-001_名称/` 后填写。

初次使用先做一部小作品，公共模板只沉淀多次创作中可复用的经验。不要在模板里保存具体客户信息、真实生成结果或作品验收结论。
