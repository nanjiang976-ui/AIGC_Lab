# 完整镜头调度模板

供后台填写，不要求用户记字段。规则唯一维护于[完整调度契约](../skills/aigc-creator/references/director-dispatch.md)；用户只需提供故事/既有资料和当前目标。旧作品按需要采用，不批量补填。

## 本轮来源与目标

填写：作品/版本、已确认来源、导演目标、不可改变的台词/事件/状态、工作假设与未知、明确镜头数及理由。计划值与实测值分开。

## 空间总图

填写：地标/世界坐标、物体数量与位置、角色起点/朝向/持物、轴线、相机位置与路径、可达通道。可用文字或简图；缺项如实标明。

## 每 Shot 重复填写

| 字段 | 后台填写要求 |
|---|---|
| Shot/场景/计划时长/功能 | 固定ID、总秒数与信息变化 |
| 前景 | 对象、画面方位、距离层、虚实焦、独立声源或不适用 |
| 背景 | 对象、方位/距离层、虚实焦、独立声源或不适用 |
| 主体 | 身份、明确衣装、姿态、视线、双手/持物 |
| 相机 | 位置、高度、观察方向、角度、运动起止和速度 |
| 景别/构图/光源 | 名称+具体裁切、必见接触点、焦点、光线来源 |
| 时间片与同步事件 | 每片起止秒、触发→动作/接触→结果、原台词、声音与相机反应 |
| 入口/出口/切点 | 状态、接续对象、切换理由、音画接法 |

## 相邻镜头与编译交接

核对动作、视线、衣装、光线、持物和声音连续性；给Clip编译节点完整源Shot，不自行用生成上限改掉叙事镜头。真实图像、模型入口和前段实际结果不足时列具体依赖，不伪称就绪。
