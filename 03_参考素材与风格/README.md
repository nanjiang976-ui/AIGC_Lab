# 参考素材与风格

为素材登记来源，以及本次只参考哪些属性。优先记录构图、色彩、光线、景别、造型或动作，不用一句“照着这个做”代替创作要求。

[素材索引.csv](素材索引.csv) 使用 UTF-8，每行一份素材：

- `asset_id`：唯一编号，例如 `REF-001`。
- `title`、`type`：便于识别的名称及图片、视频、文字等类型。
- `source_url`、`local_file`：实际来源链接或本地相对路径；没有则写“无”。
- `reference_attributes`：具体参考的属性，多项可用分号分隔。
- `usage_notes`：哪些内容可采用、哪些不应带入作品。
- `rights_status`：已知的授权或来源情况；不确定写“待确认”，不作法律结论。
- `checked_at`：最近核对来源或信息的日期；未核对留空。

公共素材被作品采用时，先将已获准素材复制到该作品的 `参考素材/` 中，并在作品内部记录原始来源与引用关系。作品分镜中的参考文件必须使用作品目录内相对路径，且文件真实存在、非空；禁止绝对路径、`../` 越界路径、符号链接或 Windows 重解析点。这些是作品校验约束，公共素材索引本身可以记录外部来源网址。

原始素材、生成素材与已验收素材分别标明用途。不要把网页缩略图或参考图误记为本项目生成成果。
