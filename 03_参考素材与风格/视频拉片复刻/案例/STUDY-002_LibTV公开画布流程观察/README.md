## 直接观察

### 过门不入：共享资产向多段视频供参考

画布中可以看见人物参考图、独立霰弹枪图、多个婚礼场景视角、裁剪/标注/多角度节点与视频节点。独立道具节点的界面ID是`i-hfL2oRBgrJ`，可见多条边连向视频节点。这说明在该工程里，道具作为可重复引用的输入存在；不证明每条生成都正确还原了道具。

素材列表显示图片155、视频51、音频1；这些是当时UI分类计数，不是镜头数量。所查看的一个视频详情显示Seedance 2.5/全能参考，不能把它扩写为全片所有节点参数。

### 幕Scene：先写段落约束，再展开逐镜执行

文本节点38/51先给一组镜头的整体情绪、时间光线、运动方向、状态持续与音乐原则，再展开景别、镜头运动、人物动作和声音事件。部分文字将头部身份与衣装作为不同参考用途，并明确某次状态改变发生于何种接触动作。

可迁移的是“段落约束约束逐镜设计”的组织方法。本项目继续遵守自己的Clip衣装独立展开规则，不照搬作者的具体衣装引用写法、镜头动作、时长或风格。

### TVC教程：母图、分镜派生与视频结果分开

画布明确分为分镜组与视频组，能看到角色三视图、多机位宫格、连贯分镜宫格、扩图和相应视频。文本节点3同时交代主体身份、工作服、餐厅品牌色与摄影/色彩意图。

本轮推断：可以从统一母图和已确认空间派生分镜，以减少每张图重新设计环境的机会。该推断尚未通过本项目生成对照验证；宫格是该例工具选择，不因此成为所有项目必做步骤。

### 长安异闻录：角色声音、状态版本和补镜头都单独管理

画布有角色、角色音频、场景、道具、视频截帧与情节分组。素材列表显示7项按人物命名的音频，包含张磊、张磊原音、刘三、王大头、小翠、月媚儿、老瞎子；图片有衣装/情节状态命名，另有首帧、尾帧和补镜头。

可见音频来源节点`a-RnBbRJABVe`和`a-egAZneqYNi`向多个视频节点连接，例如都连接至`v-otuFIhAMqu`。本轮没有确认这两个节点各自对应哪一个具名声音，也没有试听，不把连线当成声纹稳定证据。

## 对本项目的缺口判断

| 需要加强的交付 | 现有节点 | 本轮处理 |
|---|---|---|
| 人物声音母版、语言/方言、试听稿、真实声音资产关联 | `aigc-audio` | 用户已批准方案A，扩展现有节点，无需新建Skill |
| 每需配乐Shot完整BGM正文、跨Shot连续使用方式 | `aigc-audio` + 完整调度/剪辑 | 用户已批准纳入本轮；不能只留“紧张音乐”一句 |
| 全片→段落→Shot/Clip的最新剧情、风格与修改传播 | 总控、handoff、各节点 | 用户已批准当前作品脉络交接方案；不假定模型能读取整张画布 |
| 道具状态派生、真实首尾帧和补镜头任务 | 视觉资产、keyframes、editing、continuity | 现有职责已覆盖；本例说明需要在实际作品中明确调用与交付，不据一次观察新增通用强制步骤 |
| 母图派生、分组与候选筛选 | 视觉资产、storyboard、画布交接 | 可作为后续具体作品的试用方法；本轮没有验证它能提升媒体质量 |

当前优先补产物和交接约束，而非增加重复入口。具体方案见[声音资产与全片脉络](../../../../spec/reviews/2026-10-20_声音资产与全片脉络方案_v001.md)。`aigc-music`继续负责音乐主导影像；一般背景配乐由`aigc-audio`承担。

## 下一次怎样学习公开画布

用户给明确公开链接，并指定想研究的重点（如角色一致性、声音、追逐调度、补镜头或风格）。先核对可访问范围，再记录“看见了什么→节点如何连接→提示词怎样表达→哪些可迁移→怎样试一小轮”。优先选一处具体方法，不把作者整套工程或风格直接变成项目默认。
