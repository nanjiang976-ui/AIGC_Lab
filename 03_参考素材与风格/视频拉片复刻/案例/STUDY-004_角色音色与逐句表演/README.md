## 方法与项目对照

00:45–01:51围绕人物背景与可听特征设计声音，再从剧本取得角色音色和试音材料。02:16–03:09使用选定视频提取的声音，或独立设计选定样音，作为后续参考。03:37–05:16把情绪意图展开成发声方式、节拍与身体状况，并演示停顿。三项对应本项目已有音色身份、样音复用和声音表演能力；本次拟完善交付组织，不称原系统缺少声音功能。

关键画面校正：六要素末项为“发声特点”，ASR误识不采用；05:07的最终文字相比04:59不仅增加停顿标记，也重复开头词，且标记数量与口播概括不同，因此不视为仅改标点的严格对照。锁定台词仍保留原字词及标点，表演说明另放。
