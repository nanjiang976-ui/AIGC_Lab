# 验收标准

版本：1.0 · 2026-09-28

PASS 只针对明确的检查范围。结构通过、提示词可发送、媒体已生成、内容审查通过必须分开表达。

## 验收矩阵

| ID | 对象 | 通过标准 | 验证方式 | 证据 |
|---|---|---|---|---|
| H-01 | 项目导航 | 根入口和六类目录均存在；本地文档链接可解析 | 默认校验命令 | 命令、退出码与日志 |
| H-02 | 作品登记 | 每部作品有唯一 WORK 编号；manifest 类型、枚举、版本有效 | 默认校验命令 | 校验结果 |
| H-03 | 安全引用 | 所有文件引用在作品内，存在且非空；无越界/链接跳转 | 默认校验 + 反例测试 | 拒绝样例结果 |
| H-04 | 提示词门槛 | 必填正文非空白；至少一条完整镜头；编号不重复；无待确认占位；发送版每镜头一个标题组、正文非空且无额外镜头 | --phase prompts | 当前版本文件与命令结果 |
| H-05 | 交付声明 | review PASS 有当前版本、真实审核人及证据；media 还须 generation PASS | --phase delivery | manifest 与真实结果/记录 |
| H-06 | 校验器有效性 | 缺文件、重复镜头、越界、假 PASS、过期版本等反例被拒绝；有效文字交付可通过 | unittest | 测试日志 |
| C-01 | 需求符合度 | 需求卡列出的每个交付项都有对应产物或明确不适用理由 | 内容审查 | 作品内验收记录逐项对应 |
| C-02 | 叙事连贯性 | 角色行为有动机；时空转换可理解；对白与分镜无矛盾；纯图片注明不适用 | 人/Agent 阅读审查 | 镜头 ID、问题与处理结论 |
| C-03 | 视觉一致性 | 核对角色脸部特征、发型、服装、关键道具、场景布局、色彩；应变与不应变分别判断 | 生成后逐镜头对照参考图 | 关键帧/媒体及检查记录 |
| C-04 | 媒体可用性 | 文件可打开；实际画幅、时长、数量符合需求；无影响使用的闪烁、变形或错误文字 | 实际播放/视觉检查 | 工具、媒体路径与实际数值 |
| C-05 | 可复现记录 | 记录实际发送输入、工具、模型、日期、设置、参考文件和结果；不把模板写成实测 | 对照生成记录 | 当前版本生成记录 |
| C-06 | 范围诚实 | 提示词交付不宣称媒体成功；Agent 复查不宣称用户认可；未发布不写已发布 | 最终报告审查 | 最终交付记录 |

## 内容审查怎样写

每次填写：检查范围、作品版本、审查人、时间、逐项结论（PASS / FAIL / NOT_RUN / 不适用及原因）、问题对应镜头、修改结果、证据位置。可以直接使用作品内 `06_修改与验收.md`。

提示词交付时 C-03/C-04 是 NOT_RUN，不能填 PASS；可以审查设定和描述的一致性，但必须明确“尚未检验实际画面”。scope=media 要求这些项目实际检查。没有真人终审时写“Agent 内容审查”，不要写“用户终审”。

## 初始化验收与作品验收分开

本次初始化可完成 H 类结构、流程与校验器检查，以及模板的内容审查；不执行真实作品 C-03/C-04。初始化日志放在 [复盘目录](../06_实验与复盘/README.md)，任务进度见 [执行计划](plans/README.md)。

## 自动化边界

校验器可判定文件是否存在、记录字段是否有效、版本是否相符，但不能证明证据真实、媒体质量合格或用户满意。填写 ACCEPTED 必须同时完成对应范围的内容检查；不得靠填入任意文件路径绕过实际审查。

## 持续迭代流程验收

从 2026-10-16 起，在后续创作任务按[持续迭代规则](持续迭代.md)执行。以下项目通过 Agent/人工内容检查，不是现有校验脚本自动强制的经验状态检查；旧作品不批量补填，不因缺少新增区块撤销其历史审查。

| ID | 检查对象 | 通过标准 | 证据位置 |
|---|---|---|---|
| I-01 | 创作前检索 | 记录检索条件、采用/试用的经验 ID + 版本与判据，或明确无匹配；停用/冲突经验未默认采用 | 作品本轮经验记录 |
| I-02 | 创作后反馈 | 记录实际效果、来源与范围，事实/推断分开；用户反馈未伪装成 Agent 视觉检查，下一步可执行或明确无 | 作品修改记录或具体实验 |
| I-03 | 状态与证据 | 索引 ID 唯一，来源/版本可追溯；已验证条目有当前经验版本的相应范围证据；无依据不升级，反例及旧版保留 | 经验索引及其链接的具体来源 |
| I-04 | 回写与边界 | 先记录来源再更新实际变化的公共资料和索引；纯复用不写公共流水账；不保存/不入库被遵守，文本验证未升级模块媒体状态 | 文件差异、索引变更记录与本轮报告 |

初次建立流程时，I-01/I-02 可做明确标注的文档情景演练，仅证明步骤可执行；真实创作采用情况仍为 NOT_RUN，演练不进入经验索引。I-03 对空索引只能检查登记约定，不能报告已有经验验证通过。运行结构检查后仍需逐项说明上述实际检查范围。
