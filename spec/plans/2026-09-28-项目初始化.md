# AIGC_Lab 项目初始化计划

状态：DONE

## 授权与目标

用户于 2026-09-28 要求按上轮建议整理当前项目，并使用 Harness Engineering 管理。此任务落实本地目录、模板、协作规则与可执行校验；尚无真实作品需求，不假设题材、人物、平台或付费预算。

沿用现有目录名 AIGC_Lab，中文显示名为「AI 影像创作实验室」。AGENTS.md 写在本项目根目录。目录初始为空，且不属于现有 Git 仓库。

## 设计

- 六个内容目录：01_创作模板、02_提示词库、03_参考素材与风格、04_作品项目、05_工具与模型适配、06_实验与复盘。
- 根目录 README.md 供人阅读，AGENTS.md 作为 AI 的简短地图；详细规则放在 spec/。
- 每部作品自带 project.json、需求、设定、脚本、分镜、发送版提示词和验收记录；尚未生成的模板不得标成真实作品。
- 按 scope=prompts 或 media 区分文字交付与生成成品交付。
- 本地校验只核验结构、状态和可追溯记录，无法代替画面检查或用户审美判断。
- Python 标准库实现只读校验，不安装依赖，不调用生成服务。

1. `python -X utf8 scripts/validate_project.py` 检查项目结构及所有真实作品。

3. 独立 Agent 审查文件、流程和检查边界；修复后重新运行受影响检查。
4. 检查文档链接和 Git 差异；记录命令、时间、结果与未执行事项。
