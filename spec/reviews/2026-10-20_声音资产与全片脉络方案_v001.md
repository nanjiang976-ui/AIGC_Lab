# 声音资产与全片脉络方案 v001

2026-10-20。**用户已明确选择“按方案A纳入本轮”，授权正式实施。** 本页保留获准设计，实施与检查结果另记本轮验证；此前Clip格式固定、人物四格与单张道具修改一并交付。设计批准不代表音频生成、试听或平台执行通过。

## 要解决的结果

用户在LibTV手动创作时，除了图片和Clip正文，还能拿到角色音色设计/试听文本、各需配乐Shot对应的BGM提示词和节点绑定说明。修改上游后，下游沿用当前剧情、风格、角色状态和声音选择；不能仅因画布存在连线就假设模型知道整片故事。

## 现状与建议

现有 `aigc-audio` 已负责对白、表演、事件声音、时长与口型；完整调度已要求同步声音；`handoff.md` 已有版本和修改传播。缺少的是可复用的角色声音资产、逐Shot可复制BGM正文，以及每次交接实际携带的整片脉络。

| 方案 | 影响与取舍 |
|---|---|
| **A，推荐：扩展现有aigc-audio，强化共享交接** | 增加“角色音色”和“Shot配乐”两项子能力；细则放总控references，保留现有入口；用户不用多记Skill。 |
| B：新建aigc-voice-assets与aigc-score | 独立声音任务非常频繁时更清晰，但现在会增加目录、调用入口和交接维护。 |
| C：只改LibTV派生包 | 贴近平台，但源项目和平台适配容易形成两套声音事实；适合A确定后再做适配同步。 |

`aigc-music` 继续负责MV、音乐主导叙事和节拍视觉，不改成所有作品的BGM入口。声纹稳定身份与一句台词的表演分开；有每Shot配乐提示词，不等于每Shot换一首独立音乐。

## 推荐的用户流程

想法/需求 → 剧本 → **视觉资产 + 人物音色提示词** → 完整调度 → **逐Shot声音/BGM提示词** → Clip及图像/音频绑定说明 → 用户在LibTV生成选定 → 剪辑与声音整合。

仍按用户当前调用的步骤交付并停止。人物图与音色可以在同一次“准备角色资产”任务中按授权一起交付；用户只改视觉时不强制重做声音。无对白、没有需要固定声音的角色，音色项注明不适用；BGM也允许明确不用。

## 人物声音资产

每个需要固定声音的说话角色关联自己的声音卡及版本，例如 `CHAR-001 → VOICE-001 v001`。卡由Codex依据当前设定整理，不让用户重复填写整套表。

| 稳定声音身份 | 每句可变表演 | 实际资产登记 |
|---|---|---|
| 主要语言；普通话/具体方言或地区口音；是否混用其他语言；听感年龄；音高/音域倾向；声线质地；共鸣/气声；咬字；基础语速与节奏；辨识点 | 情绪、音量、重音、停顿、呼吸、哭笑与压低声音等 | 完整素材名、用户在LibTV选定的样音、实际平台音色ID或音频节点（确有时）、模型兼容范围、版本和用户确认来源 |

“中文”不代替“普通话还是粤语/四川话”；“有方言”需具体到用户认可的语言或口音。声音身份不从人物外貌推断。真人原音、平台预设与文本设计的新音色分开登记，不能将原始音频文件名直接当平台可复用voice ID。

每个角色交付：音色设计正文、独立试听台词、实际入口的填写/选择说明、生成后如何选用及回传名称。之后每条对白复用同一选定声音，单句表演单独写；哭泣、低声不自动换音色。

### 可审阅的音色例子

以下是本次虚构演示设定，不是从公开案例复制，不成为项目默认。

**音色设计正文：**

```text
为虚构角色“书店女店主”设计可在后续对白中重复使用的自然女声音色。主要语言为中文普通话，发音清楚，普通话标准口音。听感约四十岁，中低音区，声音温暖、沉稳，胸腔共鸣自然，轻微柔和气声，字头清晰、句尾平稳。基础语速从容，句间保留自然呼吸；亲切而克制，像在安静书店里与面前的人交谈。保持同一音色身份，情绪通过重音、停顿和气息变化表达。
```

**试听文本：**

```text
你找的那本书，我替你留着呢。先别急，坐下来慢慢说。原来……这把钥匙，一直在你这里。
```

试听的实际秒数、方言自然度和音色可复用性由用户在LibTV确认；上述文字不证明任何模型会提供固定音色ID。模型若分开提供音色描述与试听文本字段，就分别填写；入口没有该能力时如实改为其支持的声音选择路线。

## 每个需要BGM的Shot

每Shot登记：不配乐 / 新起音乐 / 延续同段 / 变奏 / 收束，以及对应BGM资产。需要配乐的Shot各有完整、可复制的专属提示词；同时写清它是独立生成任务，还是同一音乐段里的一个发展区间，避免把连续镜头生成成互不相干的曲子。

提示词应展开：整片音乐基调、本Shot剧情作用、当前人物情绪与变化、乐器和音色、旋律/和声气质、速度或节奏密度、是否人声、计划时长及制作余量、进入/退出、对白避让和前后音乐关系。具体BPM/调性只有确有创作意图或平台设置时才指定，不为显得专业填数。

### 可审阅的BGM例子

演示片《归还钥匙》整体是温暖克制的写实短片；当前Shot是女店主意识到旧友保存了自己的钥匙，情绪由疑惑转为释然。计划可用段落8秒，需要给剪辑留尾音。

```text
为温暖克制的写实短片创作一段室内近景配乐：安静书店里，人物看清旧友递来的旧钥匙，从迟疑转为理解，情绪变化细微而真实。以柔和钢琴单音和低音量弦乐长音为主体，节奏稀疏，旋律短而留白，声音亲近、自然、纯器乐。开头保持轻微悬而未决的感觉，中段随人物理解而温和展开，末段落在安稳的和声上，保留自然余音供剪辑衔接。对白出现时音乐保持背景层次，音域和织体留出人声空间。目标生成约12秒，供本镜选取约8秒并保留前后余量；后续同场景音乐沿用相同乐器和主题气质。
```

**本Shot使用说明：**标为新起音乐；用户选定后登记实际BGM节点与可用区间。如果后两个Shot继续同一情绪，优先使用这段音乐的后续区间或生成一段更长的统一音乐，不承诺多次独立生成天然保持同一旋律。

每个对应Shot的提示词仍完整写全，不用“同上”。多Shot合成一条Clip时，交接一条连续音乐时间线，不在每个Shot开头重复重置音乐。先后叙事目的变了，音乐发展也应相应变化；整片一致允许有原因的局部变化。

## 全片一致性的实施方式

**一份当前有效的作品依据，三层约束。**

1. 全片层：故事主题、情绪走向、视觉与声音语言、人物稳定身份及不可变规则。
2. 场景/段落层：这一场在全片的位置、人物此刻知道/想要什么、本场光线空间、情绪弧线、音乐主题与段落目标。
3. Shot/Clip层：实际起点、核心事件、相机/主体/画面、台词及声音节拍、终态和进入下一段的条件。

局部变化先说明叙事理由。例如同一部暖色写实片可以在人物进入冷库时使用冷光，但仍保持已经确定的摄影质感和人物身份；音乐转紧张也须源于当前危险或人物认识变化，不凭单个关键词任意换风格。

每次进入下游，Codex自动整理一份短的**当前作品脉络交接卡**：

| 内容 | 必须回答 |
|---|---|
| 当前版本和范围 | 用的是哪版需求/剧本，本轮只做什么 |
| 整片核心 | 主题、结局方向、视觉和声音基调 |
| 剧情位置 | 前面发生什么、当前人物知道什么/想做什么、此段要造成什么变化 |
| 当前有效资产 | 人物/衣装/道具/场景/声音的版本、完整名称、真实选用状态 |
| 相邻镜头衔接 | 本段实际入口、计划出口、动作/信息/光线/声音的联系 |
| 最新修改 | 用户刚改了什么，哪些旧决定作废、哪些保留、缺什么 |

这张卡用于Codex节点之间理解作品，放在交接说明中，不整张塞进生成模型。每条实际模型提示词再展开本条必须知道的事实与风格，让独立生成也自足。用户无需手工复制所有项目文件；同聊天直接复用，跨聊天提供由Codex生成的当前交接包。

项目文件继续分工：`00_创作需求.md`保留全片目标/风格；`01_故事与角色设定.md`增加角色声音专节；`02_剧情脚本.md`保留最新剧本；调度/分镜与Clip保存当前动作和声音；`06_修改与验收.md`记录决定、实际反馈和影响范围。逐Shot声音正文可在当前作品的`04_生成提示词/`按需新建声音稿，不声称已有一个固定的`08_声音与剪辑计划.md`模板，不修改旧CSV表头。

“当前作品脉络”是从这些实际来源整理的派生交接，不是另造一套矛盾事实。发现摘要版本落后或用户刚改了上游，先更新相关交接再写下游；不靠聊天太长时的隐含记忆。

## 上游修改怎样传下去

| 用户修改 | 需要更新 | 通常可保留 |
|---|---|---|
| 角色改说四川话 | 该角色声音卡、试听稿、对白表演、相关时长/口型和音频绑定 | 未受影响的人物视觉、场景与道具 |
| 结尾由和解改为离开 | 剧本动机与铺垫、反应镜头、音乐情绪落点、相邻Clip出口 | 与新结局相容的已有资产 |
| 旧钥匙从银色改为黄铜 | 道具母版、可见镜头与相关文字 | 不涉及此物的段落及声音身份 |
| 前段实际结束时已经站起 | 后段入口、相机/动作连续性及所需真实末帧 | 稳定身份与不变的故事事实 |

每轮给一次简短变更摘要，列受影响项再修，不为每一句话另建整套表。旧版本保留，已生成素材不能自动充当新版本的结果。

## 来源与能力边界

2026-10-20实读的公开案例中，《幕Scene》文本节点使用段落级情绪/光线/运动方向和音乐规则；《长安异闻录》画布有角色音频分组、7项按人物命名的音频素材，另有首尾帧、道具状态和补镜头。这些支持资产化与段落约束的组织方法，不证明某个样音在所有后续片段里都稳定生效。

[LibTV官方更新记录](https://www.liblib.tv/feature-updates)的v1.5（2026-09-20）介绍角色卡可关联音色，并介绍剧本局部改写对大纲、钩子、伏笔的关联影响。本轮只读说明及公开视频画布，没有验证用户账号音色生成、特定方言、语音驱动口型、BGM时长或音乐延续成功。

实施时仍须按实际音频入口核对：音色设计/声音选择/语音合成/音乐生成各自模型；可复用音色ID或音频节点；语言方言支持；视频如何消费声音；音乐时长与续作能力。原生视频声音、独立配音、背景音乐和最终混音分别安排，避免两套对白或BGM重复叠加。

## 拟修改范围与验证

采用A时，修改现有`aigc-audio`及其usage，新增聚焦的声音参考文档；在总控/交接/完整调度/Clip/剪辑的必要位置接入；模板仅增加必要声音专节；README同步自然语言入口。保持21个Skill，不默认改LibTV派生包或全局安装。

验收用真实文字执行检查：同角色不同情绪仍沿用声音身份；每个需配乐Shot有完整BGM提示词及连续复用说明；更改上游剧情后，声音/镜头受影响项正确更新；只改道具颜色时不重做声音。媒体结果由用户在LibTV生成试听后反馈，结构校验不代表音色、旋律或口型通过。
