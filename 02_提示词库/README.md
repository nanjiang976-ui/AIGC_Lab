# 提示词库

保存跨作品可复用的表达结构，具体剧情与实际发送文本留在各自作品目录。初始模块均为**未实测**，不代表平台效果保证。

- [分类模块索引](分类模块/00_使用索引.md)：12 类、60 条模块，按本轮需要选择。
- [成熟提示词资产](成熟提示词资产/README.md)：用户指定的可复制资产区，逐项标注验证范围；现含[人物参考图→四格人物设定表](成熟提示词资产/人物参考图转四格设定表_v001.md)，保留原文及逻辑补全依据，媒体未测。
- [通用提示词骨架](通用提示词模块.md)：图片、视频与局部修改的基础结构。
- [入库规范](入库规范.md)：自动抽取、查重、分类、版本与实测证据要求；允许零新增。
- [入库日志](入库日志.md)：新增、修订及验证状态变化。

使用前读取作品设定，替换变量并移除不适用项，成稿存入作品 `04_生成提示词/本次发送.md`。工具参数单独适配，未知能力先核验。用户本轮要求不入库或不保存时，遵从其要求。
