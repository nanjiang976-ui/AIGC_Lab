# 提示词库

保存可复用的表达结构，不把某次作品的完整剧情堆入公共库。初始[通用提示词模块](通用提示词模块.md)是未实测模板，不代表任何平台的效果保证。

从 [分类模块使用索引](分类模块/00_使用索引.md) 选择需要的类别；首批覆盖叙事、人物、服装道具、场景、构图、光色、风格、静态画面、动作、运镜、连续性、声音后期与修复等用途。具体类别以索引为准，全部初始模块均为未实测。

`aigc-creator` 每次创作后按 [入库规范](入库规范.md) 自动抽取、查重并保存通用结构；变动见 [入库日志](入库日志.md)。已有同等模块就复用，允许零新增。用户本轮要求不保存时不入库。

使用时先读取作品需求、设定和分镜，再选取所需模块，替换占位符并删除不适用项。作品实际发送文本保存到该作品的 `04_生成提示词/本次发送.md`。

将模块升级为“实测可用”时，需要记录工具、模型或版本、测试日期、输入及结果证据、适用范围与失败条件。一次成功只支持其实际测试范围，不推定跨模型通用。

叙述提示词与工具界面/API 参数分开。未知参数或模型能力先核验，在适配记录中说明，避免把其他工具语法直接复制进去。
