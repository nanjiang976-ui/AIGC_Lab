# 通用提示词模块

状态：**未实测**。以下结构用于组织输入，尚未验证任何特定工具或模型效果。

## 图片：描述一个确定画面

```text
主体：{{人物或物体的固定特征、服装与状态}}。
场景：{{地点、环境与关键空间关系}}。
画面：{{主体在画面中的动作或姿态、景别、角度与构图}}。
光线与色彩：{{光源方向、明暗关系与主要色调}}。
风格与情绪：{{具体视觉属性和情绪}}。
保持：{{参考素材中必须保留的特征}}。
避免：{{与本作品直接相关的错误或多余元素}}。
```

## 视频：描述一个时间段内的变化

```text
起始画面：{{主体、场景、位置与初始状态}}。
动作顺序：{{先发生什么，再发生什么；匹配镜头时长}}。
镜头运动：{{固定或明确的运镜方向、幅度与速度}}。
结束画面：{{动作停止位置、表情与最后的构图}}。
连续性：{{人物外观、服装、道具、光线与空间关系的固定要求}}。
风格与情绪：{{视觉属性、动作节奏和情绪变化}}。
```

音频、首尾帧、多参考图或其他控制项仅在工具已支持且本次需要时添加。声音不能仅因出现在提示词中就视为已生成。

## 局部修改：规定修改范围

```text
基于所提供的原始图像或素材进行修改。
修改对象与位置：{{明确对象、区域或时间段}}。
目标变化：{{改成什么，变化幅度是什么}}。
保持不变：{{角色身份、其他对象、构图、光线、背景等具体内容}}。
边界与衔接：{{修改区域如何与周围材质、光影或动作衔接}}。
```

是否支持局部遮罩、视频修改或保留参考特征，需要在选定工具中确认。保留要求是创作约束，需要用结果检查，不能当作已实现的能力。
