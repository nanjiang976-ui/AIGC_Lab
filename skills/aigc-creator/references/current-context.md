# 当前作品脉络：跨节点共享依据

v001 · 2026-10-20。由总控与各节点通过同版 [交接协议](handoff.md) 按任务加载。本文件规定怎样整理当前依据，不保存某部作品的事实；人物音色与逐Shot配乐的具体交付另见 [声音资产与配乐](voice-and-music.md)。

## 何时读取、读取多少

进入作品的需求、剧本、资产、调度、分镜、声音、Clip、剪辑或局部修改时，先核对当前版本，再读取本步相关来源并整理短卡。叶节点必读handoff，由handoff引到本文件；不要求每个节点重复加载全套参考文档。只做单图时保留相关主体、风格、当前修改与资产状态，不强加剧情、声音或全片表格。无既有作品的新想法如实写“首稿／未建档”，只整理已有事实与必要未知。

同一聊天复用已有产物与最新明确修改；跨聊天由Codex整理当前交接包，附相关来源、版本和必要正文。用户无需重新填写完整需求表，也不必手工复制全部项目。资料不可访问或存在影响本步的冲突时，只补该缺口；不能用压缩摘要或旧聊天记忆覆盖当前明确决定。

## 一份事实来源，三层约束

| 层级 | 本步必须承接的内容 | 局部变化的处理 |
|---|---|---|
| 全片 | 主题、主要因果和结局方向、情绪走向、视觉与声音语言、稳定人物身份、已锁约束 | 新明确决定优先；不因单镜关键词任意换整片风格 |
| 场景／段落 | 位于全片何处、前面已发生什么、人物此刻知道什么／想要什么、本场要改变什么、空间光线、情绪弧线与音乐主题 | 变化须有故事或场景依据，如进入冷库可转冷光，摄影质感与身份仍承接全片 |
| Shot／Clip | 当前事件、相机／主体／画面、逐字台词及声音节拍、真实入口与计划出口、与下一段的条件 | 不把计划出口当实际结果；多Shot一Clip保留信息、动作和连续音乐的发展 |

背景与结局供Codex理解人物选择，并不意味着每条模型正文都讲完整剧情。独立模型输入只展开本条必须知道的事实、风格、表演与衔接；不要让角色提前表现出尚未获知的信息。

| 实际发送正文、Clip映射、逐Shot声音稿 | `04_生成提示词/`当前版本；只按需要增补声音稿，不假设存在固定的声音模板文件 |

短卡是这些来源的派生摘要，放现有交接说明或聊天中，不另造一套事实数据库。每次下游开工核对所引版本、最新修改和实际结果：摘要落后时先刷新，再写下游。文件版本号未变但用户刚明确改动时，该决定仍须进入当前依据；允许保存则更新所属来源及修改记录，不保存则仅在聊天承接，并注明尚未落盘。互相矛盾且无法判断当前有效决定时，不悄悄挑一个版本。

不为每条消息重建全表；一轮整理一张短卡，后续只更新变化部分。用户只调整本步结果时，不要求重新确认未变事实。

## 当前作品脉络交接卡

由Codex自动从上述实际来源整理，内容要短而具体。下表是后台检查字段，不是要求用户填写的问卷；不适用项说明原因。

| 内容 | 必须让接手节点知道 |
|---|---|
| 当前版本与范围 | 作品／revision、本轮节点、prompts或media、实际读取的来源与版本、确认／假设／待定 |
| 整片核心 | 主题、当前结局方向、整体视觉和声音基调、不可改变项 |
| 剧情前中后 | 前段已发生什么；当前人物知道什么、想做什么；本段造成的变化与后段目标，区分角色认知与观众信息 |
| 有效资产与声音 | CHAR／OUTFIT／SCENE／PROP／VOICE／BGM的相关版本、完整名称和真实状态：文字设计、待生成、已生成待选择、用户确认、待绑定／已实际绑定；没有真实素材不编路径、标签或voice ID |
| 入口与出口 | 本段实际起点的来源；尚无实际结果时注明计划起点；计划出口、真实反馈及相邻动作／视线／信息／光线／声音联系 |
| 最新修改与失效项 | 用户改了什么、影响哪些来源和产物、旧决定／摘要／素材哪里失效、保留什么、缺什么与下一动作 |

一张声音节点、一条画布连线或一个文件名都不证明后续模型能消费该内容。短卡用于Codex跨节点理解；模型侧仍须按实际入口展开必要描述并绑定真实图像／音频。声音设计、选定样音、可复用平台voice ID、Clip音频输入与实际口型是不同状态，不能互相代替。

## 按最小语义影响传播

先定位改动事实，再沿实际依赖复查；“最小”指只改受影响内容，不能删掉用户要求的复杂表达。按项目规则保留旧版、升版并重置受影响状态；旧媒体不能自动变成新版证据。

| 改动 | 需要复查／更新 | 通常可沿用 |
|---|---|---|
| 角色改说四川话 | VOICE语言／具体口音、试听稿、对白文字与表演、时长／口型、音频选择与绑定；相关Clip声音输入 | 未变视觉身份、场景与道具；不自动重做全片音乐 |
| 结局从和解改为离开 | 动机与前段铺垫、人物认知／情绪反应、受影响镜头出口、BGM发展与落点、Clip及剪辑衔接 | 与新结局相容的视觉／声音资产 |
| 道具由银色改黄铜 | 道具母版与相关可见画面／正文；先核对是否改变线索意义 | 未涉及该物的段落、稳定声音身份和相容的配乐；不机械重做声音 |
| 前段实际结尾已站起 | 后段实际入口、动作／相机连续性、真实末帧依赖与声音跨切点 | 不变剧情、身份和已选声音 |

每轮给一次受影响项、可保留项和失效项摘要，再交接当前版本。剧情变化会影响音乐语义，颜色变化若无剧情意义通常不影响声音；按实际因果判断，不按字段名机械全链重做。

## 完成判断

下一节点应能说清“这是哪版故事、位于哪里、人物为何这样做、用什么真实资产、从何处开始、这轮刚改了什么”。检查来源与摘要一致、必要事实进入本条提示词或真实绑定、未完成状态如实保留即可结束当前范围。文字脉络一致不等于模型理解、音色稳定、音乐连续或媒体验收通过；这些由实际生成和用户在LibTV的反馈分别证明。
