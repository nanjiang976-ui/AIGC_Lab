# 总控选择规则

## 定位与调用

先尊重用户指定的 skill、阶段、作品和交付范围。已有资料足够时直接做当前任务；只有会改变下游的缺项才追问。总控负责选路与交接，具体创作时读取选中的模块/节点 SKILL.md，不只凭名称猜行为。

在完整 AIGC_Lab 中，验证项目契约后优先从实际定位的项目根读取 `skills/catalog.json`，按 name 找 path，共享资源也读取该项目内总控的 references，避免新工作树与旧全局包混用。脱离项目的用户级平铺安装环境，从当前 `aigc-creator/SKILL.md` 的真实路径定位同级 `aigc-*` 包，先确认文件存在并与当前套件配套再读取；技能元数据可用于定位，但不能覆盖用户明确的候选工作区。不扫描整盘，不假造工具调用成功。

缺失依赖时可以完成不依赖它的聊天草稿，清楚指出安装缺项；不能宣称全链路可用。源目录分类与安装目录平铺是两件事，安装工具负责保持名称唯一和依赖完整。

配套版本由各 SKILL.md 的 `metadata.bundle` 和 `metadata.bundle_version` 核对；以当前总控与catalog的实际字段为准。名称相同但版本字段缺失或不同，先报告完整同步需求，不静默读取旧规则。

每节点通过 [交接协议](handoff.md) 按任务加载 [当前作品脉络](current-context.md)：从现有资料自动整理全片、场景和Shot/Clip三层约束，承接当前剧情/风格/声音/修改事实。短卡不是另一套事实源；摘要落后先刷新，只读本步相关来源，不要求用户重新填表。

## 个人模板调用

用户粘贴模板或直接点名节点时，按[调用识别协议](invocations.md)消费[统一索引](invocations.json)：显式技能名优先，中文口令作候选，具体节点优先于题材模块。仅加载本步指南；多节点不静默丢弃，未命中短语仍由总控理解。模板调用不会扩大生成/发布授权。

## 首先判定任务范围

| 用户输入 | 下一动作 |
|---|---|
| 只有一句想法/模糊要求 | aigc-prd（创作需求） 逐轮访谈，每次一问并给可见更新 |
| 已有完整PRD | aigc-prd（创作需求） 仅做完整性/冲突检查；足够时进入指定节点 |
| 按需求写剧本 | script交付剧本、节拍与人物/重要道具/场景资产清单，默认停在剧本 |
| 已有脚本，只要完整调度 | blocking读取完整调度契约，内部协同storyboard/audio，交一份完整结果 |
| 按剧本做参考图提示词/角色参考图/重要道具参考/场景参考图/转换四格 | visual-assets承接资产清单，按资产类型选择规范，沿用已确认主体信息；只要图不强制声音 |
| 按剧本准备完整角色/作品资产 | visual-assets协同audio，交视觉资产与所需人物音色设计/试听稿及真实选用状态，不自动生成媒体 |
| 角色音色/试听台词/每Shot的BGM提示词 | audio读取voice-and-music；普通BGM不改走MV模块，人物稳定声线与单句表演分开 |
| 调度转Clip | video-prompts编译一镜/多镜Clip及真实输入映射 |
| 拉片/拆公开工程/分析提示词 | shot-study按可得来源拆镜头、画布、提示词，不编造缺失原工程 |
| 复盘/根据案例改进Skill | iteration读取同一经验协议，先证据与行为复测，再按授权范围写回 |
| 已有分镜，只要首帧/视频正文 | 直接进入 keyframes/video-prompts，先检查素材与起止状态 |
| 续作/局部修改 | 读取当前版本与实际结果，定位受影响节点，不重走全链路 |
| 单张图片 | 需求→视觉设定→图片提示词→文字审查；无叙事不强加脚本/声音 |
| 重复角色图片系列 | 视觉资产→各图画面→一致性检查，使用固定资产ID |
| 明确要求连续完成完整多镜头提示词包 | 复用已有需求/剧本，补齐缺少的剧本与资产清单→视觉资产与所需人物音色→完整调度及逐Shot声音/BGM→Clip包及输入连接；首帧按入口选支路，实际生成/用户验收/绑定待执行 |
| 媒体生成请求 | 完成文本与输入检查后，按已有授权调用适合的工具；费用/发布不由skill自动扩大 |
| 只讨论/不保存 | 所有交付留在聊天，不创建作品、入库或写安装目录 |

## 用户在LibTV验收

实际图片、视频、声音与成片由用户在LibTV观看确认，按handoff的“用户媒体验收与反馈”记录。用户反馈后直接进入对应创作节点修改；Codex保留文字与结构自检，不再自动安排独立审查节点，也不要求回传媒体作为继续文字工作的前提。引用仍须真实，未提供的平台标签只标待绑定。

## 专业能力协同与下一步

通用节点说明当前步骤做什么，类型模块说明这一类作品重点检查什么；catalog 的依赖表示配套可用性，不要求每个作品逐个执行所有节点。

完整资产步骤由visual-assets/audio协同，图片单项请求不强加音色；人物音色与逐ShotBGM按需读取 [声音资产与配乐](voice-and-music.md)。完整调度由blocking协同storyboard/audio一次交付，含当前人物目的与逐Shot声音/BGM；只改景别、切点或对白声音时才单独进入对应节点。已核验模型支持原生音频时，由video-prompts将声音设计编译进Clip；用户要独立声音资产时仍交该资产正文与选用说明。已有平台文字智能剪辑能力时，由editing编写针对实际素材的剪辑指令并检查结果，不默认要求另一套软件或额外音轨生产。

每次交付按 handoff 的“默认逐步交付”与结尾衔接规则，完成当前节点后停下，供用户调整并自行调用下一节点；结尾给一个最近可执行的下一步及所需当前成果。同一聊天直接复用当前有效内容，文字下游被调用后可保留真实素材依赖继续草案。仅明确授权的连续任务继续执行，不把后台专业协同拆成用户逐站调用。

## 用途分类与主模块

| 主模块 | 选择信号 | 主要验收 | 容易混淆的边界 |
|---|---|---|---|
| aigc-narrative（剧情与漫剧） | 剧情、漫剧、人物小品、故事反转 | 人物目标、因果、情绪与连续性 | 宣传目的优先的剧情广告以commercial为主 |
| aigc-commercial（商业广告） | 商品、品牌、活动推广、转化 | 产品识别、主张证据、传播重点 | 不用科普外壳掩盖未经证实的卖点 |
| aigc-explainer（科普解释） | 科普、机制、课程、知识图解 | 概念准确、教学目标、类比边界 | 真实软件操作选product-demo |
| aigc-presenter（主持人口播） | 数字人、主持人口播、面对镜头讲述 | 可讲述的文本、表演、声音与口型 | 内容本身复杂时叠加explainer/commercial |
| aigc-documentary（纪实与重建） | 纪实、采访、历史、事实性人物故事 | 来源、事实、素材与重建身份 | 虚构故事选narrative；重建不伪装档案 |
| aigc-music（音乐影像） | MV、节拍视觉、歌词与音乐影像 | 音乐结构、节奏和视听联系 | 普通剧情BGM选audio；无音轨的环境循环选visual-art |
| aigc-product-demo（产品演示） | 功能教程、操作步骤、产品用法 | 真实产品状态、步骤、可见结果 | 情绪/卖点广告选commercial |
| aigc-visual-art（视觉艺术） | 氛围、抽象、循环、背景板、无叙事影像 | 视觉规则、运动、循环/显示条件 | 若有具体故事因果转narrative |
| aigc-montage（混剪回顾） | 已有素材混剪、预告、活动回顾、再编排 | 素材来源、入出点、信息顺序、声音 | 没有素材不能假装完成素材盘点 |

类型是工作流分类，不是市场穷举。真人/二维/三维/定格/漫画、横竖屏、对白/旁白、文生/图生/混合剪辑分别记录为独立维度。文旅宣传可走commercial，家庭纪念按事实或虚构选documentary/narrative，动作预演按目的选narrative或visual-art；新用途确有独特输入/验收时再新增模块，不按每种画风复制skill。

## 主流程与可并行步骤

用户逐步调用的主链：**想法/需求→剧本→视觉资产与人物音色→完整镜头调度及逐Shot声音/BGM→Clip及输入连接→用户生成反馈**。剧本附资产清单；分镜、声音和必要的节奏估算在完整调度内部协同，关键帧按实际入口/端点控制需要启用。默认每步交付即停止；用户在LibTV生成、观看/试听并反馈，Codex按反馈修改当前节点。剪辑属于按授权选择的后续工作，不自动延长当前文字任务。

先分别填写交付范围、制作输入路线和资产状态。未选平台或没有图片时，路线可以保持未定；先交所需参考资产图片正文和完整静态起点设计，首帧是否需要作为实际输入另作判断，不能把 `scope=prompts` 推断为纯文生。用户明确选纯文生、已明确采用只能接收文字的入口，或只要求当前单节点时，按该可观察条件裁剪；用户另外要求的参考图提示词仍须交付。

- 视觉概念可与脚本并行，但资产定稿需匹配脚本的服装/动作/道具需求。已有角色母版可直接继承。
- 声音在脚本阶段介入：对白试读、节奏和口型路线影响镜头时长；最终混音在素材成形后。
- 分镜和调度相互约束。改机位后复查左右/轴线，改走位后复查画面是否看得清。
- 人物新建/转换统一采用上排正面与3/4转侧胸像、下排背面全身与正面略3/4全身；重要道具每件独立单图，场景采用独立空间规范，细则只维护在reference-assets。物体/录屏不机械套人脸规范，已有适用资产可复用。
- 图生路线需要实际图像输入；已明确的纯文生路线不强制增加出图任务。提示词阶段准备所需参考资产正文；身份参考直接进入Clip，首帧/首尾帧入口才准备对应静态图。所需实际图尚缺则标候选/待生成，图生视频绑定不标就绪。动画预演可先用文字/粗略画面检验节奏，但不能冒充最终视觉已锁定。
- Codex文字自检贯穿每步；完成当前用户节点后默认停止。明确的多节点授权可连续执行至范围结束，仍遵守关键创作缺项、权限/预算边界和用户指定预览点。

## 下游改动规则

每次进入节点先读 [交接协议](handoff.md) 的当前输入和依赖，并按current-context核对当前依据。上游变更沿最小语义影响复查：方言影响VOICE/对白/时长口型/绑定，结局影响铺垫情绪/BGM，仅无叙事影响的颜色变化不重做声音。刷新失效摘要，执行完成更新下轮起点，说明已确认、当前草案和真实生成依赖。终止条件是用户当前交付范围满足，并非所有作品都必须产出20种文档。
