# 总控选择规则

## 定位与调用

先尊重用户指定的 skill、阶段、作品和交付范围。已有资料足够时直接做当前任务；只有会改变下游的缺项才追问。总控负责选路与交接，具体创作时读取选中的模块/节点 SKILL.md，不只凭名称猜行为。

在完整 AIGC_Lab 中，验证项目契约后优先从实际定位的项目根读取 `skills/catalog.json`，按 name 找 path，共享资源也读取该项目内总控的 references，避免新工作树与旧全局包混用。脱离项目的用户级平铺安装环境，从当前 `aigc-creator/SKILL.md` 的真实路径定位同级 `aigc-*` 包，先确认文件存在并与当前套件配套再读取；技能元数据可用于定位，但不能覆盖用户明确的候选工作区。不扫描整盘，不假造工具调用成功。

缺失依赖时可以完成不依赖它的聊天草稿，清楚指出安装缺项；不能宣称全链路可用。源目录分类与安装目录平铺是两件事，安装工具负责保持名称唯一和依赖完整。

配套版本由各 SKILL.md 的 `metadata.bundle` 和 `metadata.bundle_version` 核对；本套件为 `aigc-lab` / `1.1.1`。名称相同但版本字段缺失或不同，先报告完整同步需求，不静默读取旧规则。

## 个人模板调用

用户粘贴模板或直接点名节点时，按[调用识别协议](invocations.md)消费[统一索引](invocations.json)：显式技能名优先，中文口令作候选，具体节点优先于题材模块。仅加载本步指南；多节点不静默丢弃，未命中短语仍由总控理解。模板调用不会扩大生成/发布授权。

## 首先判定任务范围

| 用户输入 | 下一动作 |
|---|---|
| 只有一句想法/模糊要求 | aigc-prd 逐轮访谈，每次一问并给可见更新 |
| 已有完整PRD | aigc-prd 仅做完整性/冲突检查；足够时进入指定节点 |
| 已有脚本，只要完整调度 | blocking读取完整调度契约，内部协同storyboard/audio，交一份完整结果 |
| 角色参考图/场景参考图/转换四格 | visual-assets确认类型与预设，沿用已确认主体信息 |
| 调度转Clip | video-prompts编译一镜/多镜Clip及真实输入映射 |
| 拉片/拆公开工程/分析提示词 | shot-study按可得来源拆镜头、画布、提示词，不编造缺失原工程 |
| 复盘/根据案例改进Skill | iteration读取同一经验协议，先证据与行为复测，再按授权范围写回 |
| 已有分镜，只要首帧/视频正文 | 直接进入 keyframes/video-prompts，先检查素材与起止状态 |
| 续作/局部修改 | 读取当前版本与实际结果，定位受影响节点，不重走全链路 |
| 单张图片 | 需求→视觉设定→图片提示词→文字审查；无叙事不强加脚本/声音 |
| 重复角色图片系列 | 视觉资产→各图画面→一致性检查，使用固定资产ID |
| 完整多镜头创作，只生成提示词 | 参考资产正文→完整调度→Clip包→平台发送版；首帧按入口选支路，实际出图/审图/绑定待执行 |
| 媒体生成请求 | 完成文本与输入检查后，按已有授权调用适合的工具；费用/发布不由skill自动扩大 |
| 只讨论/不保存 | 所有交付留在聊天，不创建作品、入库或写安装目录 |

## 用途分类与主模块

| 主模块 | 选择信号 | 主要验收 | 容易混淆的边界 |
|---|---|---|---|
| aigc-narrative | 剧情、漫剧、人物小品、故事反转 | 人物目标、因果、情绪与连续性 | 宣传目的优先的剧情广告以commercial为主 |
| aigc-commercial | 商品、品牌、活动推广、转化 | 产品识别、主张证据、传播重点 | 不用科普外壳掩盖未经证实的卖点 |
| aigc-explainer | 科普、机制、课程、知识图解 | 概念准确、教学目标、类比边界 | 真实软件操作选product-demo |
| aigc-presenter | 数字人、主持人口播、面对镜头讲述 | 可讲述的文本、表演、声音与口型 | 内容本身复杂时叠加explainer/commercial |
| aigc-documentary | 纪实、采访、历史、事实性人物故事 | 来源、事实、素材与重建身份 | 虚构故事选narrative；重建不伪装档案 |
| aigc-music | MV、节拍视觉、歌词与音乐影像 | 音乐结构、节奏和视听联系 | 无音轨的环境循环选visual-art |
| aigc-product-demo | 功能教程、操作步骤、产品用法 | 真实产品状态、步骤、可见结果 | 情绪/卖点广告选commercial |
| aigc-visual-art | 氛围、抽象、循环、背景板、无叙事影像 | 视觉规则、运动、循环/显示条件 | 若有具体故事因果转narrative |
| aigc-montage | 已有素材混剪、预告、活动回顾、再编排 | 素材来源、入出点、信息顺序、声音 | 没有素材不能假装完成素材盘点 |

类型是工作流分类，不是市场穷举。真人/二维/三维/定格/漫画、横竖屏、对白/旁白、文生/图生/混合剪辑分别记录为独立维度。文旅宣传可走commercial，家庭纪念按事实或虚构选documentary/narrative，动作预演按目的选narrative或visual-art；新用途确有独特输入/验收时再新增模块，不按每种画风复制skill。

## 主流程与可并行步骤

PRD → 故事/信息脚本与基础设定 → 视觉资产 → 完整镜头调度（协同分镜/声音）→ 节奏预演 → Clip编译与输入适配 → 结果回传/审查 → 剪辑与成片检查。关键帧是按实际入口/端点控制需要启用的支路。

先分别填写交付范围、制作输入路线和资产状态。未选平台或没有图片时，路线可以保持未定；先交所需参考资产图片正文和完整静态起点设计，首帧是否需要作为实际输入另作判断，不能把 `scope=prompts` 推断为纯文生。用户明确选纯文生、已明确采用只能接收文字的入口，或只要求当前单节点时，按该可观察条件裁剪；用户另外要求的参考图提示词仍须交付。

- 视觉概念可与脚本并行，但资产定稿需匹配脚本的服装/动作/道具需求。已有角色母版可直接继承。
- 声音在脚本阶段介入：对白试读、节奏和口型路线影响镜头时长；最终混音在素材成形后。
- 分镜和调度相互约束。改机位后复查左右/轴线，改走位后复查画面是否看得清。
- 角色参考采用新建/转换两种四格预设，场景采用独立空间规范；物体/录屏不机械套人脸规范，已有适用资产可复用。
- 图生路线需要实际图像输入；已明确的纯文生路线不强制增加出图任务。提示词阶段准备所需参考资产正文；身份参考直接进入Clip，首帧/首尾帧入口才准备对应静态图。所需实际图尚缺则标候选/待生成，图生视频绑定不标就绪。动画预演可先用文字/粗略画面检验节奏，但不能冒充最终视觉已锁定。
- 审查贯穿每步；普通已授权步骤自动继续，只在关键创作选择缺失、权限/预算边界或用户指定预览点停下。

## 下游改动规则

每次进入节点先读 [交接协议](handoff.md) 的当前输入和依赖；上游变更按影响复查。执行完成更新下轮起点，说明哪些是已确认、哪些只是当前草案、哪些仍需真实生成结果。终止条件是用户当前交付范围满足，并非所有作品都必须产出20种文档。
