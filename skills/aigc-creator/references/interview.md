# 逐轮访谈与创作扩展

## 选择下一个问题

不要机械地按清单从头问。先提取用户已经说过的媒介、用途、受众、时长/张数、风格、情节与禁区；选择“答案会改变最多下游内容”的一个缺口。优先确认创作意图，其次是结构，最后才是外观小细节。

| 用户状态 | 本轮推进 | 合适的问题示例 |
|---|---|---|
| 只有一个意象 | 先复述已知画面，探索表达 | “你希望看到这幅画的人更先感到温暖、孤独，还是神秘？” |
| 有故事梗概 | 找人物动机或冲突 | “主角为什么一定要在今晚完成这件事？” |
| 剧情完整但平淡 | 提一个与既有主题相容的变化，不强加反转 | “你想让结尾落在团聚的满足，还是留下失而复得的余味？” |
| 外观或风格不清 | 比较可观察的差异 | “你更偏柔和手绘质感，还是材质真实、光影自然的电影画面？” |
| 续作 | 先读台账，只问新决策 | “这次换场景时仍是同一天、同一套服装吗？” |
| 用户让你决定 | 交付一版，不继续问卷 | 用“本版工作假设”说明少量必要选择，不标为用户原话 |

示例只是问法，不是默认选项。单图不问反派和结局；无叙事产品图不增加人物。用户已给明确信息不再问。

## 扩展内容的抓手

- 故事：目标与代价、障碍为何存在、选择如何推动后续、转折是否有铺垫、结尾是否回应开头。
- 角色：欲望、矛盾、关系变化、行为习惯；用可见动作表达情绪，如犹豫的手部动作而非只写“内心复杂”。
- 画面：主体层级、前中后景、空间位置、可辨识道具、光源方向、颜色关系、留白用途。
- 视频：每镜头承担一个叙事作用，动作前后有变化；对白无需重复画面已经说明的事。
- 节奏：有事件推进，也允许停顿、反应和空镜；不要默认所有故事都要快切、悬疑或反转。

给 2–3 个候选方向时说明体验差别，允许用户自己描述。一个问题收获答案后，写 2–5 句更新版梗概/画面，显示创作有进展，再推进下一个必要问题。

## 保存与收束

每轮在作品 `00_创作需求.md` 维护以下简短区块，保留已有内容：

- **用户已明确**：确切选择与其来源（本轮回答/已有资料），不伪造逐字引语。
- **本版工作假设**：Agent 为便于起草提出的取舍；只有用户授权自行决定时才用作确定稿的依据。
- **候选未采用**：有价值且用户可能回看才记录，避免无限累积。
- **影响制作的待定项**：只留会改变主体、结构、时长或生成输入的内容。
- **下轮从这里继续**：当前阶段、当前版本、下一个问题或动作、已经完成的镜头、用户最近修正。

纯聊天讨论或用户禁止落盘时只在回复里维护摘要。

满足“目的明确、主要内容可执行、风格可描述、交付范围明确”即可开始产出；不以固定问满 N 轮为门槛。平台未定可直接做通用文字材料。用户说暂停就保存进度后停，不能趁暂停替其决定结局。

草案可含明确标识的待定项，但不能混入可发送正文。用户要求直接交付且授权你补全时，给出可用的一版，并在内部列工作假设；普通创作取舍无需反复审批。参考图生成结果与视觉母版选择只在真实存在时记录。
