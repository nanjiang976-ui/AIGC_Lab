## 使用方法

每镜头选择少数能改变画面的词组：主体核心动作和硬约束先写；相机、表演、画面三要素齐备后才加修饰。保留一个主导光线/材质/运动风格，并检查彼此是否冲突。中英文摄影术语可作内部对照，发送语言按平台核验，不默认英文或双语更有效。

### 构图与空间

| ID | 词语/术语 | 可见作用 | 使用条件与检查 |
|---|---|---|---|
| LX-COMP-01 | 前景遮挡 | 边缘人/物建立层次或窥视感 | 遮挡不得挡住本镜必须看懂的手/眼/道具 |
| LX-COMP-02 | 前中后景分层 | 建立人物、动作、环境的深度关系 | 每层明确是什么，避免“三层都重要” |
| LX-COMP-03 | 对角线构图 | 动作轨迹或身体轴线倾斜贯穿画面 | 写清从哪一角到哪一角，检查越轴变化 |
| LX-COMP-04 | 居中主体／中心动作落点 | 快切中便于追踪主要行动 | 不要求所有镜头机械居中；留出运动空间 |
| LX-COMP-05 | 负空间／留白 | 将未被占据区域作为信息/情绪空间 | 指明方向，用于等待/疏离/字幕时各有目的 |
| LX-COMP-06 | 框中框 | 门窗/结构包围主体 | 框架来自真实场景，不能凭空改变建筑 |
| LX-COMP-07 | 视线空间 | 在角色看向的一侧留出空间 | 视线与对手位置须对应；反打后重新检查 |
| LX-COMP-08 | 浅景深／深景深 | 区分注意中心或保留多层信息 | 与焦点位置/叙事目的相容；不等于统一“电影感” |

### 光线与色彩

| ID | 词语/术语 | 可见作用 | 使用条件与检查 |
|---|---|---|---|
| LX-LIT-01 | 柔和侧光 | 面部一侧渐变明暗，阴影边缘柔 | 写光从人物/画面哪侧来，别混坐标 |
| LX-LIT-02 | 硬侧光 | 清晰的阴影边界与立体面 | 若角色转身，亮暗面随动作变化 |
| LX-LIT-03 | 逆光轮廓 | 发丝/肩部边缘发亮 | 不保证面部同样明亮，需要补光理由 |
| LX-LIT-04 | 低调照明／low-key | 大面积暗部，局部信息可见 | 关键动作仍须能辨认，不用“暗”遮问题 |
| LX-LIT-05 | 高调照明／high-key | 明亮、低对比、暗部较少 | 与想要的细节/材质相容，不默认过曝 |

| LX-LIT-07 | 冷暖分区 | 不同光源区产生色温差异 | 写哪边冷哪边暖及光源，不全画面互相抵消 |
| LX-LIT-08 | 体积光／可见光束 | 空气中的雾/尘使光路可见 | 环境要有适当散射介质，不给所有室内加浓雾 |

### 表演与情绪外化

| ID | 表达词组 | 可见作用 | 使用条件与检查 |
|---|---|---|---|
| LX-ACT-01 | 嘴唇半开后停住 | 说话意图被打断或收回 | 与对白入点对应，不一边闭嘴一边长句 |
| LX-ACT-02 | 下唇抿紧，再松开 | 克制情绪后的变化 | 程度克制；不是所有悲伤都咬唇 |
| LX-ACT-03 | 视线短暂落下再抬起 | 犹豫、寻找回应或重新面对 | 写看向的具体对象，避免漂移无目标 |
| LX-ACT-04 | 短吸气后缓慢呼出 | 准备开口、压抑或恢复 | 与身体状态/声音连贯，不要求精确呼吸医学值 |
| LX-ACT-05 | 手指收紧物体后松开 | 内部张力通过接触传达 | 接触必须可见且物体可握，不凭空握持 |
| LX-ACT-06 | 嘴角逐渐放平 | 从轻松转向认真或难言 | 过渡需足够时间；避免笑/哭同时极端 |
| LX-ACT-07 | 肩膀下沉、重心后移 | 放松、泄气或退让的身体变化 | 动机来自当前情节，不把动作当心理诊断 |
| LX-ACT-08 | 先看物件，再看对方 | 让发现与反应形成因果 | 不在物件出现前预知；视线方向必须可达 |

## 组合示范与冲突修整

- “很委屈地哭”→“她想再次解释，嘴唇半开却停住；抿住下唇，视线落到桌面，眼眶渐湿；抬头寻找回应时一滴泪滑下。”
- “紧张的电影感”→“眼平近景固定，左侧虚焦肩部压住画面边缘；右侧人物手指收紧桌沿，停在半口吸气中；背景只有轻微冰箱声。”
- “产品高级”→“杯身哑光浅灰，柔和侧光显示弧面；背景无杂物；相机缓慢推进，杯身轮廓与盖口始终完整。”
- “固定机位＋环绕”不能并列为同一时段要求。先决定目标；若需要两段，明确切点/连续过渡与时间。
- “全身特写＋面部微表情极清晰＋远处城镇细节清晰”需要重新选择画面信息层级；可以拆镜或改变景别/景深，不靠更多形容词解决。

## 新条目如何记录

重复出现且有跨作品价值时，新增唯一 LX 类别编号，记录：表达、可见作用、适用场景、冲突词、具体例子、来源、验证状态、验证模型/日期、失败或反例。当前库已收56条；数量不作为质量目标，允许一轮零新增。

文字上有用标“文字演练”；实际模型结果需有输入/输出证据才标“已在指定组合验证”。某次作品的角色姓名、私密经历和客户数据留在作品中。新词与原公共提示词模块先查重，必要时只添加交叉索引，不复制同义长段。未经用户要求不更新长期记忆。
