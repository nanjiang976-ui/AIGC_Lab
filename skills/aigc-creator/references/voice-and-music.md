# 人物音色与Shot配乐

声音资产共享契约 v002，2026-10-20。由同版 `aigc-audio`（声音制作）、总控及相关节点按任务读取；先按 [handoff.md](handoff.md) 定位当前套件，再按 [current-context.md](current-context.md) 承接当前作品脉络。本文约定文字交付与资产交接，不声明LibTV某个模型当前已支持固定音色、方言、音乐续作或音频驱动视频。

## 范围与当前依据

人物声音与配乐服从当前剧本、全片风格和最新用户决定。先复用当前声音资产；只有声音身份、剧情作用或音乐发展受影响时修改相关项。只做图片不强制声音；无对白且无需固定角色发声时音色不适用；明确不配乐的Shot写“不配乐”及原因。音乐主导的MV叙事、节拍与画面结构由 `aigc-music`（音乐影像） 决定，这里的资产与同步契约仍可复用。

用户要求先准备人物声音/BGM资产时，先交完整文字资产包，不能以原生视频已有声音为由略过。交付设计不等于获准调用生成；媒体、付费和对外操作仍按已有授权。正常原生音频路线可复用当前设计，不必额外生成一套重复对白/BGM。

本轮依据至少可追溯到当前剧本版本、角色设定、全片声音基调、当前剧情位置及已选声音；已有作品引用实际来源，聊天试作标未建档。未知的语言/口音不从人物外貌、地域场景或年龄推断为确认设定，只补本步必要缺口；授权工作假设明确标注。

## 角色音色身份卡

每个需要稳定声音的角色关联一个独立声音身份，例如 `CHAR-001 → VOICE-001 v001`。卡由Codex依据当前设定整理，不要求用户重复填全套字段。

| 内容 | 应记录什么 |
|---|---|
| 关联与用途 | CHAR、VOICE、版本、对白/旁白/其他发声用途，采用的当前设定与确认来源 |
| 语言 | 主要语言，具体方言或地区口音，是否混语及何时混用；“中文”不足以替代普通话/粤语/四川话的选择 |
| 稳定声音身份 | 听感年龄、音高/音域倾向、音质、共鸣/气声、咬字、基础语速与节奏、可听辨识点；只写与角色有关且无冲突的特征 |
| 身份来源 | 文本设计的新音色、平台预设、真人原音分别登记；涉及真实声音时记录来源与允许用途 |
| 实际选用依据 | 完整样音/素材名、真实文件或平台节点、实际voice ID（确有时）、版本、用户选择/确认来源；未取得写待生成/待选择 |
| 复用范围 | 实际模型/入口、语言、跨句复用方式及已核验范围；不可用原始文件名冒充voice ID，不可把样音存在当后续模型支持引用 |

稳定身份与单句表演分开。哭泣、压低声音、激动、重音、停顿和呼吸属于每句变化，不能自动生成另一个声音身份。声音身份改变才升声音版本，并复查受影响对白、时长/口型及绑定；仅道具颜色改变而剧情/声音用途未变时保留现有声音。

每个角色交付以下三份可使用内容，内部ID和平台填写方式放在正文外：

1. **完整音色设计正文**：展开该角色语言、口音和稳定听感特征，无“同上”或依赖项目文件的简写。它描述可复用音色，不把整段戏的情绪当固定身份。
2. **独立试听文本**：自然可读，覆盖常见发音、长短句、转折/停顿及角色需要的表现；与音色描述分区，不把导演说明混作要读出的台词。实际时长、方言自然度和稳定性待用户试听确认。
3. **LibTV音频生成/选择卡**：按真实入口说明音色设计、平台预设选择、语音合成或参考音频路线；参数只写已核验支持项，未核验给待核验分支，不能编造字段或点击项。

## LibTV音频生成/选择卡

提示词或交接中引用上游命名素材时，按handoff展示规则加粗完整素材名；含引用的主稿使用可渲染Markdown，不把加粗藏在代码块内。声音卡、台词朗读文本和机器字段各按用途保留原值，实际名称/ID/路径不因展示改写。

生成卡用于用户在平台操作，与可复制正文分开。人物声音与音乐各按所用入口提供必要项，不用一张卡假装所有模型能力相同。

| 项目 | 填写与边界 |
|---|---|
| 任务与当前入口 | 音色设计/选择预设/语音合成/音乐生成，实际模型、版本、入口及核验日期；未核验不得给确定的按钮路径 |
| 输入怎么放 | 音色描述与试听台词若有独立字段分别填；只有单一字段时按该入口支持语法适配。参考音频给真实完整名称、用途与绑定位置，不能仅写“已上传” |
| 语言和设置 | 当前入口的语言/具体方言、音色选择/引用、时长及输出设置；只有实际支持时才写可点击选项，未支持则给真实替代路线或待确认项 |
| 生成与选择 | 本轮只做文字或已获准生成的范围；生成后用户在LibTV试听，反馈选定完整样音/音乐名、实际voice ID或真实节点（有哪个记哪个）、版本与可用范围 |
| 下游复用 | 下一句对白如何选同一声音，视频是否接受voice ID/声音参考或需独立配音及口型；音乐如何绑定Clip或进入剪辑。未核验不承诺连线会传递音色身份 |
| 待验收 | 发音、方言自然度、声线跨句稳定、真实时长/截断；音乐结构、旋律连续、对白可懂度；仅用户已反馈的范围可记用户确认 |

当前平台能力使用前依同版 `model-adaptation.md` 查可靠来源及当前入口。官方描述、账号可见、实际生成、试听选用、后续复用成功分别记录。无固定voice ID但有用户选定真实样音时，可以登记样音及待核验复用途径，不能阻断已授权文字设计，也不能称跨片已锁定。不得要求用户默认上传给Codex再复审。

## 每个需要BGM的Shot

先标每Shot的音乐关系：不配乐 / 新起 / 延续同段 / 变奏 / 收束。每个需要BGM的Shot均交一条完整专属提示词；专属表示剧情与时间目标明确，不等于每Shot另生成一首曲子。

每条BGM正文展开本条必须知道的事实：

- 全片音乐风格与当前Shot剧情作用，人物此刻的情绪及变化；有叙事理由的局部变化如何留在整体声音语言内。
- 乐器/音色、旋律与和声气质、速度或节奏密度，以及人声/歌词控制。明确纯器乐或需要的歌声；BPM、调性仅在有创作目的或平台设置需求时指定，不填装饰性数值。
- 本Shot计划可用时长、目标生成时长及剪辑余量，起乐、延续、发展/变奏、退出/收束和余音安排。目标精确秒数是计划，实际命中待生成后记录。
- 对白区间的音乐织体、音域及相对层次，让人声清楚；音量目标不是已完成混音。否定约束按实际平台能力放在独立约束区，正文优先用正面要求，如“纯器乐、稀疏织体、对白期间轻柔背景层”。
- 与前后段音乐的关系。正文展开所需主题与风格，不写“沿用上一条”来代替内容；真实BGM引用和素材区间在外部映射中登记。

持续音乐优先使用同一长段的连续区间，或先组织覆盖多个Shot的统一音乐段。仍逐Shot交完整提示词，说明该条是共享长段中的发展区间，实际生成任务可以合并为一条覆盖整段的音乐正文。现有素材直接使用时，Shot正文用于明确音乐需求，标“本轮复用，不执行新生成”。独立重生成/续作只有在当前模型支持且输入已满足时采用；相同文字、乐器或BPM不证明相同旋律。不能承诺逐Shot多次独立生成天然连续。

## Shot、Clip与真实资产映射

| 字段 | 记录要求 |
|---|---|
| Shot/Clip与时轴 | shot_id、clip_id、Clip内计划区间及声音触发事件；多Shot合一Clip时音乐共用连续时轴 |
| 声音/音乐身份 | VOICE或BGM ID + 版本、关联角色/剧情作用；没有正式作品ID的聊天试作明确为演示 |
| 音乐关系 | 新起/延续同段/变奏/收束；同一BGM段不要在每个Shot开头重置 |
| 实际输入 | 用户选定的完整素材名、实际文件/平台节点/voice ID及确认来源；没有就写待生成/待绑定，不制造媒体结果 |
| 使用区间与余量 | 计划源素材区间与实际可用区间分开；跨镜尾音只延续，不重复触发动作音。剪辑以真实音频长度及实际画面校准 |
| 消费路线 | 原生音频、音色/音频参考、后期对白、独立BGM及最终混音如何组合；避免两套对白/BGM叠加，口型仍按实际能力与播放确认 |

多Shot一Clip交一条连续音乐时间线；长Shot分Clip时标明跨Clip同段音乐及实际区间。后段沿用真实前段的出口，不能把原计划当实际结果。用户改结局时复查音乐落点与角色表演，改方言时复查声音身份、台词发音、时长/口型和引用，保留未受影响资产。

## 完整文字示例

以下是虚构演示，不是实测或默认偏好。短片《归还钥匙》采用温暖克制的写实风格；书店女店主需要普通话声音，当前Shot中她看清旧友递来的旧钥匙，由迟疑转为理解。所有媒体仍待用户在LibTV生成和选用。

**声音身份：** 演示 `CHAR-001 → VOICE-001 v001`；中文普通话、标准口音、不混语；约四十岁听感、中低音区、温暖沉稳、自然胸腔共鸣、轻微柔和气声、字头清晰、句尾平稳、基础语速从容。来源为本次虚构设定；实际样音与voice ID待选择。

**可复制音色设计正文：**

```text
为虚构角色“书店女店主”设计可在后续对白中重复使用的自然女声音色。主要语言为中文普通话，采用标准普通话口音，整句使用普通话。听感约四十岁，中低音区，声音温暖沉稳，胸腔共鸣自然，带轻微柔和气声。字头清晰，句尾平稳，基础语速从容，句间保留自然呼吸。听感亲切而克制，像在安静书店里与面前的人交谈。保持同一声音身份，具体情绪通过重音、停顿与气息变化表达。
```

**独立试听文本：**

```text
你找的那本书，我替你留着呢。先别急，坐下来慢慢说。原来……这把钥匙，一直在你这里。
```

**本例生成/选择卡：** 先核验用户LibTV当前音频入口；有音色设计与试听独立字段时分别粘贴上述两段，只有预设音色时选接近身份卡的候选并由用户试听。此次只交文字；选定后反馈真实完整样音名与入口实际提供的voice ID或节点，之后对白复用该选项。下一句低声或落泪只改表演字段。当前不宣称支持固定音色ID、特定口型路线或已锁定声音。

**演示Shot-001完整BGM正文：**

```text
为温暖克制的写实短片《归还钥匙》创作一段室内近景配乐。安静书店里，女店主看清旧友递来的旧钥匙，从迟疑转为理解，情绪变化细微而真实。以柔和钢琴单音和轻柔弦乐长音为主体，节奏稀疏，旋律短而留白，音色亲近自然，采用纯器乐。开头保持轻微悬而未决的感觉，中段随人物理解温和展开，末段落在安稳的和声上，保留自然余音。对白期间音乐维持轻柔背景层，织体和音域为人声留出空间。目标生成约12秒，供本镜选取约8秒并保留前后剪辑余量；这是本段音乐的新起，结尾余音连接下一镜。
```

**演示Shot-002完整BGM正文：**

```text
为温暖克制的写实短片《归还钥匙》安排书店对话的延续配乐。女店主理解旧友多年保存钥匙的心意，低声说“原来……这把钥匙，一直在你这里”，情绪由释然转为安静的感动。配乐属于同一段书店音乐的发展区间，以柔和钢琴单音和轻柔弦乐长音维持亲近自然的音色，短旋律留白、节奏稀疏、纯器乐。在前镜余音中平滑进入，人物停顿时让弦乐轻微展开，台词期间维持轻柔背景层与稀疏中音织体，句末自然延续到后镜。目标可用6秒，并为前后连接各保留约2秒制作余量；整段采用持续发展的同一音乐主题，末尾保留可接续余音。
```

**本例映射：** 两条正文均已展开各Shot的需求。实际制作优先统一生成一条覆盖两Shot与余量的长段音乐；本例计划共享 `BGM-001 v001`：Shot-001使用源音乐约2–10秒，Shot-002接用约10–16秒，计划长段约18秒。单Shot正文中的12秒/10秒是各自制作窗口目标，不代表要分别生成；合并正文以连续18秒的发展安排覆盖两个窗口。实际长度、选定节点及源区间待用户选用后回填。若当前模型无法满足时长，按真实能力调整生成/剪辑计划，不把两次独立生成宣称同曲连续。Clip合并两个Shot时音乐在切镜处继续；分为两个Clip时仍在剪辑中使用同一实际长段连续区间。

## 文字完成与媒体状态

文字自检核对：声音身份与表演分开；每需BGM Shot有完整正文及音乐关系；LibTV卡未虚构能力；Shot/Clip映射和素材名真实；最新剧情改变已传播，未影响声音的视觉局部修改不重做声音。只有文字完成可标文字范围通过，生成、试听、时长、跨句稳定、旋律延续、口型和最终混音分别保留实际状态。用户在LibTV确认选用的范围按用户反馈记录，不要求自动回传给Codex复审。
