# 我怎样调用创作总控

这是发给 Codex 的调用模板，用于识别任务和安排节点；不是发给图片或视频模型的生成正文。
不确定该用哪个 Skill，或要从现有资料接着做时，用这个入口。

## 最少告诉它什么

在 AIGC_Lab 内读取本项目同版本 Skill 源码和配套协议，不混用旧全局安装副本。

说清“想做什么”和“这轮先做到哪里”。已有作品就给作品目录或当前版本；新想法可只给一句话。
不需要自己选择全部节点、编资产 ID 或填写 Clip 映射。

## 短口令

> 帮我做这个视频，先把参考图、完整调度和 Clip 文字准备好。
>
> 接着这个作品往下做，先告诉我当前卡在哪里。

## 可复制调用模板

替换【】中的内容后发给 Codex；不清楚的项直接写“未定”，没有材料写“暂无”。

```text
请使用本项目源码中的 $aigc-creator。
我要做：【作品想法，或现有作品目录】
已有材料：【需求/脚本/参考图/调度/生成结果；提供正文或真实位置】
这轮先做到：【需求/脚本/参考图提示词/完整调度/Clip文字/复盘】
必须保留：【已经确定的人物、事件、台词、风格或结局】
计划规格：【画幅、总时长；未定可写未定】
制作路线：【参考图驱动/纯文生/未定】
保存方式：【保存到当前作品/只在聊天输出/不入公共库】
这轮只准备文字；缺关键资料时一次只问影响当前步骤的一项。
```

## 已填示例

```text
请使用本项目源码中的 $aigc-creator。
我要做：20秒写实短片，深夜维修工修好母亲留下的旧台灯。
已有材料：暂无，这是新作。
这轮先做到：整理需求，并指出下一步应该准备什么。
必须保留：只有一名成年维修工，灯亮之后只看着灯停住，结尾没有对白。
计划规格：16:9，20秒。
制作路线：参考图驱动。
保存方式：只在聊天输出。
这轮只准备文字；缺关键资料时一次只问影响当前步骤的一项。
```

## 会得到什么，怎样继续

会先辨认已有资料与当前阶段，再给这轮产物、必要假设/未知和下一步。
要继续可直接说“按刚才确认的内容写完整调度”；不必重新粘贴整套规则。
只做一个节点时，可以转用对应节点的模板，省去整链安排。

## 重要依赖

参考图驱动需要真实图片时，会先交图片提示词，依赖图片的 Clip 保留草案。
只准备文字不等于改走纯文生；生成、上传、费用和发布沿用已有明确授权。
平台未定仍能创作，专用输入格式和模型执行效果要另行核验。
执行细则见本包 [SKILL.md](../SKILL.md)。
