# 完整镜头调度：从故事到可执行画面

v001 · 2026-10-19。由 `aigc-blocking` 提供统一入口，内部协同 storyboard 与 audio；这里维护输出契约，节点不各复制六维规则。术语定义见 [镜头术语](shot-glossary.md)，表达条件见 [语言库](lexicon.md)。

## 用户入口与输出

“把这场戏写成完整镜头调度”即可调用。已有故事、角色、场景就直接消费；只追问会改变人物目的、场景关系或交付范围的缺口。用户不需要填写以下后台字段。局部空间未定可提出标注的工作方案，不能写成已确认事实。

交付顺序：一句话叙事目标 → 明确镜头数及理由 → 空间/轴线图 → 逐镜完整调度 → 相邻镜头接续 → Clip 编译交接。用户只问走位时裁剪到走位；不强迫完成一整套影片。

## 六维与证据

| 维度 | 必须落实 | 防止的错误 |
|---|---|---|
| 物理事实 | 明确主体数量、左右手、方向、可见范围、动作幅度；控制结果所需的距离/高度/时长用数字 | 不为“有数字”编造实测距离；草案数字是设计值 |
| 空间说明书 | 地标、角色/物体起止位置、距离、前中后景、遮挡、相机路径和可达性 | 场景左右、身体左右、画面左右混为一谈 |
| 台词嵌入 | 原话、说话者、画内/画外、起止节拍和与动作的关系 | 调度只写情绪，最后才补台词；擅改已确认对白 |
| 情绪链 | 诱因→呼吸/眼神/肌肉/手部/姿态变化→对方反应；写可观察的表演 | 只写“悲伤、愤怒、崩溃”；把所有人物写成同步反应 |
| 声画同拍设计 | 每个声音的来源、发生时刻、方向/距离、画内外及与动作的同步点 | 有画面没声源，或把声音设计完全拖到后期 |
| 节奏死数 | 镜头总时长、连续时间片、停顿、动作/对白密度、切点 | 秒数漏段/重叠、长台词挤进一秒；把目标秒数说成模型已实现 |

“声画同拍”是共同设计，不是所有模型原生输出音频的承诺。模型能力不支持时，保留完整声画计划并明确后期音轨/口型实施。实际生成后测量时间和同步，不把计划值回填为实际值。

## 每个 Shot 的必填内容

可用短段落或表格承载，但所有项目必须能定位。没有某层物体或独立音源时内部写“无/不适用及原因”，不为填表增加角色、道具或声音。发送正文再用正向描述表达实际画面。

1. **标识与功能**：Shot ID、场景、目标秒数、这一镜改变了什么信息，入口/出口。
2. **前景**：物体/人物、画面九宫格方位、距离层、清晰或虚焦、遮挡比例意图、对应声源或无独立声源。
3. **背景**：物体/空间、位置、距离层、虚实焦、环境/画外声音或无独立声源。
4. **主体**：具名角色/生物/物体、身份及本场衣装、具体姿态、视线、双手和持物；不入画但持续的关键状态另记。
5. **机位与相机运动**：场景位置、离地高度/主体相对高度、观察方向、水平朝向与俯仰角、路径起终点、速度变化；固定也是明确选择。
6. **景别与构图**：景别名称和具体裁切线、中心/三分等构图、焦点对象及转焦触发；裁切必须容纳关键动作。
7. **连续时间片**：每片写谁因何做什么、哪只手如何接触/释放、可见表情、原台词及声源、镜头如何响应。时间从本Shot的0秒到计划总时长，事件顺序必须可执行。
8. **光与节奏**：光源位置/类型/色调，切点为什么落在该处，如何与相邻镜头接动作、视线、光和声。

## 空间与动作处理

先画简单俯视图并标角色动线/相机动线/轴线；不知道的墙门方位不写成实际取证。数字只精确到叙事需要，设计“相距约1米”可比“1000.0毫米”更合理。动态过程中相机跨轴或人物换位时，重新推导画面左右。

道具交接必须有“发起者持有→双方接触→接收者握稳→发起者松手→分离”；坠落、起身、转身等也要有可见支撑、发力与结果。把大动作、背景表演和听者反应错开节拍。复杂镜头可有多个连续阶段，不能把“单一运镜”误读为全场只有一个动作。

台词原文包含“不、别、没有、no”等时，保留台词；这些是角色所说的话，不是对模型的负面指令。情绪词可以留在导演意图说明中，生成正文须有足够物理表现，不能只有标签。

## 编译前检查

- 逐镜六维及以上字段齐备，所有可见/可听的关键内容有表达位置。
- 源资料的台词、角色与事件未被转换步骤改写；推断与工作假设仍有标签。
- 时长相加正确，台词试读结果如未执行就如实注明；停顿不是靠省略号假定长度。
- 相邻镜头动作/视线/光/声音继承可追溯；真实结果优先于旧计划。
- 镜头数根据叙事决定，Clip 数根据能力和连续性决定。转交 [Clip 编译](clip-prompts.md)，保持所有源 Shot ID 与目标状态。

本规则可做文字行为检查；摄影、表演和声音效果需实际媒体验证。
