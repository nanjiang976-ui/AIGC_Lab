# 完整镜头调度：从故事到可执行画面

交付中的已有参考图、人声、BGM和实际前段素材引用，统一按handoff加粗完整名称并保持版本，供后续Clip在平台中准确@选择；机器字段保留原值。

v004 · 2026-10-21。由 `aigc-blocking`（场面调度） 提供统一入口，内部协同 storyboard 与 audio；这里维护输出契约，节点不各复制六维规则。术语定义见 [镜头术语](shot-glossary.md)，表达条件见 [语言库](lexicon.md)。

## 用户入口与输出

“把这场戏写成完整镜头调度”即可调用。已有故事、角色、场景就直接消费；只追问会改变人物目的、场景关系或交付范围的缺口。用户不需要填写以下后台字段。局部空间未定可提出标注的工作方案，不能写成已确认事实。

交付顺序：一句话叙事目标 → 明确镜头数及理由 → 空间/轴线图 → 逐镜完整调度 → 相邻镜头接续 → Clip 编译交接。用户只问走位时裁剪到走位；不强迫完成一整套影片。

完整调度先按[当前作品脉络](current-context.md)整理本轮有效的全片、场景和Shot依据，继承最新剧本、人物此刻知道什么/想做什么、视觉与声音风格、选定资产及相邻段实际状态。脉络卡留在交接说明中，逐镜正文展开本镜必须知道的内容；发现上游已改或摘要过期时先更新相关依据。仅走位请求只读取影响空间/动作的上下文，不扩成完整声音任务。

## 六维与证据

| 维度 | 必须落实 | 防止的错误 |
|---|---|---|
| 物理事实 | 明确主体数量、左右手、方向、可见范围、动作幅度；控制结果所需的距离/高度/时长用数字 | 不为“有数字”编造实测距离；草案数字是设计值 |
| 空间说明书 | 地标、角色/物体起止位置、距离、前中后景、遮挡、相机路径和可达性 | 场景左右、身体左右、画面左右混为一谈 |
| 台词嵌入 | 原话、说话者、画内/画外、起止节拍和与动作的关系 | 调度只写情绪，最后才补台词；擅改已确认对白 |
| 情绪链 | 诱因→呼吸/眼神/肌肉/手部/姿态变化→对方反应；写可观察的表演 | 只写“悲伤、愤怒、崩溃”；把所有人物写成同步反应 |
| 声画同拍设计 | 每个声音的来源、发生时刻、方向/距离、画内外及与动作的同步点 | 有画面没声源，或把声音设计完全拖到后期 |
| 节奏死数 | 镜头总时长、连续时间片、停顿、动作/对白密度、切点 | 秒数漏段/重叠、长台词挤进一秒；把目标秒数说成模型已实现 |

“声画同拍”是共同设计，不是所有模型原生输出音频的承诺。模型能力不支持时，保留完整声画计划并明确后期音轨/口型实施。实际生成后测量时间和同步，不把计划值回填为实际值。

## 每个 Shot 的必填内容

可用短段落或表格承载，但所有项目必须能定位。没有某层物体或独立音源时内部写“无/不适用及原因”，不为填表增加角色、道具或声音。发送正文再用正向描述表达实际画面。

1. **标识与功能**：Shot ID、场景、目标秒数、这一镜改变了什么信息，入口/出口。
2. **前景**：物体/人物、画面九宫格方位、距离层、清晰或虚焦、遮挡比例意图、对应声源或无独立声源。
3. **背景**：物体/空间、位置、距离层、虚实焦、环境/画外声音或无独立声源。
4. **主体**：具名角色/生物/物体、身份及本场衣装、具体姿态、视线、双手和持物；不入画但持续的关键状态另记。
5. **机位与相机运动**：场景位置、离地高度/主体相对高度、观察方向、水平朝向与俯仰角、路径起终点、速度变化；固定也是明确选择。
6. **景别与构图**：景别名称和具体裁切线、中心/三分等构图、焦点对象及转焦触发；裁切必须容纳关键动作。
7. **连续时间片**：每片写谁因何做什么、哪只手如何接触/释放、可见表情、原台词及声源、镜头如何响应。时间从本Shot的0秒到计划总时长，事件顺序必须可执行。
8. **光与节奏**：光源位置/类型/色调，切点为什么落在该处，如何与相邻镜头接动作、视线、光和声。
9. **声音与音乐交接**：对白的说话者、原文、VOICE引用及版本、单句表演和节拍；环境/拟音的来源与同步事件；本Shot配乐状态、叙事作用、完整BGM生成正文及前后关系。真实音频有完整素材名、选用状态和源区间，未生成则标计划与待绑定，不能用虚构voice ID补齐。

## 逐Shot声音与BGM

完整调度调用现有 `aigc-audio`（声音制作） 的逐Shot声音/BGM子能力，按[人物声音与Shot配乐](voice-and-music.md)执行并整合到本次调度，用户无需另开一次声音请求。沿用已选角色音色；稳定语言/方言和声线身份与本句情绪、重音、呼吸分开。没有需要固定声音的角色可注明音色不适用；没有配乐意图可明确本Shot不配乐。

每个需要配乐的Shot都交一条完整、自足、可复制的专属生成提示词，写出全片音乐风格约束、当前剧情与情绪变化、音乐的叙事作用、乐器/音色、旋律或和声气质、节奏密度、是否人声、计划时长及制作余量、进入/延续/变化/结束、对白避让和前后音乐关系。不能只写“温暖配乐”，也不能以“同上”代替正文。BPM和调性按真实创作意图或入口条件选择，不为填项编数。

提示词外另写本Shot是“不配乐 / 新起 / 延续同段 / 变奏 / 收束”，关联BGM及版本，并说明这是独立生成任务还是同一长音乐段中的发展区间。需连续配乐时优先统一生成足够长的段落，用户选定后用真实源区间映射到Shot/Clip；尚无音频时只给计划区间。每Shot专属正文不表示每Shot都要重新生成或重新起乐；多Shot合成一Clip时合并为一条连续音乐时间线，切镜处继承正在进行的音乐。工具续作能力未核验时，不承诺多次独立生成能延续同一旋律。

按用户选择的声音资产链先交音色、试听/BGM文本与生成/选择说明；视频入口原生有声音也不能省略本轮已要求的声音资产。Clip交接中区分 `samplevoice` 样音输入、独立对白、BGM与原生音轨的实际用途：当前入口支持什么才绑定什么，不能将样音节点自动当作可复用voice ID或口型驱动。逐层注明由哪一路承担、原生层保留什么、哪些层在后期替换，防止两份对白或BGM重复叠加；平台能力未知则保留待核验。

## 空间与动作处理

先画简单俯视图并标角色动线/相机动线/轴线；不知道的墙门方位不写成实际取证。数字只精确到叙事需要，设计“相距约1米”可比“1000.0毫米”更合理。动态过程中相机跨轴或人物换位时，重新推导画面左右。

道具交接必须有“发起者持有→双方接触→接收者握稳→发起者松手→分离”；坠落、起身、转身等也要有可见支撑、发力与结果。把大动作、背景表演和听者反应错开节拍。复杂镜头可有多个连续阶段，不能把“单一运镜”误读为全场只有一个动作。

台词原文包含“不、别、没有、no”等时，保留台词；这些是角色所说的话，不是对模型的负面指令。情绪词可以留在导演意图说明中，生成正文须有足够物理表现，不能只有标签。

## 编译前检查

- 逐镜六维及以上字段齐备，所有可见/可听的关键内容有表达位置。
- 源资料的台词、角色与事件未被转换步骤改写；推断与工作假设仍有标签。
- 时长相加正确，台词试读结果如未执行就如实注明；停顿不是靠省略号假定长度。
- 相邻镜头动作/视线/光/声音继承可追溯；真实结果优先于旧计划。
- 每个需配乐Shot都有完整正文、叙事与全片风格依据、音乐状态和引用版本；已选真实音频的区间与尚待生成的计划分开，多Shot一Clip不重复启动同一BGM。
- 镜头数根据叙事决定，Clip数根据能力和连续性决定。转交[Clip编译](clip-prompts.md#生成分组卡正文外)时，携带源Shot时段、必须保留的切点/连续观看意图、动作/对白难点、可独立重做需求和连续声音安排，供其交付生成分组卡。分组未批准或入口未知时保持建议身份；只做调度时不抢先编完整Clip正文。

本规则可做文字行为检查；摄影、表演和声音效果需实际媒体验证。
