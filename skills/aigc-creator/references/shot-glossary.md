## 调度与镜头

**调度**：为一场戏安排人物／物体在空间中的位置、动作、视线、交互，以及摄影机如何观察这些变化。本项目的“镜头调度文档”还把对白、声源、时长和切点写在相应动作旁，让接手者能够复现观众将看到和听到的过程。这是本项目交付范围，不能把行业里的所有 blocking 一律解释为六维模板。

**Shot／镜头**：一段连续呈现的画面；摄影机可以移动、转向、变焦或转焦。连续运镜中机位位置发生变化，仍可属于一个 Shot；不能把“一个机位”误解为相机必须始终停在同一坐标。切到另一段画面通常开启下一 Shot。

**Clip／生成片段**：本项目一次送给视频模型生成的素材单元，可含一个或多个 Shot；受入口能力和时长约束，一个长 Shot 也可能分成多个 Clip。Clip、Shot 与后期成片是不同层级，不能互相当编号同义词。具体时间映射和发送格式见配套 Clip 协议。

每镜先确认“观众何时知道什么”，再写 **相机、主体行动、画面**。前景、背景、机位、景别、台词与声音都服务这个信息变化，不为填表增加不存在的道具或音效。

## 景别

景别说的是画面取景范围，不能单靠相机距人物多少米决定。同样的距离换焦段会改变取景；相同裁切也能由不同距离／焦段组合实现。各语系与教材分级不完全一致，Adobe 的教学页也明确中景边界并非严格统一；**本项目以中文约定＋实际裁切线为最终判断**，英文词作检索标签，不逐字硬对齐。[Adobe：中景及其变体](https://www.adobe.com/creativecloud/video/hub/ideas/what-is-a-medium-shot-in-film.html)

| 本项目名称 | 裁切约定／可见范围 | 常见用途 | 写给模型时必须补什么 |
|---|---|---|---|
| 远景／大全景 | 环境为主，人物很小，完整环境关系可读 | 交代地点、距离与人与环境关系 | 主体在画面何处，哪些地标必须看清；需要时再注明“极远景” |
| 全景 | 人物头顶至脚底完整入画，保留足够落脚与动作空间 | 走位、全身动作、人物与近场环境 | 头脚完整、主要物件和行动路径 |
| 中景 | 通常从大腿上部／胯部附近到头顶；需要膝上范围时明写“膝上中景” | 肢体动作和人际关系 | 本镜究竟膝上、胯上还是其他裁切，手和道具是否完整 |
| 中近景 | 腰部以上至头顶 | 手部互动与面部反应兼顾 | 腰线、手部可见范围和关系背景 |
| 近景 | 胸口以上至头顶 | 表情、呼吸、肩部变化 | 胸口裁切、视线方向、主要焦点 |
| 特写 | 面部或一处局部成为主要画面，例如整张脸、握门把的手、戒指 | 强调一项信息或细节 | 特写对象、边界、清晰部位，不能只写“特写” |
| 大特写 | 更小范围，例如双眼、瞳孔、指尖纹理 | 极细反应或物件关键证据 | 哪一小块及可见细节，避免要求画外全身动作同时清楚 |
| 近景特写 | 不另设独立景别；旧稿或口语中的混合称呼 | 保留用户原词以便对照 | 后端必须解析为“近景（胸口以上）”或“面部特写”等明确范围；影响结果且仍歧义时补问 |

例：“中近景、腰部以上，右手与杯沿都在下半画面，双眼为焦点。”比单写 MCU 更容易跨节点检查。项目约定不是摄影学唯一标准；引用外部案例时保留其原名，另填本项目裁切解释。

## 机位

机位要拆成 **摄影机位置、高度、朝向／俯仰、主体关系**。角度与运动能够组合，例如低机位仰拍同时缓慢侧移，或正面平拍同时推近；“俯拍”与“侧拍”也可以同时成立。

| 维度／术语 | 含义 | 常见误解与写法 |
|---|---|---|
| 位置 | 相机在场景中的地点，以及与主体的距离 | 写“门内 1 米、人物右前方约 45°”；数值为设计值时注明，勿假装实测 |
| 平拍／眼平 | 相机与目标主要观察高度接近、视线大致水平 | 人物通常以眼部高度为基准，物体以目标结构为准；不是永远固定 1.6 米 |
| 俯拍／high angle | 从高于主体的位置向下观察 | 可表现空间关系或人物处境，具体情绪取决于上下文；高度与朝向需同时说明 |
| 仰拍／low angle | 从低于主体的位置向上观察 | 可突出高度、力量或局促，不能自动判“强大” |
| 正俯拍／top-down | 从目标上方接近垂直向下观察 | 与一般高机位微俯不同；不能同时保证人物正面五官清楚 |
| 正面拍摄 | 相机位于主体面对方向的一侧 | 主体转头后脸部正侧关系会变，须跟动作更新 |
| 正侧拍 | 从主体自身明确一侧观察，轮廓关系接近 90° | 写人物左侧或右侧；人物右侧不是画面右边 |
| 斜侧拍／3/4 view | 在正面与正侧之间观察 | 常用约 45°作为设计值；这是一个观察角度，不是三视图 |
| 背面拍摄 | 从主体背部一侧观察 | 看得到后脑和背部；若要看脸，需安排回头或机位变化 |
| 倾斜地平线／Dutch angle | 相机绕光轴滚转，画面水平线倾斜 | 不等于仰俯拍，也不等于 tilt 上下摇 |

摄影机高低角度、Dutch tilt 等名称可在 [Adobe Story 摄影术语附表](https://helpx.adobe.com/pdf/adobe_story_reference.pdf) 复核。本文方向拆分和数字写法是项目执行约定，不声明模型会严格执行角度值。

## 运镜

| 术语 | 物理变化 | 需要写出的起止与区别 |
|---|---|---|
| 固定镜头／locked-off | 相机位置和朝向在该时段保持不变 | 主体仍可动；是否变焦、转焦另说，不能同时笼统写“固定＋环绕” |
| 推／dolly in | 相机向主体靠近 | 起止距离或起止裁切、速度、触发点；靠近引起透视关系变化 |
| 拉／dolly out | 相机远离主体 | 拉开后揭示什么；后退路径是否可通行 |
| 摇／pan、tilt | 相机基点不移动，朝向改变 | pan 是水平转向；tilt 是垂直仰俯转向，分别写起点和终点 |
| 移／truck | 相机在空间中侧向平移 | 左移或右移相对于当前摄影机／场景哪一套坐标；前后景会产生视差 |
| 跟／follow、tracking | 相机随运动主体移动，以维持或改变相对关系 | 前跟、后跟、侧跟以及距离变化；“跟”不限定某一种器材 |
| 升／降／pedestal、crane | 摄影机高度发生变化 | 写从多高到多高、是否同时转向；升降不是单纯抬低镜头朝向 |
| 环绕／arc、orbit | 相机沿主体周围弧线路径改变观察方向 | 顺／逆方向、起止方位、弧度和距离；终点左右关系重新检查 |
| 手持／handheld | 由持机产生的细小或明显运动特征 | 写幅度和节奏；“呼吸感”须具体到轻微不规则摆动，不拿晃动掩盖关键动作 |
| 变焦／zoom | 改变镜头焦距与视野，相机可保持原位 | 与物理推进不同；要推近就写相机位移，不能只写 zoom |
| 滑动变焦／dolly zoom | 相机前后移动与反向变焦配合 | 主体尺寸可接近不变、背景比例关系改变；仅故事需要且入口有能力时使用 |

运动定义和镜头术语参见 [Adobe 摄影术语附表](https://helpx.adobe.com/pdf/adobe_story_reference.pdf)；跟随与器材的区别见 [Adobe：Tracking shot](https://www.adobe.com/creativecloud/video/production/cinematography/camera-shots-and-angles/tracking-shot.html)，推移与变焦的组合见 [Adobe：Dolly zoom](https://www.adobe.com/creativecloud/video/production/cinematography/camera-shots-and-angles/dolly-zoom-shot.html)。

## 焦点与构图

| 术语 | 定义 | 写调度时的落点 |
|---|---|---|
| 景深 | 沿距离方向看起来可接受清晰的范围 | 浅景深突出有限距离层，深景深保留多层信息；不要把“景深”当成前后物体实际距离的同义词 |
| 实焦／虚焦 | 某对象在当前焦点范围内清楚，或失焦模糊 | 指明谁清晰、谁模糊；前景不必总虚、背景不必总虚 |
| 转焦／rack focus | 清晰焦点从一个距离层转到另一层 | 写从杯子到后方人物双眼、由哪个动作触发；不是摄影机位移 |
| 前景／主体层／背景 | 相对于当前摄影机的深度层次 | 写对象、画面方位、遮挡、清晰度；移动后层次可变 |
| 中心构图 | 主要关注点安排在画面中心附近 | 可用在人脸、对称空间或核心动作；不自动等于庄重 |
| 三分构图／rule of thirds | 用横纵三等分辅助安排重点 | 写人物或双眼位于哪条线／交点附近，不只贴术语标签 |
| 框架构图／frame within frame | 场景中的门窗等结构围合主体 | 框来自真实场景，避免为了构图凭空加窗 |
| 对角线构图 | 主要线条或行动方向沿对角线展开 | 指明从哪一角到哪一角；画面斜线不等于相机滚转 |
| 留白／负空间 | 主体之外保留的相对空区域 | 指明方向、面积关系和叙事用途；不是把画面忘记描述 |
| 视线空间 | 主体望向方向保留的构图空间 | 视线须对应场景里具体的人／物；反打后核对 |

景深与光圈关系的基础说明见 [Nikon：What is aperture](https://www.nikon.co.uk/en_GB/learn-and-explore/magazine/tips-and-tricks/what-is-aperture)。景深还受其他拍摄条件影响；只写某个 f 值不能保证 AI 生成对应虚实关系，发送正文应写出可见结果。

## 剪辑与声音

**正反打**是相互关联的观察方向之间的切换，可表现说话者、听者反应或人物所看的物件。它不是“A说话只能拍A，B说话只能拍B”的机械规则。**越肩正反打**在观察另一人物时保留前方人物的肩／头部作为空间线索，要写清哪侧肩、谁清晰和视线方向。[Adobe：Shot-reverse shot](https://www.adobe.com/creativecloud/video/production/cinematography/camera-shots-and-angles/reverse-shot.html)

| 术语 | 含义 | 检查重点 |
|---|---|---|
| 轴线／180°关系 | 用人物互动或运动方向建立空间参照，连续镜头据此保持方向可读 | 不是不能越轴；有意越轴需交代方向改变并承担观众重新定位的代价 |
| 切点 | 从当前镜头转入下一镜头的具体时刻 | 依据动作、信息、情绪或声音变化；写切前／切后状态 |
| 动作接切 | 在动作过程中切换视角，同时保持动作连续可理解 | 同手、同方向、同动作阶段，避免抓起后又回到未抓起 |
| 反应镜头 | 展示人物对事件或话语的可见反应 | 可以在他人仍说话时切过去，避免用旁白代替本来该可见的反应 |
| J-cut／声音先入 | 下一段声音先到，画面稍后切换 | 下一声源可以先在画外；编辑入点和生成音轨要求分开 |
| L-cut／声音延续 | 前一段声音跨过画面切点继续 | 不等于视频重叠或自动延长镜头 |
| 音画错峰／反应错峰 | 画面、声音或不同人物动作不同时起落 | 标清谁先、谁后、相差多久及目的；本项目统称，不能全等同 J/L cut |
| 场内声／画外声 | 声源属于故事空间；是否在画面中可见另计 | 门外人声仍可属于场内声，写声源方向与隔门音色 |
| BGM／非场内音乐 | 作为叙事配乐加入，通常不是人物环境中的可见声源 | 指明有无、进入与退去时机；不让背景音乐盖对白 |

J/L 的声音先后定义核验于 [Adobe：J cuts and L cuts](https://www.adobe.com/uk/creativecloud/video/discover/j-cut-and-l-cut.html)。轴线、切点和错峰在本项目拉片中记录观测与推断，不能仅凭成片倒推拍摄者的真实意图。

## 时间、色彩与光线

| 术语 | 定义与边界 | 写法 |
|---|---|---|
| 帧率／fps | 每秒图像帧数；生成、剪辑和播放可有不同设置 | 写输出要求并核对实际文件，24fps 不是“自动电影感”的保证 |
| 动态模糊／motion blur | 曝光期间运动在图像上形成的模糊痕迹 | 与曝光时间和相对运动相关；快速运动清晰边缘或自然拖影需明确选择 |
| 时间切片 | 本项目调度中给动作／台词分配的起止时段 | 精确秒数是计划目标；检查对白、停顿和运动能否完成，实际生成另测 |
| 色彩基调 | 主导色相、饱和度、明暗与色温关系 | 写暖白顶灯、冷色窗光、肤色和暗部保留规则；避免只写“高级色调” |
| 柔光／soft light | 阴影边缘过渡较柔和的照明 | 写光源方位和柔化方式；不是“完全没有阴影” |
| 硬光／hard light | 阴影边界较清晰的照明 | 写直射来源与照到的位置；不能与同一主光“全柔光”并列 |
| 环境光／ambient light | 场景中的整体基础照明与周围光贡献 | 写来源和强弱，不能用泛称抹掉已确定主光方向 |
| 实景灯／practical light | 场景中作为陈设、可能入镜的灯具，如台灯、壁灯 | 入镜与实际照明贡献分别说明；不等于“现实中的所有光源”或自动禁止补光 |
| 主光／key、补光／fill | 主要塑形照明，以及影响阴影细节的补充照明 | 主光方向、软硬与明暗关系；补光不必来自另一盏可见灯 |
| 低调／高调照明 | 整体暗部占比、亮度与对比的组织方式 | 低调仍须看清必要动作；高调不等于高曝光溢出 |

快门与运动模糊的区别可核对 [Canon 视频机说明书：Shutter speed guidelines](https://files.canon-europe.com/files/soft33582/Manual/HG20_HG21_IB_ENG.pdf)；柔硬光与主补光基础见 [ARRI Lighting Handbook](https://www.arri.com/resource/blob/83996/409091c612f371b0c68b41d9dcb636db/arri-lighting-handbook-english-data.pdf)。这些资料支持拍摄术语，不证明 AI 平台支持相同摄影参数。

## 复习方法

每次选一段 10—20 秒的已获使用许可素材，手动完成三题即可，不需要为复习建立定时任务：

1. 遮住术语名，只说画面裁到哪里、谁清楚、谁在前后，再对照景别和景深。
2. 判断变化来自相机位置、朝向、焦距还是焦点；若多项同时改变，分别标出。
3. 写出一个切点的“切前观众知道什么／切后增加什么”，再检查声音是否先行或延续。

五组必分清：**推近／变焦，横移／水平摇，升降／上下摇，前后空间／虚实焦，角色身体左右／画面左右**。复习后把术语翻译回可见动作和几何关系，检查原镜头，而不以背出名词作为通过。
