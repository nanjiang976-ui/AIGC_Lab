# 参考图制作：角色或场景

用户可以说“给这位短发维修工做角色参考图”“把这张人物图整理成四格”或“做夜间便利店的场景参考图”。后端选择预设、展开规范并检查依赖；用户不用记四格顺序、锚定语法或资产编号。

## 入口与依赖

- 已明确完整 AIGC_Lab 工作区时，验证项目契约并读取该根 `skills/aigc-creator/references/handoff.md`、`reference-assets.md`；脱离项目再定位同版本总控，检查 metadata 的 bundle 与 bundle_version。缺配套文件时报告，不混接旧全局副本。
- **先确定资产类型**：角色参考图（人物／生物／物体）或场景参考图。用户自然语言已足够判断时直接声明类型；“帮我做参考图”而主体不明时只补问类型和主体，不先猜图。
- “转换这张人物图”进入旧图标准化；“创建角色”进入新建预设。仅准备提示词时不生成媒体。逐镜首帧是后续入口按模型选择的分支，交 `aigc-keyframes`，身份联系板不冒充首帧。
- 读取已确认设定、镜头用途、实际参考文件与状态；只补影响本步的缺口。未选平台可交完整通用文字，参考绑定、原生分辨率和生成就绪状态待适配核验。

## 本节点的选择规则

1. **新建人物**：柔光棚拍，中性自然表情，干净纯色背景；9:16 竖版、4K 输出目标，等分 2×2 四格为正面、明确侧面、背面、身份局部细节。完整规范由 `reference-assets.md` 维护。
2. **旧人物图转标准四格**：脸部正面／脸部侧面／全身正面／全身背面。保留原图可见身份、体态、衣装、鞋和不对称细节，改用柔光。原图未展示的背面不能标“精确保留”；先说明未知，用授权补全方案或补参考，不虚构已确认设计。
3. **物体或生物型角色**：沿用清晰多视角与一致结构原则，把人物面部字段换成轮廓、结构、标记或物种特征；禁止给物体套用“眼睛鼻子”。主体为商品时保留真实结构与商标证据，不自动拟人化。
4. **场景**：总览、反方向与关键细节，先固定地标、门窗、主要物件、尺寸关系与光源。需要四格时用总览／反方向／侧向布局／关键细节；场景不是人物棚拍，不搬入人物表情与服装要求。
5. 本轮用户明确的其他版式／材质／设计锁定优先。若与已确认的硬规范冲突，先指出具体冲突并询问取舍，不暗改成另一套预设。旧作品保留历史，不批量重制。

## 产出与检查

- 给一份可直接复制的完整图片正文；正文外注明类型、预设、上传素材与用途、目标尺寸、实际入口及待核验项。正文不留模板括号、“同上”或虚构文件引用。
- 四格是一个图文件，不是四张独立图片。确需拆图或入口仅接单人图时，按已授权路线裁切或分别生成，再逐图检查；不声称整板一定被模型理解。
- 资产记录固定 ID、版本、用途、稳定身份特征、衣装记录、文字候选／待生成／已审实际图、真实文件和目视检查证据。图片未查看不能标已审，只有文字不得填写实际像素。
- 人物验收检查四格同一身份、同衣装、体态比例、左右侧别、头脚入画和关键细节可读。柔光、中性表情、干净背景及无可见图像噪点属于人物参考规范；禁止以美颜或抹去五官来追求整洁。
- 交给 Clip 的人物参考**默认只锁面部结构、五官、发型**；明确选定的痣、眼镜等身份特征可加入范围。**Clip 服装在文字中逐条独立定义**，不从参考图默认继承。参考制作阶段保留原衣装与 Clip 阶段重新指定衣装并不冲突。
- 失败时定位身份、角度、衣装、布局或输入限制，只修受影响面；保留已审母版。文字通过不代表图像一致或视频可用。

## 交接完成标准

类型与预设明确；图片正文完整；不变项和未见部分分开；生成参数未冒充已验证能力；真实文件绑定存在才登记；身份与衣装分开交给调度和 Clip。下游只使用经检查的真实图或清楚标明的待生成依赖。

## 行为演练入口

- “角色参考图：成年女性维修工，黑色齐耳短发，人物右脸一颗痣，灰色工装。先只给提示词。”检查新建四格、左右侧别和中性表情。
- “把这张旧人物图转成标准四格，后面视频让他换白衬衫。”检查转换时保留图中衣装，Clip 单独定义白衬衫；没收到图片时不伪造身份。
- “场景参考图：门在北墙、窗在西墙、东侧货架的便利店，反打也要用。”检查反方向布局和空间比例，不套人物棚拍。
- “给这个铜制机械猫做角色参考图，锁住背部铆钉结构。”检查结构锚定，不强塞人物面部要求。
