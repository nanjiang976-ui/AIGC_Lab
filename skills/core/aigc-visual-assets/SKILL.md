# aigc-visual-assets（参考图资产）

个人调用时可直接用 [提示词模板与使用方法](references/usage.md)：短口令、可复制调用模板和已填示例；这些是发给 Codex 的请求，不是生成模型正文。

每次面向用户交付的最后一段，读取同版本总控 `references/handoff.md` 的“面向用户的结尾衔接”，加粗提示下一节点、携带本轮哪些成果及继续口令；缺项按实际依赖选择补齐或草案续接，当前范围结束则明确停止。

作品素材与成片的观看验收按同版总控 `references/handoff.md` 的“用户媒体验收与反馈”执行：用户在LibTV观看确认，Codex负责文字自检及按反馈修改。

用户可以说“给这位短发维修工做角色参考图”“把这张人物图整理成四格”“给开门用的铜钥匙单独做道具图”或“做夜间便利店的场景参考图”。后端选择预设、展开规范并检查依赖；用户不用记四格顺序、锚定语法或资产编号。

## 入口与依赖

- 已明确完整 AIGC_Lab 工作区时，验证项目契约并读取该根 `skills/aigc-creator/references/handoff.md`、`reference-assets.md`；脱离项目再定位同版本总控，检查 metadata 的 bundle 与 bundle_version。缺配套文件时报告，不混接旧全局副本。
- **先确定资产类型**：人物、生物或物体型角色、道具、场景。一次请求包含多类资产时逐项识别；用户自然语言已足够判断时直接声明类型，“帮我做参考图”而主体不明时只补问类型和主体，不先猜图。
- “转换这张人物图”进入旧图标准化；“创建角色”进入新建预设。仅准备提示词时不生成媒体。逐镜首帧是后续入口按模型选择的分支，交 `aigc-keyframes`（静态关键帧），身份联系板不冒充首帧。
- 读取已确认设定、镜头用途、实际参考文件与状态；只补影响本步的缺口。未选平台可交完整通用文字，参考绑定、原生分辨率和生成就绪状态待适配核验。

## 本节点的选择规则

1. **新建人物**：按用户样图采用接近 3:4 竖版、2×2 等分四格：左上正面头肩／胸像、右上 3/4 转侧胸像、左下背面全身、右下正面略 3/4 全身；柔光、自然中性表情、干净浅灰背景，同人同衣装。4K 为输出目标，入口能力待核验；样图仅供版式、视角与光线参考，不复制示例人物身份。完整规范由 `reference-assets.md` 维护。
2. **旧人物图转标准四格**：与新建采用同一视图顺序和版式；右上 3/4 转侧胸像不是 90°纯侧脸，下排背面／略 3/4 正面全身同尺度、头脚完整。保留原图可见身份、体态、衣装、鞋和不对称细节，改用柔光。原图未展示的背面不能标“精确保留”；先说明未知，用授权补全方案或补参考，不虚构已确认设计。
3. **物体或生物型角色**：沿用清晰多视角与一致结构原则，把人物面部字段换成轮廓、结构、标记或物种特征；禁止给物体套用“眼睛鼻子”。主体为商品时保留真实结构与商标证据，不自动拟人化。
4. **道具**：剧情重要道具或用户点名需要单独出图的道具，**必须各交一份独立参考图提示词**；出现在角色手中或场景细节格里不能代替该交付。锁定结构、材质、标记、比例和作用状态，不套人物脸部或服装规则。每件只做一张单视角图，选择清楚的 3/4 角度或最能说明功能的视角，同图展示完整轮廓与关键结构，不拼四宫格、多角度或细节窗；普通背景装饰不默认逐件出图。细则见 `reference-assets.md`。
5. **场景**：总览、反方向与关键细节，先固定地标、门窗、主要物件、尺寸关系与光源。需要四格时用总览／反方向／侧向布局／关键细节；场景不是人物棚拍，不搬入人物表情与服装要求。
6. 本轮用户明确的其他版式／材质／设计锁定优先。若与已确认的硬规范冲突，先指出具体冲突并询问取舍，不暗改成另一套预设。本次人物统一四格与道具单张规则取代旧预设；旧已完成作品和成熟提示词原文保留历史，不覆盖或批量重制。

## 产出与检查

- 逐项交付本轮所需资产的独立、完整图片正文；每份标题和正文都使用完整、易识别的资产名称，不只写“道具”“它”或内部 ID。正文外注明类型、视图方案、上传素材与用途、目标尺寸、实际入口及待核验项。正文不留模板括号、“同上”或虚构文件引用。
- 转换或派生图片引用已有命名素材时，按handoff使用可渲染Markdown并加粗完整素材名；新建且没有上游引用的正文仍可代码块。展示加粗不修改资产登记名称、路径、版本或实际标签。
- 人物四格是一个图文件，不是四张独立图片；道具每件一张单视角图，不套四格。人物可保留 FRONT／3/4 VIEW／BACK／3/4 FRONT 小标签，需检查准确可读，不能接受乱码；必要时后期加字。确需拆图或入口仅接单人图时，按已授权路线裁切或分别生成，再逐图检查；不声称整板一定被模型理解。
- 资产记录固定 ID、版本、完整名称、用途、适用的不变项与状态、文字候选／待生成／用户确认可用、真实文件或平台标签，以及用户确认来源。人物另记身份和衣装；道具另记结构与作用状态。用户在 LibTV 确认可用后可继续下游，不要求回传 Codex 复审；用户未反馈不代填已验收，只有文字不得填写实际像素。
- 人物验收检查四格同一身份、同衣装、体态比例和左右侧别；上排胸像尺度相近、3/4 转侧明确，下排全身同尺度且头脚完整，关键细节可读。柔光、中性表情、干净背景及无可见图像噪点属于人物参考规范；禁止以美颜或抹去五官来追求整洁。
- 交给 Clip 的人物参考**默认只锁面部结构、五官、发型**；明确选定的痣、眼镜等身份特征可加入范围。**Clip 服装在文字中逐条独立定义**，不从参考图默认继承。参考制作阶段保留原衣装与 Clip 阶段重新指定衣装并不冲突。
- 失败时定位身份、角度、衣装、布局或输入限制，只修受影响面；保留已审母版。文字通过不代表图像一致或视频可用。

## 交接完成标准

类型与视图方案明确；所需资产逐项有完整正文、完整名称和用途，重要或点名单独出图的道具没有漏项；不变项和未见部分分开；生成参数未冒充已验证能力；真实文件绑定存在才登记；人物身份与衣装分开、道具结构与作用状态分开交给调度和 Clip。下游使用用户已确认的真实素材，或清楚标明的待生成／待绑定依赖；结尾说明携带哪些资产进入下一步。

## 行为演练入口

- “角色参考图：成年女性维修工，黑色齐耳短发，人物右脸一颗痣，灰色工装。先只给提示词。”检查新建四格顺序、接近 3:4 版式、3/4 而非 90°侧脸、左右侧别和中性表情。
- “把这张旧人物图转成标准四格，后面视频让他换白衬衫。”检查转换时保留图中衣装，Clip 单独定义白衬衫；没收到图片时不伪造身份。
- “场景参考图：门在北墙、窗在西墙、东侧货架的便利店，反打也要用。”检查反方向布局和空间比例，不套人物棚拍。
- “给这个铜制机械猫做角色参考图，锁住背部铆钉结构。”检查结构锚定，不强塞人物面部要求。
- “维修工用缺一枚齿的黄铜钥匙打开控制柜，钥匙是识破冒充者的线索；桌上普通纸杯作背景。给角色、道具和修理室参考图提示词。”检查黄铜钥匙独立正文、单张单视角而非拼版、完整轮廓及关键结构可见、用途明确，纸杯不自动扩成独立任务。
