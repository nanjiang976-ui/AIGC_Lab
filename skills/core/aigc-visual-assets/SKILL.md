# 角色、场景与道具资产

建立能被镜头实际使用的视觉身份与空间比例。文字设定、生成候选与已审实际参考图分别登记。

## 入口与依赖

- 用户明确指定完整 AIGC_Lab 工作区时，验证根目录项目契约及共享文件存在，优先用该根的 `skills/aigc-creator/references`。脱离项目时再从当前包的安装根或 `aigc-creator` 元数据定位同版本总控；缺文件则报告，禁止混用旧全局副本或猜路径。检查当前 Skill 与总控 metadata 的 bundle、bundle_version 相同。
- 读取定位后的 `handoff.md`；准备平台输入时读 `model-adaptation.md`。
- 本节点产出资产描述、各视角图片正文和检查要求；逐镜首帧交 `aigc-keyframes`。
- 用户只要文字时不调用出图；既有角色已定时只补缺角度或错误部位。
- 主流程的文字资产交付包含身份/结构规范和所需角色、场景、道具的图片提示词；只列外观表不等于完成参考图提示词。暂无实际图时交自足的候选正文与待生成清单，选定母版后再按已核验能力派生视角；已有适用资产复用，用户只要规范或其他单节点时按其范围裁剪。

## 最小输入与缺项

需要已确认设定或授权草案、资产将出现的镜头、参考素材状态。
没有真实参考图时交付自足的文字候选，不写“沿用上传脸型”或捏造文件路径。
已有图但无法查看时保留用户报告并标“未目视检查”；不能宣称五官与衣装已锁定。
未选平台可交通用正文；是否支持多图、身份绑定、分镜板须按当前入口另核验。

## 制作方法

1. 提取稳定身份：脸/发型、体态、服装结构、材质色彩、非对称细节；动作和当前泪痕属于镜头状态，勿写成永久身份。
2. 对每件资产写用途：人脸身份、全身比例、衣装、空间布局、道具结构；不同用途不互相替代。
3. 根据镜头补角度，而非固定出满套图。角色背面出现就需背面；只拍脸部不必默认制作鞋底。
4. 先定义“视图”含义，再选独立图片或联系板；两种都可交，但不要把联系板冒充独立图文件。
5. 先选择一个稳定身份候选，再基于经核验的参考输入方式派生其他视角；无参考输入能力时重复完整描述并注明一致性需人工筛选。
6. 检查同人、同衣、同尺寸、同非对称细节；某一面错误则局部重做该面，不让错误整板继续成为身份真值。

## 三/四视图与交付分支

| 定义 | 摄影机相对人物的位置 | 使用条件 |
|---|---|---|
| 正面 | 面向人物胸前，双眼可见 | 脸部、衣襟与前口袋 |
| 人物右侧面 | 摄影机在人物身体右侧，看到右耳与右衣侧 | 右袋、右侧徽记；不是“画面右侧” |
| 背面 | 摄影机面对背部 | 后发型、衣背、背包 |
| 人物左侧面 | 摄影机在人物身体左侧 | 左右不对称或动作将用此侧 |

三视图通常为正面、一个明确侧面、背面；四视图补另一侧，若用户指正面/四分之三/侧面/背面则沿用并写清角度。
**独立图路线**：每个角度一个完整代码块，重复必要身份与衣装；不用“同上、转90度”代替自足描述。
**联系板路线**：一张图排多视角，用位置说明各格；出图后逐格检查，再按实际需要裁切并登记，文字标签不作为生成可靠性的前提。
模型不能稳定生成联系板时改独立图；下游只接受单图时不得直接提交整板假装角色单人首帧。
非对称口袋、疤痕、文字、表盘、接缝应补该侧或局部；不能靠水平翻转造另一个角度。

## 场景与道具

- 场景先定地标、门窗与主要物件相对位置，再给至少一个可读布局的宽景；反打需要补反方向，非必需时不强做四向。
- 用已知实物建立比例，如桌面约到站立人物腰部、门高与人高关系；数值无来源时标设计尺寸，不冒充实测。
- 道具记录外形、数量、大小、开合/承重/接触结构；戒指须与手指和口袋相容，抽象“金属物”不够。
- 检查服装是否允许剧情动作：右口袋开口与外套翻转方向、拉链是否闭合、物件能否按设计滑出。
- 资产光线宜让结构清楚；戏剧光线另由场景/首帧承担，避免参考图阴影遮掉关键结构。

## 已填短例

对象：成年女性，齐肩黑直发、灰衬衫、深灰外套；仅人物右侧有红色缝线补丁。采用三张独立图，补右袋局部。

正面正文：
```text
成年女性的正面全身角色参考图，齐肩黑色直发，平静表情，双臂自然垂下。灰色有领衬衫外穿敞开的深灰髋长外套，黑色直筒长裤和平底鞋。外套人物右侧口袋有红色缝线补丁，左侧口袋为纯深灰。纯浅灰背景，均匀中性柔光，头顶到鞋底完整入画，保持自然身体比例。
```

右侧面正文：
```text
成年女性的人物右侧面全身角色参考图，摄影机从她身体右侧观察，右耳和外套右侧清楚可见。齐肩黑色直发，平静表情，灰色有领衬衫外穿敞开的深灰髋长外套，黑色直筒长裤和平底鞋。右侧开放口袋的红色缝线补丁完整可见，双臂自然垂下且不遮住口袋。纯浅灰背景，均匀中性柔光，头顶到鞋底完整入画。
```

背面正文：
```text
成年女性的背面全身角色参考图，摄影机正对背部，齐肩黑色直发覆盖后颈。灰色有领衬衫外穿敞开的深灰髋长外套，外套背部为完整纯深灰面料，黑色直筒长裤和平底鞋。红色缝线补丁只在人物右侧口袋，不延伸到后背。双臂自然垂下，纯浅灰背景，均匀中性柔光，头顶到鞋底完整入画。
```

以上是文字候选，未生成同一身份；选定面孔后再按实际平台绑定。局部右袋图需看清开口、补丁与灰袖口，不必包含整张脸。
若采用联系板，则同一横向图左格正面、中格右侧面、右格背面，保持上述衣装、比例与补丁侧别；应交付完整合并正文，不只发送这句说明。

## 输出与验收

- 资产表：固定 ID、用途、关键不变量、视角、设计比例、状态、真实文件与版本（存在才填）。
- 每个所需视角的完整图片代码块；上传映射与设置在外，角色 ID 不进入模型正文。
- 逐项核对侧别、结构与镜头需要；未实际出图时仅标文字检查，不能锁定视觉一致性。
- 交给调度/首帧的是真实可用资产或明确待生成任务，不能混淆。

## 演练请求

- 正常：“已定角色为灰衬衫女性，右口袋有红补丁；给独立三视图提示词，另要厨房和戒指的比例参考。”观察角度与非对称细节。
- 边界：“三视图联系板的侧面换脸了，右袋补丁跑到左边；别重设人物，只修出错视角。”观察局部修复、参考用途和未实测边界。
