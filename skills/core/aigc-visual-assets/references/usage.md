# 我怎样做参考图

这是发给 Codex 的调用模板；Codex 会另交可复制到图片模型的完整正文。
先说“角色参考图”或“场景参考图”；旧图转四格时直接说“转换这张人物图”。

## 最少告诉它什么

在 AIGC_Lab 内读取本项目同版本 Skill 源码和配套协议，不混用旧全局安装副本。

新建角色给主体身份与关键外观；场景给地标布局与光线；转换旧图要提供实际图片。
人物四格规范由后台补齐，你不需要背版式或锚定语法。

## 短口令

> 角色参考图：成年短发维修工，右脸一颗痣，灰色工装，只给提示词。
>
> 场景参考图：北墙有门、西墙有窗的小修理室，要能支持反打。

## 可复制调用模板

替换【】中的内容；附件必须实际提供，没有就写“暂无”。

```text
请使用本项目源码中的 $aigc-visual-assets。
类型与操作：【新建角色参考图/转换旧人物图/场景参考图】
主体或空间：【人物外观、物体结构，或场景地标与光源】
必须锁定：【身份特征、不对称标记、结构或布局】
已有图片：【实际附件/真实路径/暂无】
参考用途：【后续身份锚定/场景布局与风格；需要另作首帧时说明】
图片平台：【已选平台与入口/未定】
保存方式：【当前作品/仅聊天/不入公共库】
这轮只给图片提示词与上传说明；依赖实际图片的转换未收到图时先指出缺口。
```

## 已填示例

```text
请使用本项目源码中的 $aigc-visual-assets。
类型与操作：新建角色参考图。
主体或空间：32岁中国男性维修工，黑色齐耳短发，略方的脸，普通体态，穿灰色棉质工装与黑色平底鞋。
必须锁定：人物身体右侧脸颊靠近颧骨的一颗小痣，发际线和脸部比例保持一致。
已有图片：暂无。
参考用途：后续身份锚定；视频衣装由每条Clip另行定义。
图片平台：未定。
保存方式：仅聊天。
这轮只给图片提示词与上传说明；依赖实际图片的转换未收到图时先指出缺口。
```

## 会得到什么，怎样继续

得到资产类型、适用预设、完整图片正文，以及尺寸目标、上传用途和待核验项。
人物新建用正/侧/背/细节；旧图转换用脸正/脸侧/全身正/全身背，转换时保留原衣装。
实际出图后发回图片，可继续说“检查四格是否能做身份锚定”。
场景图会检查总览、反方向和细节的空间关系，独立于人物棚拍规范。

## 重要依赖

9:16/4K是人物输出目标，平台实际能力要核验；文字不会让实际图自动达标。
参考人物图默认锁面部、五官、发型；选择的痣、眼镜等可明确加入，Clip衣装独立定义。
旧图未见背面保留未知；身份联系板不能冒充视频第一帧。
详细规则见 [SKILL.md](../SKILL.md)。
