# 我怎样写完整镜头调度

这是发给 Codex 的调用模板，用来设计整场戏的摄影、动作和声音；不是视频模型正文。
说清故事与空间后，后台会协同分镜和声音，不用你手填六维规则。

## 最少告诉它什么

在 AIGC_Lab 内读取本项目同版本 Skill 源码和配套协议，不混用旧全局安装副本。

给事件顺序、人物/物件起点、场景地标和结尾状态。
空间还没定可允许提出带标记的方案；已经锁定的左右关系要明确保留。

## 短口令

> 把这场戏写成完整镜头调度，台词和声音一起写进去。
>
> 只解决这次递杯和相机侧移的走位，别重写剧情。

## 可复制调用模板

替换【】内容；“画面左/右”和“人物自己的左/右”尽量说清。

```text
请使用本项目源码中的 $aigc-blocking。
本场事件：【按先后说明谁做什么，或给脚本真实路径】
人物与道具起点：【站坐、朝向、持物、衣装】
场景布局：【门窗、桌椅等地标；未定可授权提出方案】
结尾要到：【人物、物件与信息终态】
台词与声音限制：【逐字台词、必须保留的声源、安静段】
目标时长与禁改项：【计划总秒数、必须保留的复杂动作】
已有实际前段：【真实素材/用户报告/暂无】
保存方式：【当前作品/仅聊天/不入公共库】
只交完整调度文字；给明确镜头数与理由，补齐空间、表演、声音、计划节拍和相邻衔接。
```

## 已填示例

```text
请使用本项目源码中的 $aigc-blocking。
本场事件：A把热杯交给B，确认B接稳后，A绕桌走到门边，停步回头。
人物与道具起点：A站在桌西侧，右手握杯把；B站桌东侧，双手空。A穿灰衬衫，B穿米白开衫。
场景布局：北墙有窗，中央一张1.2米宽桌；门在西墙靠南处。摄影机从南侧向北拍，起始画面A左B右。
结尾要到：B双手独持杯，A站门边双手空，两人相互看着。
台词与声音限制：A递出时说“小心烫”，杯交接与衣料声可听；没有配乐。
目标时长与禁改项：计划10秒，必须看清交接；相机可以侧移，但不能穿过桌子。
已有实际前段：暂无，这是首场设计。
保存方式：仅聊天。
只交完整调度文字；给明确镜头数与理由，补齐空间、表演、声音、计划节拍和相邻衔接。
```

## 会得到什么，怎样继续

得到完整逐镜调度、空间依据、动作接触链、台词/音效、计划时间和入口/出口/切点。
下一步说“把这份调度转成 Clip”；编号和时间映射由后台维护。
局部走位请求只交必要部分，不强制重做整片。

## 重要依赖

续接实际结果要看真实末帧/片段，只有用户报告时只继承报告中的已知状态。
精确时间是调度目标，生成后还要检查动作、声音和切点是否命中。
完整职责见 [SKILL.md](../SKILL.md)。
