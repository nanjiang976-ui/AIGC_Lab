# 我怎样设计分镜

这是发给 Codex 的调用模板；用来决定看几镜、每镜看什么和怎样切。
已有完整调度只需转 Clip 时，不必再单独重做分镜。

## 最少告诉它什么

在 AIGC_Lab 内读取本项目同版本 Skill 源码和配套协议，不混用旧全局安装副本。

给故事/信息节拍、总时长、固定角色关系与起止状态。
说“镜头数由你定”即可；后台会说明数量和理由，不默认套固定镜数。

## 短口令

> 把这段脚本设计成分镜，给镜头数、理由和前后衔接。
>
> 只改第三镜的观看方式，保留台词和结局。

## 可复制调用模板

替换【】内容；已有资料可给真实路径与当前版本。

```text
请使用本项目源码中的 $aigc-storyboard。
脚本或事件：【正文/真实文件与版本】
总时长与画幅：【计划秒数、横竖屏】
人物与空间限制：【站坐、左右、地标、持物与不可变项】
本轮要做：【首轮分镜/改指定镜头/检查切点与连续性】
观看重点：【观众先知道什么、最后看到什么】
镜头数：【由你建议/已有数量与理由】
已有实际结果：【真实材料/用户报告/暂无】
保存方式：【当前作品/仅聊天/不入公共库】
只设计文字；逐镜写相机、主体行为、画面层次、计划时长、入口出口与切点。
```

## 已填示例

```text
请使用本项目源码中的 $aigc-storyboard。
脚本或事件：A追问“戒指呢？”，B答“不是我”；A说“只有你碰过”，B吸气说“你为什么不信我？”，抿唇后一滴泪滑下，低头。
总时长与画幅：18秒，16:9。
人物与空间限制：绿色厨房，桌在两人之间；A在桌西侧站着，B在东侧坐着；摄影机保持桌南侧观察。A穿灰外套，B穿米色开衫。
本轮要做：首轮分镜。
观看重点：先建立争执关系，后把观看中心留给B的解释和反应。
镜头数：由你建议并解释。
已有实际结果：暂无，尚未生成。
保存方式：仅聊天。
只设计文字；逐镜写相机、主体行为、画面层次、计划时长、入口出口与切点。
```

## 会得到什么，怎样继续

得到镜头数与观看理由、逐镜三要素、张力变化、计划时间和相邻连接说明。
需要完整导演调度可说“把这些分镜补成完整调度”；已完整则进入 Clip 节点。
镜头与一次生成片段分开计数，长镜跨生成段不会自动变成叙事切镜。

## 重要依赖

对白时间需试读；平台片段上限未知不阻止先设计，但单次生成可行性待核验。
需要看见的手、道具接触点必须与景别裁切相容；实际前段状态优先于旧计划。
规范见 [SKILL.md](../SKILL.md)。
