# aigc-keyframes（静态关键帧）

个人调用时可直接用 [提示词模板与使用方法](references/usage.md)：短口令、可复制调用模板和已填示例；这些是发给 Codex 的请求，不是生成模型正文。

每次面向用户交付的最后一段，读取同版本总控 `references/handoff.md` 的“面向用户的结尾衔接”，加粗提示下一节点、携带本轮哪些成果及继续口令；缺项按实际依赖选择补齐或草案续接，当前范围结束则明确停止。

作品素材与成片的观看验收按同版总控 `references/handoff.md` 的“用户媒体验收与反馈”执行：用户在LibTV观看确认，Codex负责文字自检及按反馈修改。

从完整镜头中截出一个确定瞬间；动态过程保留给视频节点，不能压进一张图片。

## 入口与依赖

- 用户明确指定完整 AIGC_Lab 工作区时，验证根目录项目契约及共享文件存在，优先用该根的 `skills/aigc-creator/references`。脱离项目时再从当前包的安装根或 `aigc-creator`（全链路创作总控） 元数据定位同版本总控；缺文件则报告，禁止混用旧全局副本或猜路径。检查当前 Skill 与总控 metadata 的 bundle、bundle_version 相同。
- 读取定位后的 `handoff.md`、`model-adaptation.md`；裁切与接触可见性按 `prompt-language.md` 的对应小节检查，复杂连续镜头按需读 `screenshot-analysis.md` 的截图3。
- 本节点产出图片正文和静态检查；全段动作、原生声音及生成任务由对应节点处理。

## 最小输入与缺项

需要镜头的目标瞬间、身份/衣装/场景资产、计划或真实起始状态、构图。
用户要求沿用真实末帧时，必须拿到该图或明确的已核验状态；只有文字报告时只能完成已知部分，未知处不能补成事实。
未选平台仍可交自足图片正文，参考输入能力和生成效果未验证。
首帧为按入口选择的后端分支：身份/场景参考模式可直接进入Clip，首帧/首尾帧入口或明确端点控制才调用本节点。所有路线仍有完整静态起点设计。需要首帧但没有真实图时，完成自足静态候选，另列待生成/审图/绑定依赖，不把候选冒充已审首帧；不能因为缺图擅自改变已选择的输入路线。
静态输入未满足的图生视频正文只作草案，不进入已就绪发送批次。

## 制作方法

1. 识别本图是首帧、过程关键状态还是末帧，写清对应镜头和动作阶段；不要把三个时刻拼成一图。
2. 将截图3式混合稿拆为首帧状态、动作节拍、运镜路径、声音、终态五槽，只把目标瞬间写入图片。
3. 保留主体身份、具体姿势、朝向、视线、双手、接触、持物、泪痕与衣装；未来动作不提前完成。
4. 用景别、机位、层次、位置和光源确定观看方式；按实际身体/场景高度核对必见对象、接触点与裁切边界，区分入画内容和画外持续状态。文字已确定不相容时先退回分镜修正，不把矛盾首帧交给生成碰运气。
5. 检查动作可启动：抓杯前手尚未抓稳，起身前支撑点可用，落物前物件还在容器；有运动暗示的首帧须与动态相容。
6. 参考用途逐项分开：身份参考不自动控制姿势，场景参考不替代脸，联系板不自动等于单一首帧。
7. 正文先写关键主体、状态与硬约束，再补支持画面；此为编排原则，不作跨模型位置权重保证。
8. 若从真实末帧改构图，区分原图直接输入、编辑/重建候选与已审新图；重建图须重新对照身份、手、光和物件。

## 首帧输入分支

| 实际入口 | 本节点交接 |
|---|---|
| 支持首帧且有合格真实图 | 登记真实文件和用途，交视频节点写变化 |
| 只支持身份/风格参考 | 图作其明确用途；视频仍需描述起始构图，不能称锁定第一帧 |
| 只有文字输入 | 图片仅作创作参考；向视频节点交完整静态描述，不要求输入图片 |
| 必须沿用首帧但工具不支持 | 列出换用已核验图生视频路线或改成可剪辑文生视频镜头的选择，不能暗换工具与成本 |

“不支持首帧”不能被“先重建一张再传进去”解决。换工具是独立路线，不是同一入口新增能力。

## 已填短例

任务：从“B躺着说话后撑地起身，相机由俯拍移到侧面”提取首帧。
选定瞬间：B仰卧、尚未撑地；本例为自足文字候选，没有参考图。

```text
一名穿米色针织开衫、白色内搭和深棕长裤的成年女性仰卧在浅灰地毯上，齐肩黑色直发散在头部两侧。双膝轻屈，双手自然放在腹部，眼睛望向画面上方，嘴唇轻合，表情平静。摄影机从她身体上方俯拍全身，头在画面上方、脚朝画面下方，右侧留出一片空地。柔和窗光从画面左侧照入，头部、双手和脚均清楚可见。画面停留在她尚未撑地起身的时刻。
```

动态交接：之后的对白、左右手移向地面的顺序、支撑起身与相机下降侧移另交视频节点，原复杂动作未删。
静态检查：全身是否真的入画；两手是否仍在腹部；是否提前坐起；右侧空地是否足够后续机位/人物使用。

## 输出

- 每张图的目的、来源版本、计划/实际状态与后续用途。
- 一图一个完整主稿；引用上游参考图/实际末帧时按handoff用可渲染Markdown并加粗完整素材名，无素材引用时可用单个代码块。文件、镜头ID、上传/设置和检查说明放主稿之外，机器路径和标签保持原值。
- 已有素材的真实映射；未生成图明确标待生成，正文不含占位或假附件。
- 静态审查清单及下一镜继承状态；若图片失败，不把它作为已锁定首帧继续生产。

## 验收

- 图片只描述一个时刻，动态过程完整保留在交接中。
- 姿势、接触、构图与动作起点相容；计划与真实状态没有混写。
- 平台输入路径可执行；纯文字工具没有被要求接收重建图片。
- 图片文字通过、实际图通过、视频连续性通过分别记，不能相互替代。

## 演练请求

- 正常：“把俯拍仰卧、说话、撑地起身、镜头降到侧面的长镜头稿，提取静态首帧。”观察只取一刻并保存动态。
- 边界：“上一镜B实际站着，我要续接；当前工具只有文字输入，没有看过末帧。”观察未知状态、文生分支与不得伪称首帧可用。
