# aigc-keyframes（静态关键帧）｜调用模板与使用方法

这是发给 Codex 的调用模板；Codex 会另交静态图片生成正文。
需要一个确定瞬间、首尾帧入口，或根据真实结果重建关键状态时使用。

## 最少告诉它什么

在 AIGC_Lab 内读取本项目同版本 Skill 源码和配套协议，不混用旧全局安装副本。

给目标瞬间、主体身份/衣装、姿势与构图。
续接上段时提供真实末帧；尚无图片可写静态候选，不会被当成已审首帧。

## 短口令

> 从这段调度提取首帧，只写动作开始前那个瞬间。
>
> 按这张真实末帧设计下一镜的起点。

## 可复制调用模板

替换【】内容；图片来源只能写已提供的附件或真实路径。

```text
请使用本项目源码中的 $aigc-keyframes。
目标：【首帧/指定中间状态/末帧/修订已有图】
所属镜头与目标瞬间：【调度内容，以及静止在何时】
主体和场景：【身份、衣装、空间、双手与持物等已知状态】
画幅与构图：【裁切、机位、画面方位、光源；未定可建议】
已有真实图：【附件/真实路径及用途/暂无】
后续动态：【下一步发生什么，用来检查起点是否可启动】
平台输入方式：【首帧/首尾帧/仅身份参考/纯文字/未定】
保存方式：【当前作品/仅聊天/不入公共库】
本轮只给静态图片提示词；一个图写一个时刻，动态过程另交接，未知状态不当事实。
```

## 已填示例

```text
请使用本项目源码中的 $aigc-keyframes。
目标：首帧文字候选。
所属镜头与目标瞬间：成年女性先仰卧在地毯上，之后要说话、撑地起身；首帧取尚未撑地的瞬间。
主体和场景：黑色齐肩直发，米色开衫、白色内搭、深棕长裤；浅灰地毯，双膝轻屈，双手在腹部，嘴唇轻合。
画幅与构图：16:9，身体上方俯拍全身，头在上脚在下，人物右侧留空地；柔光从画面左侧照入。
已有真实图：暂无。
后续动态：说话后双手按地，支撑起身；相机下降至侧面。
平台输入方式：未定。
保存方式：仅聊天。
本轮只给静态图片提示词；一个图写一个时刻，动态过程另交接，未知状态不当事实。
```

## 会得到什么，怎样继续

得到目标瞬间、完整静态图片正文、构图/接触检查及后续动态交接。
真实图生成并检查后，再交视频节点写变化；图片尚缺时视频图生版保留草案。
如果入口只接身份参考，后台不会让四格人物板冒充第一帧。

## 重要依赖

不是每镜都要额外生成首帧；先按实际模型入口判断。
只有文字输入的平台，重建图片也不会新增上传首帧能力。
静态候选通过、实际图通过与视频连续性分别记录，见 [SKILL.md](../SKILL.md)。
