# 我怎样准备人物声音、Shot配乐和对白

这是发给 Codex 的调用模板，用来准备角色音色、逐Shot BGM正文、声音表演、试读和同步；不是配音模型正文。实际交付会把可复制正文、试听文本、平台生成/选择卡分开。
对白还未生成时也能先做计划，不必等剪辑结束才发现时长不够。

## 最少告诉它什么

在 AIGC_Lab 内读取本项目同版本 Skill 源码和配套协议，不混用旧全局安装副本。

给逐字台词、说话者、镜头时长和动作发生顺序。
有实际音频或视频就提供文件；没有时只做文本估时和声音设计。
仅做人物声音设计时，先用已确认角色设定、主要语言、具体方言/地区口音、是否混语和声音用途，不必先准备完整对白；已有选定样音可提供完整名称与真实节点/voice ID（有哪个给哪个）。声音身份不能只从外貌猜。
做Shot配乐时沿用当前剧本、全片风格、每Shot剧情/情绪与时长，说明不配乐、新起、延续、变奏或收束；Codex从当前资料整理，不要求你重填所有来源。

## 短口令

> 给这场戏安排对白、呼吸、环境音和动作音，检查时间够不够。
>
> 这段嘴部清楚可见，帮我确定真实可行的声音和口型路线。
>
> 先给这两个角色做音色设计、独立试听文本和LibTV生成/选择卡，后续同一角色继续用同一选定声音。
>
> 给每个需配乐Shot写完整BGM提示词，展开当前剧情情绪和整片风格；连续音乐共用同一段素材，列Shot/Clip使用区间。

## 人物音色的可复制调用

```text
请使用本项目源码中的 $aigc-audio，沿用本聊天最新剧本和角色决定，先做人物声音文字资产。
角色与语言：【角色、主要语言、普通话或具体方言/口音、是否混语；已有设定可直接引用】
已有声音选择：【完整样音名、真实平台音色ID/节点及用户选用状态；暂无则写暂无】
本轮交付：每位需要固定声音的角色各给CHAR→VOICE版本身份卡、完整可复制音色设计正文、独立试听文本、LibTV音频生成/选择卡。
稳定音色与每句情绪表演分开；未选实际样音不称声音已锁定，未核验入口不编造字段或能力。
先交文字，不调用媒体生成；保存方式：【当前作品/仅聊天/不入公共库】。
```

## 每Shot BGM的可复制调用

```text
请使用本项目源码中的 $aigc-audio，沿用最新剧本、完整调度和全片声音基调。
Shot范围与剧情：【当前段落/Shot；已有正文可直接引用】
配乐选择：【哪些不用、哪些新起/延续同段/变奏/收束；未定可给带理由的工作方案】
已有音乐：【真实素材完整名称、可用区间和授权/用户选用状态；暂无】
每个需要BGM的Shot各给完整可复制专属提示词，写全当前剧情和人物情绪、整片风格、乐器/人声控制、计划时长与余量、对白避让及进入/延续/收束。
连续Shot优先共用同一长段，列Shot/Clip和BGM资产及计划/实际区间映射；逐Shot正文不等于逐Shot换曲，不承诺未核验的音乐延续能力。
另给LibTV音乐生成/选择卡；素材未生成标待生成/待绑定。本轮只交文字；保存方式：【当前作品/仅聊天/不入公共库】。
```

## 已填示例

```text
请使用本项目源码中的 $aigc-audio。
逐字台词与说话者：B低声说“你为什么不信我？”，逐字锁定。
画面与动作节拍：7秒近景，B先抬眼吸气，再说话，抿唇后第一滴泪滑下，最后低头；A在画外。
表演意图：B努力解释，最后几个字声音轻颤，保留说完后的呼吸和反应。
已有声音或视频：暂无。
声音路线：未定，先比较原生对白和独立配音后口型的依赖。
音乐与授权状态：只做方向；本段先留环境底噪，不选音乐文件。
本轮要做：文字声音表和试读安排。
保存方式：仅聊天。
先做文字设计；未听音频不填实际时长，未播放不判口型通过，不调用配音或媒体生成。
```

## 会得到什么，怎样继续

得到逐字声音脚本、表演说明、事件同步表、计划/估时区分和试读要求。
要求人物声音时，另得到稳定身份卡、音色设计正文、独立试听文本和LibTV音频生成/选择卡；要求配乐时，每个需BGM Shot各有完整正文及音乐连续关系、Shot/Clip资产映射。只做图片、没有对白或明确不用配乐时，按实际范围标不适用。
用户要求先做声音资产时，不会因后续视频原生带声音而省略本步；实际生成仍按已有授权。用户在LibTV选定后，可反馈完整样音/音乐名、实际voice ID或节点与可用范围，后续复用该选择，哭泣或低声只改每句表演。
用户在LibTV试听后反馈实际时长、停顿及具体问题，可以继续说“按这些时长和问题调整镜头节拍”；无需回传音频复审。
用户在LibTV观看试听实际画面与声音，反馈发音、停顿、口型和动作音问题，Codex按反馈修改方案。

## 重要依赖

给嘴部可见画面贴配音不等于完成口型；需要已核验的原生语音或口型流程。
单次接触音只触发一次，尾音跨镜不等于再次发生动作。
声音文件和音乐授权要真实，详细方法见 [SKILL.md](../SKILL.md)。
仅文字描述声线不是实际声音锁定；同曲跨Shot优先使用真实长段的连续区间。平台字段、语言/方言、音色复用、语音驱动口型及音乐延续能力须按当前入口核验。
