# aigc-audio（声音制作）｜调用模板与使用方法

这是发给 Codex 的调用模板，用来准备角色音色、逐Shot BGM正文、声音表演、试读和同步；不是配音模型正文。实际交付会把可复制正文、试听文本、平台生成/选择卡分开。
对白还未生成时也能先做计划，不必等剪辑结束才发现时长不够。

## 最少告诉它什么

在 AIGC_Lab 内读取本项目同版本 Skill 源码和配套协议，不混用旧全局安装副本。

给逐字台词、说话者、镜头时长和动作发生顺序；词和标点默认一起锁定。
有实际音频或视频就提供文件；没有时只做文本估时和声音设计。
仅做人物声音设计时，Codex依据当前剧本和角色设定整理职业身份、性别、年龄、音高、声音质地、发声特点，再为主要角色设计可听辨识的声音；不要求你手填全卡，缺项标待确认或授权工作假设。职业和性别不机械决定声线；主要语言、具体方言/地区口音、是否混语和声音用途单独记录，不能从职业或外貌推断。无剧本也能先做音色设计；有剧本优先取原剧本1句试听，必要时2句。
已有选定样音可提供完整名称、说话者、源区间和用途，以及真实节点/voice ID（确有哪个记哪个）；样音用于声音身份参考，不冒充完整对白或voice ID。
做Shot配乐时沿用当前剧本、全片风格、每Shot剧情/情绪与时长，说明不配乐、新起、延续、变奏或收束；Codex从当前资料整理，不要求你重填所有来源。

## 短口令

> 给这场戏安排对白、呼吸、环境音和动作音，检查时间够不够。
>
> 这段嘴部清楚可见，帮我确定真实可行的声音和口型路线。
>
> 依据当前剧本给主要角色做音色设计、原剧本试听文本和声音参考制作/复用卡，后续同一角色继续用同一选定样音；每句另写语气、节奏和身体/发声状态。
>
> 给每个需配乐Shot写完整BGM提示词，展开当前剧情情绪和整片风格；连续音乐共用同一段素材，列Shot/Clip使用区间。

## 人物音色的可复制调用

```text
请使用本项目源码中的 $aigc-audio，沿用本聊天最新剧本和角色决定，先做人物声音文字资产。
角色依据：【当前剧本/已确认角色设定；Codex从中整理职业身份、性别、年龄、音高、声音质地、发声特点，不要求我手填全卡】
语言与用途：【主要语言、普通话或具体方言/口音、是否混语、声音用途；未知项标待确认或授权工作假设，不从职业/外貌推断】
已有声音选择：【完整样音名、说话者、源区间、用途、用户选用状态；真实平台音色ID/节点确有时才记，暂无则写暂无】
参考制作方法：【从已有LibTV视频手动提取人声/先在音频平台制作选样/未定，按下述两种方法交接】
本轮交付：每位需要固定声音的角色各给CHAR→VOICE版本身份卡、完整可复制音色设计正文、独立试听文本、声音参考制作/复用卡；有剧本优先原剧本1句，必要2句，无剧本照常设计。
稳定音色与每句情绪表演分开；多人声音有可听辨识，职业和性别不机械决定声线。逐句另写语气、节奏、身体/发声状态、重音、停顿、动作触发和完整表演说明。
原词与标点默认锁定；表演说明与朗读文本分区，不擅加重复字；明确允许改标点时才给单独对照，不凭标点承诺秒数。未选实际样音不称声音已锁定，未核验入口不编造字段或能力。
先交文字，不调用媒体生成；保存方式：【当前作品/仅聊天/不入公共库】。
```

两种声音参考方法按实际资料选择：

- **方法1：从已有视频提取。** 用户手动在LibTV视频节点进入“音频分离”中的“人声提取”，取得声音参考音频。这是2026-10-21用户提供的操作路径，本轮未做UI核验。登记真实完整样音名、说话者、源区间和用途，再按各视频节点的实际入口手动引用；尚无合适视频时标待生成。
- **方法2：先制作并选样。** Codex交完整音色设计提示词与原剧本试听台词，用户在音频平台制作、试听选样，再手动将同一声音参考喂给该角色的每个视频节点；登记同样的真实样音信息。样音是身份参考，后续完整对白仍需逐句给出；未知入口保留待核验，不保证接入或跨节点声线稳定。

两种方法都由用户确认试听与实际复用效果。引用已有样音、图像、BGM或前段素材时，每次以可渲染Markdown加粗完整素材名；含引用的唯一完整主稿放在代码块外，实际ID/路径保持原值。未知素材标建议或待生成，加粗不能代替实际绑定。

## 每Shot BGM的可复制调用

```text
请使用本项目源码中的 $aigc-audio，沿用最新剧本、完整调度和全片声音基调。
Shot范围与剧情：【当前段落/Shot；已有正文可直接引用】
配乐选择：【哪些不用、哪些新起/延续同段/变奏/收束；未定可给带理由的工作方案】
已有音乐：【真实素材完整名称、可用区间和授权/用户选用状态；暂无】
每个需要BGM的Shot各给完整可复制专属提示词，写全当前剧情和人物情绪、整片风格、乐器/人声控制、计划时长与余量、对白避让及进入/延续/收束。
连续Shot优先共用同一长段，列Shot/Clip和BGM资产及计划/实际区间映射；逐Shot正文不等于逐Shot换曲，不承诺未核验的音乐延续能力。
另给LibTV音乐生成/选择卡；素材未生成标待生成/待绑定。本轮只交文字；保存方式：【当前作品/仅聊天/不入公共库】。
```

## 已填示例

```text
请使用本项目源码中的 $aigc-audio。
逐字台词与说话者：B低声说“你为什么不信我？”，原词与问号锁定，不加重复字，不改标点。
画面与动作节拍：7秒近景，B先抬眼吸气，再说话，抿唇后第一滴泪滑下，最后低头；A在画外。
角色音色：本例未提供职业、性别和年龄，不替B编造确认设定；请从当前角色资料整理六项音色依据，缺项标待确认。主要语言与具体口音单独核对，不从职业或外貌推断。
朗读文本：你为什么不信我？
表演说明：B想让A相信自己。抬眼后短吸气触发开口；语气从努力解释走向委屈，节奏先稳后慢，身体尽力克制，呼气支撑减弱但字音仍清楚；重音落在“信我”，句内停顿按自然试读决定，最后几个字轻颤，保留说完后的呼吸和反应。这些说明不读入台词。
已有声音或视频：暂无。先走方法2，交完整音色设计提示词，并只用上述原剧本1句试听；我在音频平台制作选样后，手动将同一声音参考送入每个实际支持的相关视频节点，再补真实样音名、说话者、源区间和用途。若改用方法1，再按用户提供的LibTV路径手动提取人声。
声音路线：未定，先比较原生对白和独立配音后口型的依赖。
音乐与授权状态：只做方向；本段先留环境底噪，不选音乐文件。
本轮要做：音色设计、文字声音表和试读安排；7秒是画面计划，台词实际时长待试听，不凭问号、停顿标记保证命中秒数。
保存方式：仅聊天。
先做文字设计；未听音频不填实际时长，未播放不判口型通过，不调用配音或媒体生成。
```

## 会得到什么，怎样继续

得到逐字声音脚本、表演说明、事件同步表、计划/估时区分和试读要求。
要求人物声音时，另得到稳定身份卡、音色设计正文、独立试听文本和LibTV音频生成/选择卡；要求配乐时，每个需BGM Shot各有完整正文及音乐连续关系、Shot/Clip资产映射。只做图片、没有对白或明确不用配乐时，按实际范围标不适用。
用户要求先做声音资产时，不会因后续视频原生带声音而省略本步；实际生成仍按已有授权。用户选定后，可反馈完整样音/音乐名、实际voice ID或节点与可用范围；声音参考另记说话者、源区间和用途，确无voice ID时不编造。后续复用该选择，哭泣或低声只改每句表演；声音参考不代替后续完整对白。
用户在LibTV试听后反馈实际时长、停顿及具体问题，可以继续说“按这些时长和问题调整镜头节拍”；无需回传音频复审。
用户在LibTV观看试听实际画面与声音，反馈发音、停顿、口型和动作音问题，Codex按反馈修改方案。

## 重要依赖

给嘴部可见画面贴配音不等于完成口型；需要已核验的原生语音或口型流程。
单次接触音只触发一次，尾音跨镜不等于再次发生动作。
声音文件和音乐授权要真实，详细方法见 [SKILL.md](../SKILL.md)。
仅文字描述声线不是实际声音锁定；同曲跨Shot优先使用真实长段的连续区间。平台字段、语言/方言、音色复用、语音驱动口型及音乐延续能力须按当前入口核验。
