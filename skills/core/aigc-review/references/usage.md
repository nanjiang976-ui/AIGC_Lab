# 我怎样审查资料或成片

这是发给 Codex 的调用模板，用来找可修复的问题，并指出该回哪个节点。
可以只审文本、图片或单段；审查范围由你指定，不自动重写整片。

## 最少告诉它什么

在 AIGC_Lab 内读取本项目同版本 Skill 源码和配套协议，不混用旧全局安装副本。

给本轮目标、待审对象与当前版本。
文字、截图、真实图、视频和整片各自只能支持相应范围的结论。

## 短口令

> 审查这份文字包，找会影响生成的问题，给最小改法。
>
> 检查这几段的实际衔接，逐条给证据和修复节点。

## 可复制调用模板

替换【】内容；没有提供的媒体请直接写“未提供”。

```text
请使用本项目源码中的 $aigc-review。
目标与不可改项：【原创作目标、固定台词/身份/结局等】
待审对象与版本：【正文/真实路径/附件】
已有证据：【文本、实际图片、可播放片段、音轨或整片】
本轮只检查：【文字完整性/静态图/动作连续/声音口型/整片节奏等】
前段真实状态：【已查看素材/用户报告的具体状态/未知】
需要的输出：【问题、影响、主责节点、最小修复和复查证据】
保存方式：【当前作品/仅聊天/不入公共库】
先报告可检查范围；这轮只审查，不生成媒体或自动重写。未看/未听的范围标未执行。
```

## 已填示例

```text
请使用本项目源码中的 $aigc-review。
目标与不可改项：两人对话连续，人物B在第2镜站起后下一镜保持站姿。
待审对象与版本：待审文字v001：“第3镜，B坐在椅子上低头，A站在桌西侧看她。”
已有证据：只有上述文字；我报告第2镜实际结果中B已经站起，未提供视频。
本轮只检查：下一镜文字是否与已报告状态冲突。
前段真实状态：用户报告B站起；手势、泪痕、机位与光线未知。
需要的输出：问题、影响、主责节点、最小修复和复查证据。
保存方式：仅聊天。
先报告可检查范围；这轮只审查，不生成媒体或自动重写。未看/未听的范围标未执行。
```

## 会得到什么，怎样继续

得到对象/证据范围、已见错误/待验证风险/审美建议，以及每项最小修复和复查条件。
示例可定位文本与用户报告的冲突，不会把实际媒体连续性判为通过。
要执行修复，再说“按第一项最小方案改第三镜”；无关镜头继续保留。

## 重要依赖

首帧截图不能证明全段动作、声音或口型；旧结果不能为新版本签字。
提示词改完只支持文字复查，媒体缺陷是否消失仍要检查新结果。
证据和分层审查规范见 [SKILL.md](../SKILL.md)。
