# aigc-editing（剪辑时间轴）｜调用模板与使用方法

这是发给 Codex 的调用模板，用来选段、算片长、连接声画；不是视频生成提示词。
只有分镜时写剪辑计划；有真实片段时再确定实际入出点和可用切点。

## 最少告诉它什么

在 AIGC_Lab 内读取本项目同版本 Skill 源码和配套协议，不混用旧全局安装副本。

给目标片长、素材实际长度/可用区间，以及必须保住的动作与对白。
有文件就提供真实路径；只有计划数据也能先核算，但不会宣称已看过素材。

## 短口令

> 把这些 Clip 排成剪辑计划，算清净片长和声音衔接。
>
> 按这些真实入出点检查时长，别把音轨跨切算成画面重叠。

## 可复制调用模板

替换【】内容；素材尚未生成时明确写“只有计划”。

```text
请使用本项目源码中的 $aigc-editing。
目标成片：【片长、画幅、观看重点与交付要求】
素材清单：【真实路径、版本、原长；或注明只有计划】
选段信息：【已知入出点、必须保留的动作/对白；未选可请建议】
画面连接：【硬切/叠化及重叠秒数/待建议】
声音版本与连接：【真实音轨/计划；对白、拟音、BGM、跨切意图】
已有分镜或Clip映射：【真实资料位置/粘贴内容/暂无】
本轮范围：【文字剪辑计划/时长核算/有素材的切点审查】
保存方式：【当前作品/仅聊天/不入公共库】
本轮只做文字；未播放时区间与连续性保留待验证，不编帧精确EDL，也不生成或导出成片。
```

## 已填示例

```text
请使用本项目源码中的 $aigc-editing。
目标成片：20秒，16:9，保留最后一段的完整反应。
素材清单：只有计划，没有真实视频；三个片段原长计划为8、10、10秒。
选段信息：片1取1到7秒；片2取2到9秒；片3取1到9秒。
画面连接：片1与2叠化重叠0.5秒，片2与3叠化重叠0.5秒。
声音版本与连接：只有声音计划；片2对白可提前0.3秒进入，片3结束保留呼吸，不另加黑场。
已有分镜或Clip映射：暂无，只核算上述顺序片段。
本轮范围：文字剪辑表和时长核算。
保存方式：仅聊天。
本轮只做文字；未播放时区间与连续性保留待验证，不编帧精确EDL，也不生成或导出成片。
```

## 会得到什么，怎样继续

得到源入出点、保留时长、画面重叠、时间轴起止、声音分轨说明和缺陷回修节点。
示例的时间核算可以执行，实际选段是否好看仍待素材播放。
下一步由用户在LibTV观看粗剪并反馈切点、连续性、对白及实际长度；Codex根据反馈调整剪辑指令，无需默认回传素材复审。

## 重要依赖

源素材时间与成片时间分开；对白先入/延后不自动缩短画面片长。
帧率未知先用秒级区间，不承诺帧精确；成片与声音由用户在LibTV完整播放后确认，Codex记录反馈。
计算规范与真实素材要求见 [SKILL.md](../SKILL.md)。
