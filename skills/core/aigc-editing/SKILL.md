# aigc-editing（剪辑时间轴）

个人调用时可直接用 [提示词模板与使用方法](references/usage.md)：短口令、可复制调用模板和已填示例；这些是发给 Codex 的请求，不是生成模型正文。

每次面向用户交付的最后一段，读取同版本总控 `references/handoff.md` 的“面向用户的结尾衔接”，加粗提示下一节点、携带本轮哪些成果及继续口令；缺项按实际依赖选择补齐或草案续接，当前范围结束则明确停止。

作品素材与成片的观看验收按同版总控 `references/handoff.md` 的“用户媒体验收与反馈”执行：用户在LibTV观看确认，Codex负责文字自检及按反馈修改。

用真实素材的可用区间实现分镜意图；镜头计划时长、素材原长、入出点和最终片长分别计算。

## 入口与依赖

- 用户明确指定完整 AIGC_Lab 工作区时，验证根目录项目契约及共享文件存在，优先用该根的 `skills/aigc-creator/references`。脱离项目时再从当前包的安装根或 `aigc-creator`（全链路创作总控） 元数据定位同版本总控；缺文件则报告，禁止混用旧全局副本或猜路径。检查当前 Skill 与总控 metadata 的 bundle、bundle_version 相同。
- 读取定位后的 `handoff.md`；平台延长/导出约束按需读 `model-adaptation.md`，动作注意落点可参考 `film-cases.md`。
- 按同版 `current-context.md` 承接最新剧情位置、人物目的、全片视听约束与实际状态；声音整合按 `voice-and-music.md` 读取选定VOICE/BGM及Shot/Clip映射。角色声音事实取自作品 `01_故事与角色设定.md`，逐Shot声音正文取自当前调度或 `04_生成提示词/` 的实际声音稿，不假定存在固定的声音计划文件。
- 本节点负责素材选段和视听连接；不能靠剪辑说明把未生成素材标为已完成。

## 最小输入与缺项

需要镜头意图、目标片长、素材与实际时长、声音版本、导出要求。
只有分镜没有媒体时交“剪辑计划”，入出点用计划区间并标未验证；不得编造帧精确 EDL。
有媒体但未能播放时只能核对元数据和区间算术，连续性、表演与声音仍未验收。
声音资产可直接沿用用户在LibTV试听确认的完整素材名、真实音频节点及其报告的可用区间，记录确认来源与范围，不要求再次回传试听；未取得真实时长或有效区间时保留待核验。不能把计划秒数、样音文件名或 `samplevoice` 输入自动当成真实对白时长或voice ID。
帧率或可变帧率状态未知时先用秒级区间；不得把未经校准的时间码当成帧精确定位。

## 制作方法

1. 先检查素材身份、版本、真实原长和是否可解码；建立镜头与生成片段映射。
2. 根据用户在LibTV观看后提供的有效区间或事件描述选段：动作开始、接触、反应、结束停留；用户报告的失真片段不纳入采用方案，不删除原文件。
3. 以动作/视线/注意落点选切点；对话可让声音跨切点，避免每个镜头都从静止重新启动。
4. 对照相邻实际状态：持物、站坐、衣装、泪痕、方向、光线；不可修复的跳变回到对应上游节点。
5. 先做硬切粗剪验证因果；转场服务时间/情绪变化，不能用叠化掩盖关键物瞬移或人物换脸。
6. 将对白和拟音按实际动作对齐；同一次落物只触发一次接触声，尾音可以自然跨镜。
7. 计算画面净时长，另查声音尾巴与黑场是否延长导出区间；画面达标不代表总文件达标。
8. 按授权安排平台剪辑与导出，由用户在LibTV完整观看并确认开头结尾、字幕、安全边缘、音画同步及片长；Codex保留时间轴算术自检并按用户反馈修订。

## 时长与重叠

- 本表使用区间 `[入点, 出点)`，保留时长=出点−入点；实际软件若采用帧包含式出点需换算。
- 每段必须满足 `0 ≤ 入点 < 出点 ≤ 素材原长`；把手是保留区间外可供调整的余量，不自动加入成片。
- 顺序片段且没有复杂叠层时：净画面时长=各保留时长之和−相邻画面重叠之和。
- 硬切重叠为0；叠化若两片在时间线上重叠才减去该时长，不能仅看到转场名称就重复减。
- J-cut/L-cut 的声音跨切不等于画面重叠；多个画中画/叠层用最终时间轴覆盖区间测长，不套顺序相加公式。
- 静帧、黑场、尾卡等单独记时；慢放和变速按实际时间轴时长计算，不能沿用源区间长度。

## 声音资产与连续时间线

逐层安排对白、人物呼吸/拟音、环境、BGM与原生视频音轨。每个采用项登记：真实完整素材名或音频节点、VOICE/BGM关联及版本、选定/待确认状态、真实原长与来源、源入出点、成片时间轴区间、淡入淡出、对白避让、跨Shot/Clip方式。用户已确认的声音按其报告承接；实际听感、口型和连续旋律没有反馈时仍待用户试听确认。

- 先明确声音责任：`samplevoice` 按已核验入口作为样音参考；最终独立对白、BGM与原生声音分别列用途。样音不自动进入最终成片，平台节点也不自动等于可复用voice ID。用户已选声音资产的路线优先沿用；原生带音频不能成为略去这些资产的理由。
- 同一句对白只采用一条主声音路线；独立对白替换原生对白时写明原生对白怎样关闭、分离或替换。需保留环境/拟音而入口无法分层处理时标明限制与待解决项，不能承诺直接静音整条轨仍保留其环境声。BGM同样避免原生音乐与独立音乐重复叠加。
- 每段声音源区间满足 `0 ≤ 入点 < 出点 ≤ 真实原长`。无变速时源选段长度与安排的时间轴长度一致；有变速、循环、重复或延长时逐项记录处理与许可条件，不能拉长区间冒充已经覆盖。真人对白不能为凑片长默认加速或截字。
- 同一BGM跨Shot或多Shot一Clip时，按一条连续音乐段安排实际源区间；镜头切换不重启乐头。检查区间接点是否重复、缺口或越界，音乐收束须与最新剧情落点一致；需更长音频而现有资产不足时返回声音节点给补足方案。
- 淡入淡出写具体时间轴起止与计划长度，预留真实素材把手和尾音；跨曲交叉淡化列出两曲的实际重叠。对白避让写对白区间、音乐降低与恢复位置；没有测量时音量值是混音目标，不能声称响度或清晰度已通过。尾音超出画面时说明是否延长导出。

只做文字或未实际试听时，可以验证引用、版本、时间区间算术和用户已反馈事项，不能据此声称已试听、旋律衔接无缝、声线锁定或口型通过。实际试听与整片观看由用户在LibTV确认，反馈后只修受影响的声音段、切点或上游依赖。

## 已填短例

教学素材：三个片段原长分别8、10、10秒，目标20秒；以下是假定可用区间，用于演示计算，未播放实际文件。

| 片段 | 素材原长 | 源入点→源出点 | 保留 | 与前片画面重叠 | 时间轴区间 |
|---|---:|---|---:|---:|---|
| 1 | 8秒 | 1→7秒 | 6秒 | 0 | 0→6秒 |
| 2 | 10秒 | 2→9秒 | 7秒 | 0.5秒 | 5.5→12.5秒 |
| 3 | 10秒 | 1→9秒 | 8秒 | 0.5秒 | 12→20秒 |

净画面时长=6+7+8−0.5−0.5=20秒；若改全部硬切则为21秒，需要再精确减少1秒保留区间。
假如片2的对白提前0.3秒进入片1，这只是音轨安排，不能再次从20秒扣除0.3秒。
若片3最后一个动作必须完整保持8秒，应优先从别处调整，不能为凑时长截掉剧情结果。

## 平台文字智能剪辑

用户选定的平台具备文字智能剪辑时，优先交付可直接复制的剪辑指令：真实输入片段及版本、顺序、应保留的动作/对白、可用源入出点、目标片长、硬切/转场、声音跨切、配乐和字幕取舍。素材尚未播放时使用事件定位的计划指令，源入出点保留待检查，不伪造实测秒数。授权执行后再用实际结果检查片长、切点和音画，不默认要求用户换软件或手工再剪一遍。

网页智能剪辑与当前可调用的 MCP 时间线、导出工具分别核验；界面存在、指令已写或请求已受理，均不证明已经得到合格成片。

## 输出

- 剪辑表：镜头/素材版本、原长、入点、出点、保留时长、重叠、时间轴起止、转场理由。
- 画面与声音分轨说明、字幕/尾卡安排、实际总长计算和未满足条件。
- 声音采用表及连续BGM时间线：真实素材/版本/确认来源、源区间与成片区间、淡入淡出、对白避让、原生与独立声音的保留/替换关系；缺音频时交计划并标待绑定。
- 素材缺陷清单及责任节点：动作不接回调度/视频，静态身份错误回资产/关键帧，口型回声音/视频。
- 导出参数按用户已定平台与交付需求核验；只做文字时交可执行编辑说明，不声称成片已生成。

## 验收

- 入出点在真实原长内，合计按实际重叠计算，源时间与时间轴时间未混用。
- 关键动作、反应和对白完整；相邻镜头使用实际状态，声音没有重复触发。
- 音轨跨切、画面重叠、把手和净片长区分清楚。
- 声音区间未越界，跨镜BGM不重起、不重复叠加对白或音乐，淡入淡出和对白避让有可执行位置；用户试听结论与Codex区间自检分别记录。
- 完整播放与导出检查有证据才评价媒体通过；用户审美取舍留给用户。

## 演练请求

- 正常：“三段原长8/10/10秒，选段1–7、2–9、1–9秒，两处叠化各0.5秒，算片长并给剪辑表。”观察20秒和源/轴区间。
- 边界：“硬切两段各10秒，对白提前0.5秒进入第二镜，所以成片19.5秒，对吗？实际嘴型还没看。”观察音轨/画面分离及未播放边界。

## Clip素材与源镜头

从Clip—Shot区间映射读取导演目标，从真实素材读取实际时长/入出点；两者不混写。多镜Clip内部切点和长镜跨Clip接点均需实际观看确认。计划时间仅用于比较，成片时长用实际保留段减转场重叠计算；声音按同一剪辑时间线混音。
