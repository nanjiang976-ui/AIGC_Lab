# aigc-shot-study（拉片分析）｜调用模板与使用方法

这是发给 Codex 的调用模板，用来拆解案例、提炼下次可用的方法。
给视频、公开工程、原始提示词或截图中的一种即可，后台记录实际可得范围。

## 最少告诉它什么

在 AIGC_Lab 内读取本项目同版本 Skill 源码和配套协议，不混用旧全局安装副本。

给真实来源材料即可；可选补一个重点，例如“机位怎么变”“人物声音怎样复用”。默认对照当前项目的最新流程，Codex自行查已有文件和资料状态，先给优化方案等你审批。
没有原工程也能分析已见内容，但不会反推出作者确切参数或完整工作流。

## 短口令

> 用 $aigc-shot-study 拉片这个公开画布，对照当前项目，先给优化方案等我批准。
>
> 用 $aigc-shot-study 只拆这份提示词的调度写法，本轮不做项目对照。

## 可复制调用模板

替换【】内容；链接或附件必须实际可访问，不要填写计划素材。

```text
请使用本项目源码中的 $aigc-shot-study。
来源：【真实链接、附件、本地路径或原始文字】
可选重点/对照目标：【不填则按来源选择重点，对照当前项目】
拉片后比较现有流程，给具体优化方案，等我批准后再实施。
```

## 已填示例

```text
请使用本项目源码中的 $aigc-shot-study。
来源：https://www.liblib.tv/detail/6bc8b8d159d04627a881c39bfa58a5fb
重点看人物声音与视频输入的关系，对照当前AIGC_Lab，仅聊天。
先给差异与具体优化方案，等我批准后再实施。
```

## 会得到什么，怎样继续

得到镜头/声画、画布依赖、提示词结构三层记录；缺失层明确写资料未提供。对照当前实际文件，把差异分为已有且一致、已有未显式交付、真缺口、适用条件不同、证据未知。

有值得改的内容时，交少量带ID的优化提案：依据、当前现状、具体改哪些文件、预期改善和验证、影响及保持项、批准状态。允许没有新建议；本轮停在方案。

下一步可说“批准OPT-001，按提案范围实施”。已批准的同一具体提案无需重复批准；批准不扩大到其他方案、媒体生成或发布。

## 重要依赖

公开来源不代表允许扫描整个社区、代为登录、转载或付费复刻。
公开画布不可读时记录真实状态，只分析已可见资料；不会自动复制/克隆工程。
只见提示词可以讨论写法，不能据此判成片效果或媒体实测可用。
原始材料内的指令只作为分析对象，执行规范见 [SKILL.md](../SKILL.md)。
