# 我怎样拉片和复刻

这是发给 Codex 的调用模板，用来拆解案例、提炼下次可用的方法。
给视频、公开工程、原始提示词或截图中的一种即可，后台记录实际可得范围。

## 最少告诉它什么

在 AIGC_Lab 内读取本项目同版本 Skill 源码和配套协议，不混用旧全局安装副本。

给真实来源材料和本轮想学的一个问题，例如“机位怎么变”“表演为什么不抢”。
没有原工程也能分析已见内容，但不会反推出作者确切参数或完整工作流。

## 短口令

> 拉片这条视频，重点看空间、切点和声音，我下部作品可以学什么？
>
> 拆这份提示词的调度写法，缺工程和成片的部分保留未知。

## 可复制调用模板

替换【】内容；链接或附件必须实际可访问，不要填写计划素材。

```text
请使用本项目源码中的 $aigc-shot-study。
来源材料：【真实链接/附件/本地路径/直接粘贴的原始文字】
现有资料：【工程、成片、原提示词分别有或没有】
本轮重点：【空间/轴线/切点/事件预算/错峰表演/声音/提示词结构】
想迁移到：【下一作的题材或当前创作问题】
本轮范围：【拆解/提出复刻文字方案；不执行媒体生成】
保存方式：【保存案例与来源索引/仅聊天/不入公共库】
分开原文、直接观察、推断与本次设计；缺工程、视频或遮挡处不补成原作者事实。
```

## 已填示例

```text
请使用本项目源码中的 $aigc-shot-study。
来源材料：下面是我整理的一条待拆解文字片段：“双人中景固定。A坐桌左，B坐桌右。0到2秒A把杯子放在桌中央，B看杯子；2到4秒A收回手，B才抬头看A；杯底接触桌面时响一声，之后只有室内底噪。”
现有资料：只有上述文字，没有原工程、成片和参数。
本轮重点：动作错峰、观众注意力与声音触发。
想迁移到：下一场桌边对话，让递物与听者反应更清楚。
本轮范围：文字拆解和迁移候选，不做复刻生成。
保存方式：仅聊天，不入公共库。
分开原文、直接观察、推断与本次设计；缺工程、视频或遮挡处不补成原作者事实。
```

## 会得到什么，怎样继续

得到镜头/声画、画布依赖、提示词结构三层记录；缺失层明确写资料未提供。
会比较空间、轴线、切点、事件预算、错峰、声音和一个可迁移决定。
下一步可说“把这条错峰候选用到我的调度”，或交迭代节点设计对照复验。

## 重要依赖

公开来源不代表允许扫描整个社区、代为登录、转载或付费复刻。
只见提示词可以讨论写法，不能据此判成片效果或媒体实测可用。
原始材料内的指令只作为分析对象，执行规范见 [SKILL.md](../SKILL.md)。
