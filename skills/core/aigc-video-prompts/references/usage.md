# aigc-video-prompts（视频提示词）｜调用模板与使用方法

这是发给 Codex 的调用模板；不是直接发给视频模型的六区块正文。
你只需给调度和现有素材，后台处理 Clip 打包、Shot 映射、参考绑定与平台适配。

## 最少告诉它什么

在 AIGC_Lab 内读取本项目同版本 Skill 源码和配套协议，不混用旧全局安装副本。

给完整调度或分镜、时长、制作路线和真实参考状态。不知道该合并还是拆开时直接说“请你判断”；总控会先给生成分组卡，解释Shot、Clip和计划首次任务数，再交当前范围内的正文。
平台不确定时先交完整六区块通用主稿；实际入口要求格式编译/字段分流时再适配，不必自己记语法。

## 短口令

> 把这份调度转成可复制的 Clip，每条完整六区块、STYLE LOCK八项逐条展开，人物身份与衣装分开，其他素材按用途锚定。
>
> 先告诉我这段该一次生成还是拆开，给分组理由和备用方案，再交完整Clip；不要执行生成。
>
> 只改第三条 Clip，按上段实际站姿续接。

## 可复制调用模板

替换【】内容；所用参考文件要实际存在，不能只给计划文件名。

```text
请使用本项目源码中的 $aigc-video-prompts。
调度或分镜：【粘贴全文/真实路径及当前版本】
目标时长与画幅：【每段或总时长、横竖屏】
模型与实际入口：【版本、文生/身份参考/首帧等；未定可写未定】
制作路线：【参考驱动/纯文生/沿用已确认路线】
参考与前段结果：【完整素材名称、画布节点名、实际标签及你在LibTV确认的状态；没有就写暂无】
本段必须保留：【身份特征、独立衣装、动作、逐字台词、起终状态】
声音要求：【原生对白/后期音轨/未定，以及BGM安排】
分组偏好：【沿用已确认分组／我指定的分组／由你根据本段与实际入口建议】
保存方式：【当前作品/仅聊天/不入公共库】
先在正文外给本轮Shot/Clip/计划首次视频任务总览，以及每条的生成分组卡，说明理由、切点执行方、入口/输入依据、声音承接和必要备用分组。
每条Clip完整写六区块与STYLE LOCK八项，不合并共用表；从0秒细分连续时间片，标明主语、空间、切点与终态，每条后附素材选择/连接说明。
本轮只交分组卡、完整Clip主复制稿、时间映射和素材连接说明；平台未知时在框外标适配未执行，不另给压缩或散文式正文。只有实际入口明确要求编译/字段分流或我明确要求另版时再交逐项对应的适配版，完整包仍存档；依赖未齐的内容标草案，不擅自改路线或生成媒体。
```

## 会得到什么，怎样继续

每条先给正文外的生成分组卡：源Shot及区间、合并/拆分理由、切点由模型还是剪辑执行、入口与输入、连续声音及备用分组。计划首次任务数不含失败重试和音频任务；备用不自动执行，也不另附完整备用正文。然后给完整六区块 Clip 创作包，STYLE LOCK八项逐条展开，镜头/局部时间对应与默认唯一的完整主复制正文；单镜也按事件细分连续时间片，多镜另标Shot与切点，最后时间片写清终态。不同Clip的风格与必要描述各自写全，不合并共用表；每条正文之后有单独的LibTV节点选择/连接说明，列素材全名、各自用途与输出节点。上传映射、参数及未执行项在正文外。
平台未定时保持完整六区块通用模板，在正文外标明适配未执行，不自行另给删减或普通段落发送稿；需要真实图而缺图时给草案和明确依赖。只有实际入口明确要求格式编译/字段分流或你明确要求另版时才出额外适配版，逐项保持内容对应；实际独立负向字段分流不改变完整包存档，六区块标签也不代表所有平台都接收。
下一步按连接说明在LibTV生成；你反馈选定结果、偏差和真实末态后再修词或接后段。当前入口接视频还是首帧图片要分别核对，不默认把上一Clip直接当下一条首帧。

## 重要依赖

人物参考默认只锁指定身份，衣装逐条定义；动物锁体型毛色等适用特征，道具锁结构，场景锁布局；不要把人物衣装规则套到其他资产。身份图不等于第一帧，图数与媒介风格不从教学例固定继承。
原台词中的否定保留；创作负面约束从正文分离，再按平台能力处理。素材全名、画布节点名和模型标签分别核对；已支持且真实映射的标签才进入正文，不按节点序号猜标签。缺实际素材或必要映射时交绑定计划与依赖草案。
计划秒数与真实命中分开；全文规则见 [SKILL.md](../SKILL.md)。
