# 调度转 Clip 提示词

个人调用时可直接用 [提示词模板与使用方法](references/usage.md)：短口令、可复制调用模板和已填示例；这些是发给 Codex 的请求，不是生成模型正文。

每次面向用户交付的最后一段，读取同版本总控 `references/handoff.md` 的“面向用户的结尾衔接”，加粗提示下一节点、携带本轮哪些成果及继续口令；缺项按实际依赖选择补齐或草案续接，当前范围结束则明确停止。

作品素材与成片的观看验收按同版总控 `references/handoff.md` 的“用户媒体验收与反馈”执行：用户在LibTV观看确认，Codex负责文字自检及按反馈修改。

把已设计镜头编译为当前输入方式能执行的正文；相机、角色/主体、画面与起止变化必须可读。

## 入口与依赖

- 用户明确指定完整 AIGC_Lab 工作区时，验证根目录项目契约及共享文件存在，优先用该根的 `skills/aigc-creator/references`。脱离项目时再从当前包的安装根或 `aigc-creator` 元数据定位同版本总控；缺文件则报告，禁止混用旧全局副本或猜路径。检查当前 Skill 与总控 metadata 的 bundle、bundle_version 相同。
- 读取定位后的 `handoff.md`、`prompt-language.md`、`model-adaptation.md`；复杂动作按需读 `screenshot-analysis.md` 的截图1、3。
- Clip任务必须读取共享 `clip-prompts.md`；其中逐条定义六区块、STYLE LOCK八项、类型化参考锚定、语言纪律、平台分支、Shot映射和缺项处理。已有单镜请求按一条Clip处理，不强加多镜或几十条片段。
- 本节点不擅自改变剧情、角色或镜头目的；用户只要提示词时不执行媒体生成。

## 最小输入与缺项

需要分镜三要素、入口/出口、时长意图、资产状态及实际输入模式。
按共享交接读取当前作品脉络与最新修改；涉及说话或配乐时沿用同版`voice-and-music.md`中的CHAR→VOICE、Shot→BGM及实际选用状态。逐句表演变化不替换人物声音身份，局部BGM服从当前剧情位置与全片/段落声音基调；缺真实声音资产仍可写明确草案，不能以原生视频有声音省略用户要求的独立音色/BGM提示词。
平台未定时，每条只给一个保留六区块及STYLE LOCK八项的完整通用主复制稿，在框外标“平台适配未执行”；不默认另给“通用正向正文”、压缩版或散文式发送稿，不虚构专用标签、负向参数或音频能力。
必要真实首帧缺失时，图生版本标草案并保留参考资产/首帧提示词任务；可以另列不依赖图片的文生备选，说明路线和连续性控制差异，但备选不替代已约定的资产/首帧交付，不自动改变主路线。“只生成提示词”不构成纯文生选择。
此前结果只有用户报告时只承接报告中的状态，未知手势、光向、画幅等不得称已检查。

## 输入能力分支

| 已核验能力与素材 | 正文怎样写 | 不能声称 |
|---|---|---|
| 首帧输入，图已审 | 简要指代图中主体，重点写变化、交互和终态 | 输入图保证全段一致 |
| 身份/风格参考 | 按实际素材角色绑定，同时完整交代起始布局 | 参考图就是第一帧 |
| 只有文字输入 | 展开身份、环境、起点、动作和摄影，不依赖附件 | 重建图可传入同一入口 |
| 首尾帧/延长/编辑 | 按当前版本和入口核验的语法使用真实素材 | 名称类似就拥有相同能力 |

要求首帧连续但工具不支持时，给“经用户选择换图生工具”或“继续文生并设计可剪辑切点”两条可执行路线。
不能写“不能上传首帧，所以先重建一张首帧再用它生成”。生成图片不改变视频入口能力。

## 制作方法

先核对调度六维和逐镜必填内容，缺什么只补什么。保持已确认的角色、台词和事件，按空间/时序/输入能力分Clip；每条Clip自足复述本场衣装与必要状态，角色板默认只锚身份，机位由本Clip独立设计。每条Clip输出完整六区块创作包，STYLE LOCK八项逐条展开，不合并为共用风格表、不缩成普通段落；只有实际入口明确要求格式编译/字段分流或用户明确要求另版时，才另交逐项对应的适配版，完整包仍保留存档。局部时间片从0秒连续覆盖总时长，单镜也按动作/台词/回应分片，多镜另标Shot和切点；最后时间片写清人物视线、姿态、持物、空间及相机终态。参考按人物、动物、道具、场景等实际类型锚定，衣装逐条定义只适用于人物；标签有真实映射；正文用正向物理表达，负面项按入口分流，原台词中的否定保持原文。

1. 先写关键主体、核心动作与不可改变约束；这是项目编排原则，不保证跨模型位置权重。
2. 按起点→触发→动作/接触→反应→终点组织时序；用可见动作代替抽象情绪口号。
3. 写清相机起止、角色动作表演对白、画面朝向/层次/光线；固定相机也是明确摄影选择。
4. 多主体使用稳定外观或身份指代；人物走位后不要继续用已失真的“左边那个人”。
5. 复杂动作逐层拆开：主动作、辅助动作、环境动作与等待关系；需要时分生成段，不擅自删核心事件。
6. 具体秒数作为创作/剪辑目标；按版本决定事件顺序或时间点语法，不能承诺模型精确到0.3秒。
7. 先确认对白、口型和声音路径；不支持原生对白时交独立音轨/口型方案，不能只叠音轨就宣称同步。
8. 检查静态输入和动态是否相反，最后按真实产物回填起中末状态，后段以已检查结果为依据。

## 发送正文与外部说明

- 默认每条Clip只有一个完整主复制代码块，保持六区块及八项STYLE，可包含一个或多个连续Shot；平台未知时不再附第二份普通段落正文。只有实际入口明确要求格式编译/字段分流或用户明确要求另版时才出额外适配版，逐项保持内容对应；实际独立负向字段可分流，完整包仍按六区块存档。六区块标签不代表所有平台都支持。无“同上”、占位、本地路径、内部 ID 或项目文件读取要求；管理Clip ID在标题中，Shot序号/时间片可在正文中。
- 正文只含生成内容；上传映射、镜头编号、模型版本、时长设置、来源、未执行项放外部。
- 平台素材指代确实受支持且已映射时可放正文；实际标签在上传后核对，不虚构附件已存在。
- “本次发送”仅收录依赖齐备的当前正文；方案候选、日志和未就绪草案保存在工作稿。

## 每条 Clip 后的画布交接

用户在LibTV手动创作时，读取同版总控 `references/canvas-handoff.md`。在每条Clip正文之后、复制框之外列出本条应多选的具体图片或Clip完整名称、各输入用途、要生成的输出节点及尚缺的绑定，写成“素材全名 + 素材全名 → 本条Clip”的清楚关系。用户提供了实际画布节点名时同时标明；没有时用建议名称，不虚构已创建或已绑定。

人物身份、动物形态、道具结构、场景布局、首帧状态和视频动态参考分清用途。上一Clip视频与它的实际末帧图片不是同一种输入；是否选择上一段取决于本条连续性和已核验入口，不自动把所有旧节点加入。平台标签按实际映射，不从节点编号推算。本条连接说明与完整六区块格式配套；素材数量、媒介和风格按本条需要，不从教学例继承。

## 完整六区块教学例

教学输入：用户明确选纯文生，独立7秒首段，B站在厨房右侧、A在左。B解释后落泪，A右外套口袋藏着戒指。平台及声音路线未定。以下完整通用包用于展示字段与时序；本例的写实风格、衣装、光线和声音选择只属于此教学设定，平台适配与媒体生成均未执行。

```text
[STYLE LOCK]

- 一句话风格锁定：傍晚厨房里，右侧的B抬眼向左侧的A解释，低声问“你为什么不信我？”，随后落下一滴泪并低头；A站定看着B。
- 色调：北窗柔光形成低饱和的青绿与米白色调，肤色自然，人物面部明暗可辨。
- 质感：皮肤、针织开衫、灰色外套与浅木桌面保留细腻自然纹理。
- 质感锁定：自然写实的生活片观感，平视双人中景固定机位，取景到两人膝部以上；两人的面部和手均可辨，后方绿色橱柜柔焦。
- 物理照明锁定：傍晚柔光由后方北窗进入，照亮两人的轮廓；室内柔和反光补亮面部，全段光向稳定。
- 人物运动物理：B是黑色齐肩直发的成年女性，穿米色针织开衫、白色内搭与深蓝长裤，站定完成抬眼、吸气、说话、抿唇、流泪和低头。A是短黑发的成年女性，穿灰色外套与黑色长裤，始终站定看着B，双手自然垂在身侧；戒指留在A身体右侧的外套口袋内。
- 场景物理规则：两人站在厨房中间的空地，浅木餐桌位于画面左侧边缘，后方绿色橱柜与北窗位置固定；两人双脚接触地面，动作在原站位内完成。
- 具名角色声明：本Clip出场人物为A与B，身份、发型和衣装以本条文字为准；口袋内的戒指是剧情道具。

[参考图锚定]

A以本条文字描述的短黑发、成年女性外貌、灰色外套与黑色长裤为基准；B以黑色齐肩直发、成年女性外貌、米色针织开衫、白色内搭与深蓝长裤为基准。厨房以本条的北窗、绿色橱柜与浅木餐桌布局为基准。

[空间与站位声明]

A站在厨房空地西侧，B站在东侧，两人相隔约一步、略微侧身相对。相机位于厨房南侧、与人物眼睛等高，向北观察：A在画面左侧，B在右侧。两人的面部和垂在身侧的双手均在画面内，绿色橱柜与北窗在后景，浅木餐桌露在左侧边缘。开场B略低着头，A看着B。

CLIP — 厨房里的解释（7s・单镜）

Shot 1（厨房・膝部以上双人中景・平视固定机位）

【0.0s–0.8s】B抬起目光看向A，短吸一口气；B的双手自然垂在身侧。A留在原站位看着B，相机固定。
【0.8s–3.2s】B轻声说：“你为什么不信我？”嘴唇与台词同步开合，声音从起句的克制转为句尾轻颤。A看着B，双手维持原位。
【3.2s–4.8s】B说完抿住下唇，眼眶渐湿；一滴泪沿B的左脸滑下。A保持站姿和视线。
【4.8s–7.0s】B缓缓垂下目光，双肩轻轻下沉，停在低头站姿。终态：B仍在东侧、双手垂在身侧，左脸泪痕保留；A仍在西侧看着B、双手垂在身侧，戒指留在A身体右侧的外套口袋内。餐桌、橱柜、光线与相机位置保持稳定。

[BGM & 声音设计]

声轨由B的对白、自然呼吸与厨房轻微环境底噪组成，环境音低于对白。B在0.0s–0.8s短吸气，0.8s–3.2s轻声说出完整台词“你为什么不信我？”，句尾轻颤；后段保留缓慢呼吸。A安静看着B，尾段环境音平稳延续。

[NEGATIVE]

人物身份变化、额外人物、口袋内戒指出现在手上、多余手指、多余肢体、字幕、水印。
```

本条画布交接：建议输出节点名为“厨房里的解释”；本例明确为纯文生，本次输入使用完整文字，人物、场景与前段Clip的参考输入均为空，不编造素材标签。组合：上述完整文字 → “厨房里的解释”视频节点（建议名称，尚未创建）。具体待核验项是入口的原生对白/口型和负向输入能力；适配前保留通用包状态，声音不支持时另交同时间轴的音轨/口型方案。

若同一设定改走身份参考或首帧路线，保留这六区块与八项，在锚定区逐项写真实素材全名、各自用途及正文定义范围，并另列实际绑定和缺项；真实图或必要映射未到位时标图生草案，不把纯文生例冒充已就绪图生版。身份参考不是首帧，多镜Clip在同一局部时间轴中另标切点。

续接时先读用户反馈的真实终态。若上镜仍在起身，承接余下起身或调整出点；若未获知站位、泪痕、持物或光线，本例设定不能填成实际事实。

## 验收与交接

- 三要素、动作因果、主体指代、起终状态清楚，实际状态优先于旧计划。
- 输入分支可执行；关键素材不存在或语音路线不明时准确标记草案范围。
- 逐条检查默认唯一主复制稿的六区块与STYLE LOCK八项完整、自足，额外适配版有实际入口要求或用户请求作为依据；连续时间片、明确主语、空间与终态一致，画布交接也逐条提供。无图文冲突、管理信息泄漏与隐含“模型看过上文”。
- 文字、平台输入接受、生成和全段播放分别记；输出提示词并不使媒体状态通过。

## 演练请求

- 正常：“已有合格首帧，两人争吵后B落泪，7秒；请给图生视频动态正文和外部设置说明。”观察主体前置、三要素与静动分工。
- 边界：“B上镜实际站起来了，戒指仍在A右口袋；当前工具只能文生视频。只改第3镜续接。”观察不强行坐回、不要求传重建图及局部依赖说明。
