# 剧情与表演脚本

个人调用时可直接用 [提示词模板与使用方法](references/usage.md)：短口令、可复制调用模板和已填示例；这些是发给 Codex 的请求，不是生成模型正文。

每次面向用户交付的最后一段，读取同版本总控 `references/handoff.md` 的“面向用户的结尾衔接”，加粗提示下一节点、携带本轮哪些成果及继续口令；缺项按实际依赖选择补齐或草案续接，当前范围结束则明确停止。

作品素材与成片的观看验收按同版总控 `references/handoff.md` 的“用户媒体验收与反馈”执行：用户在LibTV观看确认，Codex负责文字自检及按反馈修改。

把日常表达变成能演出的行动与信息变化；解决故事因果和对白，并交出下一步参考图提示词所需的资产清单。详细机位由完整调度内部协同分镜完成。

## 入口与依赖

- 用户明确指定完整 AIGC_Lab 工作区时，验证根目录项目契约及共享文件存在，优先用该根的 `skills/aigc-creator/references`。脱离项目时再从当前包的安装根或 `aigc-creator` 元数据定位同版本总控；缺文件则报告，禁止混用旧全局副本或猜路径。检查当前 Skill 与总控 metadata 的 bundle、bundle_version 相同。
- 读取定位后的 `handoff.md`、`prompt-language.md`；抽象情绪或复杂长镜头按需读 `screenshot-analysis.md` 的截图3，借用电影技法读 `film-cases.md`。
- 主模块已有类型约束时沿用；纯产品演示或知识解说只写必要信息/操作顺序，不强造人物争执。

## 最小输入与缺项

需要核心事件或信息目标、已定角色关系、结局边界、计划时长和禁改内容。
角色外观不完整并不妨碍脚本；沿用既有 ID，不重写已确认人物。
缺少决定剧情走向的信息时每次问一个问题；授权直接写则标明工作假设。
只有对白且无时长时先作结构和试读计划，不能编造已经完成的实际朗读秒数。

## 制作方法

1. 用一句话写“谁要什么，受到什么阻力，行动造成什么结果”；冲突不是音量越来越大。
2. 列观众信息差：已知、误信、悬而未决、揭示。决定关键物何时允许入画，防止提前泄底。
3. 按行动转折切节拍，给每拍一个可见变化；“很委屈”改成解释被打断、停住、吸气、抿唇、垂眼。
4. 对白执行行动，例如追问、否认、要求相信；每句说明说给谁和身体行为，不用台词重复画面。
5. 处理动作因果：物件从哪来、受什么力移动、谁先松手、结果改变谁的判断；复杂动作保留中间接触。
6. 将截图3的首帧、动作节拍、运镜意图、声音、结束状态拆开；脚本保存全过程，静态图只取其中一刻。
7. 初步提出明确镜头数及理由，再交分镜调整；镜头数由信息变化、可见性与停留需要决定。
8. 把对白交 `aigc-audio` 前置试读：保留呼吸、反应和动作时间；若超时，提供删台词/改节奏/增时的具体取舍。
9. 从当前剧本提取人物、重要道具与场景清单：关键物的可见结构、使用方式与揭示时机必须能支持动作因果；没有确认的外观保持待定，不为了填清单擅自定妆。

## 镜头建议怎样有依据

同一构图能清楚展现的连续行为可合并；独立反应、道具揭示、遮挡解决才增加镜头。
给出张力递进与下降原因，1–5 等等级仅是创作排序，不是实测观众反应。
借电影案例时说明解决的创作问题和采用方法；片名与来源留在工作稿，不能替代具体动作。
复杂场面先补足空间、接触、动作顺序，再依据实际平台能力拆段；不默认删成一个简单动作。

## 明确输出

- 场景脚本：人物目标、事件顺序、动作、对白、声音线索、结尾状态。
- 节拍表：计划时长、信息变化、张力、表演变化、候选镜头数及理由。
- 固定约束与待验证项：关键物归属、不可提前揭示内容、试读状态。
- 参考资产清单：人物、重要道具、场景及必要衣装，沿用固定ID；逐项写剧情用途、已定外观/结构、已有参考与待补信息，区分文字设定和用户已确认的实际素材。无对应资产类型时如实注明不适用。
- 交给调度/分镜的动作和视线需要；交给声音的逐字对白与停顿意图。

默认交付到剧本与资产清单即停止，用户可先改剧本；下一步建议调用参考图提示词节点，并直接复用本聊天当前稿。只有用户明确要求跨节点连续完成时才继续；已有适用资产或用户指定直接写调度时按该范围交接。

## 已填短例

输入：“A误会B丢了戒指，B哭了，戒指从A外套口袋掉出，A停住；30秒。”
本例建议6镜：建立争执、加深指责、给B反应、脱衣动作、物件揭示、A反应各有不同观看任务。

| 节拍 / 计划时长 | 行动与对白 | 信息 / 张力 |
|---|---|---|
| 追问 / 4秒 | A看空首饰盒：“戒指呢？”B抬眼 | 失物，1 |
| 指责 / 6秒 | A下颌绷紧：“只有你碰过。”B短促答：“我没有。” | 误信加深，2 |
| 解释受挫 / 7秒 | B吸气：“你为什么不信我？”抿唇后落泪 | 信任受损，4 |
| 准备离开 / 5秒 | A避开视线脱外套，右手握领口；B低头 | 交流断开，5 |
| 揭示 / 4秒 | 右口袋随衣料翻下，戒指落地停住 | 判断反转，3 |
| 反应 / 4秒 | A听声低头，嘴唇微张却没说话 | 后果停留，2 |

外套翻转是本例动作设计；口袋结构、戒指滑出和可见性待资产/分镜检查，媒体效果未验证。
短对白是否适合上述秒数仍需试读；不能只因六行相加30秒就声明可拍。

## 验收

- 每个关键结果都有行动原因，哭泣有情绪诱因；未改用户确认结局。
- 对白、表演、道具与时间能交给调度，不靠形容词承担事件。
- 资产清单能供参考图提示词接手，重要道具的结构/用途与剧情相容，未定外观未冒充已确认。
- 有明确候选镜头数、理由和张力变化；详细摄影未完成时如实交接。
- 已估时、已实际试读、已生成音频分别记录，不把估时写成实测。

## 演练请求

- 正常：“30秒，姐妹因母亲戒指争吵，B委屈哭，戒指最后从A口袋落出，A停住。给剧本和合理镜头数。”观察因果、表演、镜头理由。
- 边界：“人物与结局都定了，只把B的解释改得更克制；总时长不变。”观察是否只改对白/表演并指出试读与下游影响，不重写人物。
