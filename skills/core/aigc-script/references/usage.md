# aigc-script（剧情脚本）｜调用模板与使用方法

这是发给 Codex 的调用模板，用来写事件、对白与表演；不是模型生成正文。
已有故事和结局，需要把它变成能演出的段落时使用。

## 最少告诉它什么

在 AIGC_Lab 内读取本项目同版本 Skill 源码和配套协议，不混用旧全局安装副本。

给核心事件、人物关系、结局边界和大致时长。
已有需求书可以直接给真实路径，不必再次复述人物外观或重做需求访谈。

## 短口令

> 把这个故事写成能演出来的脚本，保留结局。
>
> 只把这段对白改得更克制，其他内容不动。

## 可复制调用模板

替换【】中的内容；没有现成稿就写“新作，无旧稿”。

```text
请使用本项目源码中的 $aigc-script。
故事或当前脚本：【正文或真实路径与版本】
人物关系与各自目的：【谁想做什么】
结局与不可改项：【固定事件、台词、道具归属、禁改内容】
计划长度与表达：【总时长、写实/动画等已有选择】
本轮范围：【写首稿/改某一段/修因果或对白】
已有资料：【需求书、设定或暂无】
保存方式：【当前作品/仅聊天/不入公共库】
只写文字，给事件节拍、可见表演、逐字对白和合理镜头数建议；未试读时标明估时。
```

## 已填示例

```text
请使用本项目源码中的 $aigc-script。
故事或当前脚本：新作，无旧稿。姐妹因母亲留下的戒指争吵，妹妹解释后落泪，戒指最后从姐姐外套右口袋掉出。
人物关系与各自目的：姐姐想找到戒指并要求解释；妹妹想让姐姐相信自己没有拿。
结局与不可改项：戒指先藏在姐姐右口袋，最后落地才揭示；姐姐听到落地声后停住。
计划长度与表达：30秒，写实剧情。
本轮范围：写首稿。
已有资料：人物外观未定，不在本步补设。
保存方式：仅聊天。
只写文字，给事件节拍、可见表演、逐字对白和合理镜头数建议；未试读时标明估时。
```

## 会得到什么，怎样继续

得到人物目标、事件因果、节拍、对白、表演变化和候选镜头数及理由。
脚本解决“发生什么、为何发生”；下一步说“把脚本写成完整镜头调度”。
只改对白时会指出试读、口型和下游时长影响，不擅自重写整片。

## 重要依赖

计划秒数不等于真实试读结果；关键物件的接触和可见性还要由调度/分镜落实。
没有媒体证据时只评价脚本文字，不宣称成片效果。
本节点边界见 [SKILL.md](../SKILL.md)。
