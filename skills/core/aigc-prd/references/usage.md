# aigc-prd（创作需求）｜调用模板与使用方法

这是发给 Codex 的调用模板，不是模型生成正文。
想法还散、需要问清楚，或已经有需求书想直接体检时使用。

## 最少告诉它什么

在 AIGC_Lab 内读取本项目同版本 Skill 源码和配套协议，不混用旧全局安装副本。

给创意、用途或现有需求书即可。已确定的关系、结局和限制直接说明。
不需要一次填完画幅、平台、人设等全部信息；只补影响下一步的关键项。

## 短口令

> 先帮我把这个视频想法问清楚，每次一个关键问题。
>
> 检查这份需求能不能开始写脚本，别重新访谈。

## 可复制调用模板

【】是调用时要替换的内容；未知项写“未定”。

```text
请使用本项目源码中的 $aigc-prd。
我的想法或现有需求：【粘贴内容，或给当前版本真实路径】
想让观众得到：【情绪、信息或行动目标】
已确定且保留：【人物关系、结局、必有/禁改内容】
本轮要做：【问清需求/整理PRD/检查缺项与矛盾】
计划规格：【图片或视频、画幅、时长；未定可写未定】
已有资产与制作路线：【实际材料；参考驱动/纯文生/未定】
保存方式：【当前作品/仅聊天/不入公共库】
只做需求文字；已有明确资料直接复用，缺关键项时每次只问一个问题。
```

## 已填示例

```text
请使用本项目源码中的 $aigc-prd。
我的想法或现有需求：20秒写实短片，一名维修工深夜修好母亲留下的旧台灯。
想让观众得到：从独处的疲惫转为短暂安定。
已确定且保留：只有一名成年男性；灯亮后停住看灯；结尾没有对白。
本轮要做：整理PRD并检查是否能进入脚本。
计划规格：视频，16:9，20秒。
已有资产与制作路线：暂无资产，选择参考图驱动。
保存方式：仅聊天。
只做需求文字；已有明确资料直接复用，缺关键项时每次只问一个问题。
```

## 会得到什么，怎样继续

得到需求摘要、固定约束、交付清单，以及已确认/假设/待定的区分。
完整需求先指出矛盾；模糊需求先问一个有用的问题。
确认后说“按这份需求写脚本”，即可交给脚本节点。

## 重要依赖

需求整理不会自动生成媒体，也不会把建议写成你已经确认的决定。
人物外观与平台细节可在影响当前节点时再补；短片时长仍需后续试读和动作估时。
详细执行范围见本包 [SKILL.md](../SKILL.md)。
