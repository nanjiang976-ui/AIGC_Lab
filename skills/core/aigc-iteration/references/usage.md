# aigc-iteration（创作复盘）｜调用模板与使用方法

这是发给 Codex 的调用模板，用来对照目标、原稿、变化与真实结果。
“复盘”可以只找经验；满足项目维护门槛后才会更新限定的自定义 Skill。

## 最少告诉它什么

在 AIGC_Lab 内读取本项目同版本 Skill 源码和配套协议，不混用旧全局安装副本。

给想改善什么、原稿/基线、实际修改和已有证据。
没有旧稿就写“无基线”，没有生成或反馈就写“未执行”，不需要自己编经验编号。

## 短口令

> 复盘这次改动，区分文字改善和还没验证的媒体效果。
>
> 这条方法下次能用吗？先查重并列对照复验的判据。

## 可复制调用模板

替换【】内容；引用真实记录，不把期望写成结果。

```text
请使用本项目源码中的 $aigc-iteration。
本轮目标与保持项：【想改善什么、哪些不能改】
基线与版本：【原始输入输出/真实文件；新作可写无基线】
实际变化：【改后文本、执行步骤或结果位置】
已有证据：【文字行为/用户反馈/真实媒体与播放记录；未做的写未执行】
我观察到：【事实与反例；不确定的单独说明】
本轮要做：【复盘/检索并试用经验/设计复验/按项目授权评估Skill维护】
保存方式：【当前记录/保存适用公共经验/仅聊天/不入公共库】
先按既有经验体系查重，对照原定判据；只把证据支持的范围写为已验证，不扩大生成或维护权限。
```

## 已填示例

```text
请使用本项目源码中的 $aigc-iteration。
本轮目标与保持项：让角色接杯动作有明确归属；保持两人、一个杯子和递杯后离开的剧情。
基线与版本：文字v001：“A把杯子递给B，然后离开。”这是原稿，没有媒体。
实际变化：文字v002：“A右手握杯把递出，B左手托底、右手握杯身；B握稳后A才松手，A空手离开。”
已有证据：只有两版文字；无生成、播放或用户效果反馈。
我观察到：改后可逐步追踪杯子由谁持有；实际动作成功率未知。
本轮要做：比较文字差异，查是否已有接触链经验；若有则复用，不新增同义规则。
保存方式：仅聊天，不入公共库。
先按既有经验体系查重，对照原定判据；只把证据支持的范围写为已验证，不扩大生成或维护权限。
```

## 会得到什么，怎样继续

得到事实/假设/未知、基线对照、采用或试用的方法、反例、验证范围和停止理由。
可继续说“按这些判据做一轮文字对照”；媒体复验需要另外满足素材与生成授权。
纯复用可以零新增，换了目标也不自动证明旧稿失败。

## 重要依赖

项目 Skill 自动维护需真实行为基线、独立实际执行、针对性修订和陌生案例复测，之后走 skill-creator。
候选、已验证经验、提示词媒体实测与作品验收分别记录，不能相互升级。
核心原则变更仍先问；全局安装、第三方/系统 Skill、长期记忆和发布不自动改变。
项目内以当前持续迭代协议为准，入口职责见 [SKILL.md](../SKILL.md)。
