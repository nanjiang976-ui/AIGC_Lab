# aigc-music（音乐影像）｜调用模板与使用方法

在 AIGC_Lab 内读取本项目同版本 Skill 源码和配套协议，不混用旧全局安装副本。

这是我发给 Codex 的调用模板，用来让画面围绕实际音轨组织。`【填入】` 供调用时替换；生成正文须展开，拍秒网格留作制作计划。

## 什么时候用，最少说什么

- 我要做 MV、音乐可视化、节拍动效或由乐句推动的影像时使用。
- 最少说：音乐来源／待作曲条件、截取起点和长度、已知速度与拍单位、视觉目标、本次范围。
- 完整音乐 brief 直接使用；只问决定本步节奏的关键缺口。
- 短口令：**“按这段音乐安排视觉节奏，先做时间轴和文字方案。”**

## 可复制调用模板

```text
请使用本项目源码中的 $aigc-music。
音轨与使用范围：【实际音频或明确写尚未提供；来源与版本】。
截取区间：【起点、时长；不知道就写待实测】。
已知节奏：【BPM、拍号、拍单位、恒速／变速；未知不猜】。
视觉主题：【主体、风格、动作；故事还是抽象变化】。
表现与时长：【画幅、总时长、保留整句或重要转折】。
同步要求：【大致呼应／按实际重音剪辑；需要多精确】。
现有素材：【可用图像／片段；没有写没有】。
本次做到：【音乐结构／视觉节奏谱／调度／Clip文字包】。
请区分计算网格与实际听测，说明镜头为什么切或持续。
只准备文字，不制作音乐或生成视频。
```

## 已填例子

以下只给假设节奏条件，音轨尚未到位，不存在已经试听的结论。

```text
请使用本项目源码中的 $aigc-music。
我想做8秒、16:9的青色光环音乐可视化，深蓝背景，没有人物。
计划音乐条件为原创无歌词、恒定120 BPM、4/4、四分音符一拍。
从首个下拍取16拍，音轨还没提供，起拍暂设0秒。
请先算拍秒关系，再设计一个连续镜头的四阶段变化。
视觉从小而暗的光环开始，逐渐变亮、扩张、停留，再收回。
不要猜实际乐器、鼓点或高潮；网格只作假设草案，精确同步待音轨到位。
请交视觉节奏谱、运动阶段、剪辑余量和需要实测的项目。
没有参考图，平台待定；只准备文字，不生成音频或视频。
```

## 我会得到什么，接着怎么用

1. 音轨身份与听测状态、拍单位、拍秒计算或实际标记，以及不确定项。
2. 视觉节奏谱、镜头数与乐句理由、动作阶段和剪辑余量。
3. 实际音轨到位后重校起点与重音，再生成所需片段并按真实时间轴剪辑。

## 这个类型要先备好什么

- 可访问的实际音轨及使用条件决定最终节奏；没有音轨也能做明确标注的假设方案。
- 只给 BPM 不足以判断乐器、段落或情绪；变速段不能套单一恒速公式。
- 换曲、换版本或改截取起点后，要重新校准，旧的同步结论不能沿用。
- 是否做首帧／首尾帧取决于生成入口和端点需求，抽象题材不强制人物参考。
- 文字算术正确不等于踩点准确；精确同步、运动相位和整体听感要实际连播。
