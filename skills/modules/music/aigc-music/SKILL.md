# aigc-music（音乐影像）

让视觉服从实际音乐结构；拍数换算给计划网格，实际音轨决定同步位置。

需要复制调用或查看使用方法时，读[我的调用模板与用法](references/usage.md)。

每次面向用户交付的最后一段，读取同版本总控 `references/handoff.md` 的“面向用户的结尾衔接”，加粗提示下一节点、携带本轮哪些成果及继续口令；缺项按实际依赖选择补齐或草案续接，当前范围结束则明确停止。

作品素材与成片的观看验收按同版总控 `references/handoff.md` 的“用户媒体验收与反馈”执行：用户在LibTV观看确认，Codex负责文字自检及按反馈修改。

## 适用边界

- 适用：MV、视觉化音乐片段、节拍动效、以乐句或音色变化组织的影像。
- 不适用：普通 BGM 设计与制作归 `aigc-audio`（声音制作）；只有背景配乐的广告不必切换主模块。完整调度的声音主链按同版 `references/handoff.md` 读取；没有音乐目的的循环氛围画面用 `aigc-visual-art`（视觉艺术）。
- 有人物故事可叠加 `aigc-narrative`（剧情与漫剧），明确故事与音乐谁主导转折；不把每个鼓点都设为切镜点。
- 动画/实拍风格与横竖屏独立记录，本模块不构成音乐影像的穷尽分类。

## 最小输入与公共协议

- 最少需要音轨或明确的待作曲条件、片段起点/长度、速度与拍号已知程度、视觉目的及本轮范围。
- 未收到/未听音轨时，只能制作假设节拍草案；不得声称听见乐器、鼓点、情绪高潮或准确落拍。
- 用户已明确完整 AIGC_Lab 工作区时，先核对该根的 `README.md`、`AGENTS.md`、`spec/harness-engineering.md` 与 `skills/catalog.json`，确认项目契约和本叶 skill 的归属；优先读取该根 `skills/aigc-creator/references/`，不让旧全局入口覆盖指定工作区。
- 脱离项目时，从当前包的实际安装根或 `aigc-creator`（全链路创作总控） 元数据定位总控，比较叶节点与总控的 metadata.bundle / metadata.bundle_version 确认版本配套；缺文件、版本不符或无法确认同版本时报告，不猜路径或静默回退。
- 按以上规则定位总控后，以其目录为基准读 `references/handoff.md`、`references/prompt-language.md`；动势/材质按需读 `references/lexicon.md`。
- 需生成工具时再读其 `references/model-adaptation.md`；缺依赖时报告，不凭通用例子承诺音画同步功能。
- 每镜头记录相机、角色/主体、画面及前后状态；主体、运动与节奏硬约束前置，精确踩点仍交后期实测。

视频提示词交付：用户本步要求生成视频提示词时，在同一交付中由 `aigc-video-prompts`（视频提示词） 按同版总控 `references/clip-prompts.md` 后台编译，每条 Clip 只交一个保留完整六区块与 STYLE LOCK 八项的主复制稿，不让用户再调用一次。平台未知时交完整通用稿，框外注明适配未执行，不另给扁平化稿；只有已核验入口明确要求格式编译/字段分流，或用户明确要另版时，才额外提供对应平台适配版。以下导演表达或输入分工片段不是 Clip 发送稿；用户只要策划或图片时保持本步范围，图片提示词不套六区块。

## 节点取舍

| 条件 | 节点与交接 |
|---|---|
| 只有视觉愿望或歌曲概念 | `aigc-prd`（创作需求） 定范围；现有曲目不擅自更换 |
| 真实音轨已到 | `aigc-audio`（声音制作） 先记时长、起拍、段落、重音与测量方式，再交 `aigc-script`（剧情脚本） 写视觉节奏谱 |
| 抽象动效无人物 | `aigc-visual-assets`（参考图资产） 建形状/材质母版，跳角色三视图与人物关系脚本 |
| 舞蹈、人物或物体节奏运动 | `aigc-blocking`（场面调度） 写动作相位与可执行幅度，再 `aigc-storyboard`（分镜设计） |
| 需要生成段落 | 按控制需要选 `aigc-keyframes`（静态关键帧） → `aigc-video-prompts`（视频提示词）；已有素材可直接剪辑 |
| 精确同步和整段播放 | `aigc-editing`（剪辑时间轴）依据音轨时间轴或用户报告写校准方案，用户在LibTV检查实际节奏与接点 |

## 专用创作判断

1. 恒定速度时，每拍秒数 `60 / BPM`，N 拍时长 `60 × N / BPM`。说明 BPM 的拍单位；常见 4/4 四分音符计拍下每小节 4 拍，其他拍号不能照搬。
2. `t(n)=起拍时间+(n-1)×60/BPM` 只适用于已确认恒定速度区间；自由速度、变速或弱起用实际节拍标记，不套单一公式。
3. 区分拍、重音、小节、乐句和段落。一次切镜可跨多拍；持续运动、材质变化或光线峰值也能响应音乐。
4. 给每段一个视觉变量主导，形成蓄势、扩张、峰值、释放等关系；这些是创作选择，不能从 BPM 自动推断音乐情绪。
5. 给出镜头数与时长的音乐理由，例如保留整句呼吸、在真实段落切换处换场，而非固定每四拍切一次。
6. 运动设计描述可控运动区间，不承诺毫秒同步。生成片段留剪辑余量；需要变速时检查光流、形变、运动方向与声音是否被影响。
7. 音轨来源、使用条件、版本与截取范围一起交接。替换音轨或起点改变后重算网格并重新连播，不沿用旧的“已踩点”结论。

## 已填文字示例

教学假设：原创无歌词、恒定 120 BPM、4/4、四分音符为一拍；取首个下拍开始的 16 拍。音轨尚未提供，所以无乐器/强弱实听结论。

换算：每拍 `60/120=0.5秒`；16 拍 `16×0.5=8秒`；4 小节，每小节 2 秒。首拍时间暂设 0，实际音轨到位后校准。

选择 1 个连续 8 秒镜头，四组视觉变化跨 4 拍；持续扩张与回落构成整体呼吸，避免短时间频繁切换主体。

| 拍 / 秒 | 相机 / 主体 / 画面 | 前态 → 后态 |
|---|---|---|
| 1–4拍，0–2秒 | 固定正视；单个青色光环；深蓝背景 | 小且暗 → 保持直径、亮度缓升 |
| 5–8拍，2–4秒 | 同机位；同一光环扩张；无新增物体 | 直径占宽度1/4 → 占1/2 |
| 9–12拍，4–6秒 | 同机位；光环维持尺寸；边缘更亮 | 中亮 → 明亮但不闪白 |
| 13–16拍，6–8秒 | 同机位；光环收缩回落；背景稳定 | 直径1/2 → 1/4，亮度回初值 |

运动设计的导演表达片段，非 Clip 发送稿：

```text
一个青色薄光环位于深蓝背景中央，保持唯一主体和稳定轮廓。固定正视机位，先维持小直径并缓慢变亮，再均匀扩张到画面宽度的一半，短暂停留后逐渐收回初始尺寸与亮度。背景始终稳定，不切镜、不出现文字、不突然闪白。节拍同步和各阶段准确时点由后期依据实际音轨调整。
```

## 专用验收与交付

- 交付音轨身份/版本/截取范围、实际听测状态、速度与拍单位、拍秒网格、视觉节奏谱及剪辑余量。
- 文本检查计算正确且假设明确；实际检查节拍偏差、相位与运动峰值、跨段节奏及完整听感，不能只看波形截图。
- 没有实际音轨时同步验收为 NOT_RUN；只有素材上传或单帧截图不能证明音乐视频播放通过。

## 训练题

- 正常：按上述 120 BPM、16 拍条件给 8 秒设计，说明拍秒换算、一个镜头的理由和四个运动阶段；无音轨时明确未试听。
- 边界：用户只说 90 BPM，却要求 16 拍正好 8 秒且逐帧踩实际鼓点，没有提供音轨。算出恒速 90 BPM 下为约 10.67 秒，提出保留拍数/时长/速度的取舍供用户选；不猜鼓点或静默改音轨速度。
