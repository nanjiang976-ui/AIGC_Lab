# 视觉艺术与氛围影像：我的调用模板

在 AIGC_Lab 内读取本项目同版本 Skill 源码和配套协议，不混用旧全局安装副本。

这是我发给 Codex 的调用模板，用来控制视觉变量和连续运动。`【填入】` 只给调用时替换；生成正文须展开全部必要要素，不能保留字段占位。

## 什么时候用，最少说什么

- 我要做抽象视觉、环境氛围、装置影像或无剧情循环时使用。
- 最少说：视觉主题、观看感受、时长／画幅、主体、是否循环、本次范围。
- 已有完整视觉设定直接使用；只补影响本步的运动或接点条件。
- 短口令：**“做一段安静雨夜氛围，只设计连续运动和循环接点。”**

## 可复制调用模板

```text
请使用本项目源码中的 $aigc-visual-art。
视觉主题与主体：【场景／形状／材质；有人物还是无人】。
观看用途与感受：【背景／艺术短片／装置；希望看到的具体体验】。
时长与表现：【总时长、画幅、写实／二维／三维】。
主要变化：【方向、速度、幅度、周期；可请你提案】。
保持稳定：【构图、光源、颜色、形状、物体数量等】。
循环条件：【要／不要；允许的回接方法和不能接受的变化】。
声音与现有参考：【环境声／音乐／静音；实际素材或没有】。
本次做到：【视觉方案／运动调度／Clip文字包／局部修改】。
请解释连续或切镜的理由，给起止状态和实际循环验收方法。
只准备文字，不生成图片、音频或视频。
```

## 已填例子

以下是新的虚构场景设定，尚无媒体可检查。

```text
请使用本项目源码中的 $aigc-visual-art。
做10秒、16:9、写实雨夜窄街，作为安静桌面背景。
场景无人、无车；左侧青色灯带，右侧紫色灯带，街道消失点居中。
固定眼平机位，建筑与光源位置稳定；细雨向下，积水倒影小幅摆动。
只让雨和水纹持续变化，亮度和焦点稳定，不添加剧情或人物关系。
目标是后期可循环；请写首尾的构图、亮度、方向与速度要求。
我不想用明显倒放，其他回接办法可先说明代价，不承诺绝对无缝。
静音，没有参考图，平台待定；先交视觉方案、完整运动调度和验收方法。
只准备文字，不生成媒体；循环接点需要之后实际连续播放检查。
```

## 我会得到什么，接着怎么用

1. 视觉目标、主变量与稳定量、运动规律、镜头数量与时长理由。
2. 起止状态、循环策略和代价；不需要人物时跳过角色设定与剧情流程。
3. 确认场景后可做场景参考或 Clip；有视频后回传尾段和首段并连播检查接点。

## 这个类型要先备好什么

- “平静”需要落到运动幅度、构图和变化频率，本片偏好不自动成为项目默认。
- 无人物不需要四格人物图；场景、材质或形状参考按实际需要建立。
- 循环不仅比首尾画面，还要检查运动方向、速度、亮度与接点重影。
- 首尾帧控制只是平台支路；同一张起止图不能保证运动自然闭合。
- 没有实际媒体时只能交循环目标，不能宣称无缝、无闪烁或播放验收通过。
