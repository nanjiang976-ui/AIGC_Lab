# 科普与知识解释：我的调用模板

在 AIGC_Lab 内读取本项目同版本 Skill 源码和配套协议，不混用旧全局安装副本。

这是我发给 Codex 的调用模板，用来把一个问题解释清楚并检查画面有没有画错机制。`【填入】` 是调用字段，生成模型正文必须完整展开。

## 什么时候用，最少说什么

- 我要做原理解释、概念动画、机制演示或知识短片时使用。
- 最少说：给谁讲、回答哪个问题、时长、已有讲稿或来源、本次做到哪一步。
- 已有完整讲稿先审查其事实和图解关系，不重走需求访谈。
- 短口令：**“把这个机制讲给初学者，先核对事实，再设计画面和解说。”**

## 可复制调用模板

```text
请使用本项目源码中的 $aigc-explainer。
要回答的问题：【一个明确问题】。
受众基础：【年龄／已有知识；不用的术语】。
已有结论与依据：【贴讲稿、可靠来源或本题定义的数据】。
需要解释的过程：【对象、关系、变化；不确定项写待核实】。
时长与表现：【总时长、画幅、图解／实拍／动画】。
可用类比：【允许的类比；没有写请提案并说明边界】。
必须准确：【方向、单位、数量、结构、不能误导的关系】。
本次做到：【讲稿审查／图像映射／完整调度／Clip文字包】。
请区分事实、教学简化、类比和未知；标签与数字给后期精确排版。
只准备文字，不生成媒体。
```

## 已填例子

以下是人为定义的玩具分类规则，可直接计算，不代表所有 AI 的真实内部机制。

```text
请使用本项目源码中的 $aigc-explainer。
做24秒、16:9的二维示意，向初学者解释“规则怎样根据已知错误调整”。
本题定义：数值大于等于阈值判高；卡2的正确标签为低，卡8为高。
初始阈值9，计划改为5；请先逐项检查两张卡的判断是否正确。
用固定卡片与移动阈值线来展示变化，颜色含义前后一致。
说明这只是玩具模型；做对这两张卡不能证明新卡都能做对。
本次只交主张依据表、画面映射、完整调度和同步解说。
请解释镜头数与停顿怎样帮助理解；数值、标签和问号由后期添加。
不增加人脑、工厂等额外类比，没有参考图，平台待定。
只准备文字，不调用生成工具。
```

## 我会得到什么，接着怎么用

1. 核心答案、主张与依据、简化／类比边界，以及待核实结论。
2. 每个对象、箭头、颜色和变化所代表的意思，与解说同步的镜头设计。
3. 确认事实与图解关系后再做资产或 Clip；有实际配音后再校准画面停顿。

## 这个类型要先备好什么

- 真实专业事实需要可靠来源；本题自定义规则要标清定义，不能扩大成现实结论。
- 数据附单位、范围和来源；示意图中的数量、比例、速度不自动构成定量证据。
- 关键结构需要精确控制时选择合适资产和端点；不因选本类型就强制每镜做首帧。
- 未收到图解或配音时可先做文字方案，但不能声称受众理解或声画同步已验证。
- 进入媒体阶段还需核验实际模型能否维持结构，标签文字通常用后期叠加。
