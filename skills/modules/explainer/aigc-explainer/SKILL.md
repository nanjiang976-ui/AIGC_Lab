# 科普与知识解释

围绕一个观众能回答的问题组织解释，保证画面关系与所讲机制相符。

## 适用边界

- 适用：概念解释、原理演示、知识动画、面向特定受众的科普段落。
- 不适用：真实软件点击教学以 `aigc-product-demo` 为主；只读稿出镜且不负责知识图解时以 `aigc-presenter` 为主。
- 解释产品原理可叠加 `aigc-commercial`，区分知识结论与产品宣传主张。
- 不把平面/三维动画当作用途类型；不因选择本模块而强制使用拟人化或统一教学风格。

## 最小输入与公共协议

- 最少需要受众基础、要回答的问题、目标时长、已知来源与本轮范围；完整讲稿优先审查，不重新访谈全套需求。
- 将内容分为已核实主张、教学简化、类比、尚待核实；时效性、专业细节或高风险知识用可靠的一手资料核验。
- 用户已明确完整 AIGC_Lab 工作区时，先核对该根的 `README.md`、`AGENTS.md`、`spec/harness-engineering.md` 与 `skills/catalog.json`，确认项目契约和本叶 skill 的归属；优先读取该根 `skills/aigc-creator/references/`，不让旧全局入口覆盖指定工作区。
- 脱离项目时，从当前包的实际安装根或 `aigc-creator` 元数据定位总控，比较叶节点与总控的 metadata.bundle / metadata.bundle_version 确认版本配套；缺文件、版本不符或无法确认同版本时报告，不猜路径或静默回退。
- 按以上规则定位总控后，以其目录为基准读 `references/handoff.md`、`references/prompt-language.md`；需要措辞或参数时按需读 `references/lexicon.md`、`references/model-adaptation.md`。
- 缺少依赖时明确报告；公共协议不从跨包相对路径猜测。
- 每镜头记录相机、角色/主体、画面及前后状态；重要概念主体、变化动作、不能画错的关系前置，不承诺跨模型权重。

## 节点取舍

| 条件 | 节点与交接 |
|---|---|
| 学习目标或受众未知 | `aigc-prd` 明确观众看完能解释什么 |
| 机制、来源和类比 | `aigc-script` 建“主张—依据—图像映射—限制” |
| 抽象图形或实体解剖需复现 | `aigc-visual-assets` 锁颜色含义、结构与尺度；无人物不做角色三视图 |
| 图元迁移、空间遮挡或多对象交换 | `aigc-blocking` 记录关系；静态图解可并入 `aigc-storyboard` |
| 关键结构必须精确 | `aigc-keyframes` 校对结构，再由 `aigc-video-prompts` 描述变化 |
| 解说与图解同步 | `aigc-audio`、`aigc-editing`；用实际配音核对节奏，再 `aigc-review` |

## 专用创作判断

1. 先写一条最终答案和必要前提，再倒推解释步骤。短片容纳不下时收窄问题，不把省略过程伪装成完整解释。
2. 每条主张指定画面对应关系：对象代表什么，箭头表示因果/流向/时间哪一种，大小/颜色是否承担数值意义。
3. 类比写“对应什么、帮助理解什么、不对应什么”。垃圾桶、工厂、老师等隐喻不能偷渡目的、意识或实体结构。
4. 区分原理示意、测量数据和实际内部影像；示意粒子数量、比例或速度不作为定量证据。数据有来源、单位、范围和时间。
5. 一次视觉变化承担一个解释任务，保持术语和颜色映射稳定。新增箭头、颜色、形状应有解释意义。
6. 按认知步骤、图像建立时间和配音停顿决定镜头数；镜头切得快不等于信息容易吸收，不设统一的三镜或每镜五秒。
7. 标签与字幕优先后期精确排版；旁白、标签与动画出现顺序一致，先建立对象再展示作用，不提前泄露尚未解释的符号。

## 已填文字示例

教学模型：向初学者解释“按阈值分卡片的规则如何根据错误调整”，24 秒；这只是人为设定的玩具分类器，不代表所有 AI 训练。

本例规则和数据由题目定义：数值大于等于阈值判“高”，训练卡 2 标“低”、卡 8 标“高”；初始阈值 9，改为 5 后两张训练卡判断正确。

| 主张 / 依据 | 视觉映射与边界 |
|---|---|
| 阈值 9 将卡 8 判低，与给定标注不符 / 本例规则可直接计算 | 数轴上 8 在阈值左侧；不称为真实神经网络内部 |
| 阈值改 5 可修正这两张训练卡 / 逐项比较可核对 | 阈值线左移，卡片数值与标注不变；不能推出未知卡都正确 |
| 已知题做对不等于泛化良好 / 本例还没有测试集结果 | 最后保留未知卡，不动画演成自动答对 |

选 3 镜、7+10+7 秒：建立规则、看到错误及调整、提出新样本检验；中间镜更长以便看清阈值移动。

| 镜头 | 相机 / 主体 / 画面 | 前态 → 后态 |
|---|---|---|
| EP01_SH001，7秒 | 固定正视；卡2、卡8和阈值9；数轴及“低/高”后期标签 | 两卡待判断 → 两卡均在阈值左侧，卡8显示错误标记 |
| EP01_SH002，10秒 | 固定正视；卡片不动、阈值线移动；颜色映射不变 | 阈值9 → 阈值5，卡8转为高类，错误标记移除 |
| EP01_SH003，7秒 | 固定正视；新空白卡进入右侧待测区；旧卡与规则仍可见 | 已知卡正确 → 新卡待测，留问号由后期添加 |

第二镜可发送草案：

```text
两张矩形卡片保持固定位置，竖直分界线从较右位置缓慢向左移动并停在两张卡片之间；卡片形状、颜色、位置全程不变。固定正视的简洁二维示意，浅色背景，分界线移动路径清楚。画面不自动生成数字、标签或箭头；数值、分类结果和错误标记由后期按教学脚本精确叠加。
```

## 专用验收与交付

- 输出目标问题、主张/依据表、简化与类比边界、图像映射、分镜与解说；未核实事实不写进可发布结论。
- 逐项检查方向、因果、数量/单位、术语、尺度与画面一致；让目标受众复述核心机制属于独立理解度验证。
- 文字校验、专业审查、受众理解测试和媒体检查分别记录；没有实际音轨/画面时不声称同步或科学成片验收通过。

## 训练题

- 正常：用上述规则和卡片制作 24 秒解释，给可计算的判断、图像映射、3 镜时长与结尾限制；不得把玩具规则称为所有 AI 的真实训练流程。
- 边界：用户要求“画一颗人脑吞入数据，就能准确解释全部 AI 学习”。保留易懂的诉求，说明类比映射与不能涵盖的机制，给有限命题的方案；事实依据不足的结论留待核实，不自动推广。
