# aigc-montage（混剪回顾）｜调用模板与使用方法

在 AIGC_Lab 内读取本项目同版本 Skill 源码和配套协议，不混用旧全局安装副本。

这是我发给 Codex 的调用模板，用来从实际素材选择片段并计算时间线。`【填入】` 供调用时替换，最终剪辑说明须展开且指向真实来源。

## 什么时候用，最少说什么

- 我要把已有影像做成回顾、精选片段或意象混剪时使用。
- 最少说：可访问素材或可靠观察记录、用途、总时长、顺序约束、声音条件和本次范围。
- 已有完整剪辑 brief 直接使用；先核对可用素材，不重做全部创作链。
- 短口令：**“按这些真实素材做20秒混剪，给源入出点和完整时间线。”**

## 可复制调用模板

```text
请使用本项目源码中的 $aigc-montage。
用途与目标：【活动回顾／精选／概念混剪；想让观众看到什么】。
总时长与画幅：【目标时长、比例、是否允许变速】。
实际素材：【可访问文件／链接或观察记录，时长、画幅、收音】。
素材核验状态：【已经看过／用户转述／未看；可用区间依据】。
排序与保留：【真实时间顺序、必留片段、不可制造的因果】。
声音要求：【保留原声、音乐来源、允许的声音跨接】。
转场与缺口：【硬切／叠化等偏好；缺口待看素材后判断】。
本次做到：【素材清点／编辑结构／剪辑表／局部修改】。
请列源入点、源出点、速度、转场重叠和时间线总长，并注明出点规则。
只准备文字，不生成补充现场、不导出或发布视频。
```

## 已填例子

以下为题目提供的虚构教学观察清单，尚无实际文件可播放。

```text
请使用本项目源码中的 $aigc-montage。
做20秒、16:9工作坊回顾练习，全段1倍速、硬切、不加音乐。
A01总长12秒：空教室与工作台，间接记录称[2,8)秒构图稳定。
A02总长14秒：双手折纸，间接记录称[3,11)秒由展开到压平折痕。
A03总长10秒：完成纸作在桌上，间接记录称[1,7)秒无遮挡。
三段按真实发生顺序排列是本题条件；出点排他，不知道帧率。
请根据记录先给20秒剪辑表和理由，不声称你已查看真实素材。
保留各段低音量环境声，不拼入别处欢呼，不称为完整折纸教程。
算清源范围与时间线；需要实看才能确定的切口和声音问题列为待验。
只准备文字，不生成假现场、不制作或发布成片。
```

## 我会得到什么，接着怎么用

1. 素材清单与已看／未看状态、实际可用区间和当前不能判断的缺口。
2. 源入出点、速度、转场重叠、时间线与选择理由，核对总长和事件关系。
3. 补齐可访问素材后核对实际切口；确认剪辑表后再执行剪辑、混音和完整播放。

## 这个类型要先备好什么

- 只给文件名或“有三段素材”不足以知道内容，不能先编出开场、互动和高潮。
- 观察记录是间接依据，实际源时间码和声音可用性要回到文件核验。
- 变速与转场重叠改变总长；秒级计划不能冒充已知帧率的精确帧级 EDL。
- 全用已有素材时跳过参考图、首帧和生成节点；补充生成需要另有明确范围授权。
- 剪辑表完成不等于成片完成，切口、音量、事实关系与连续播放仍需媒体验收。
