# aigc-montage（混剪回顾）

先知道手里有什么，再决定怎样连起来；剪辑节奏不能替代素材事实。

需要复制调用或查看使用方法时，读[我的调用模板与用法](references/usage.md)。

每次面向用户交付的最后一段，读取同版本总控 `references/handoff.md` 的“面向用户的结尾衔接”，加粗提示下一节点、携带本轮哪些成果及继续口令；缺项按实际依赖选择补齐或草案续接，当前范围结束则明确停止。

作品素材与成片的观看验收按同版总控 `references/handoff.md` 的“用户媒体验收与反馈”执行：用户在LibTV观看确认，Codex负责文字自检及按反馈修改。

## 适用边界

- 适用：活动回顾、素材混剪、精选片段、已有影像重新编排和声音连接。
- 不适用：从零生成全部剧情以 `aigc-narrative`（剧情与漫剧） 为主；按曲目节拍主导的混剪可叠加 `aigc-music`（音乐影像）。
- 活动真实性要求高时叠加 `aigc-documentary`（纪实与重建）；非事件关联的意象混剪明确其概念表达，不暗示真实因果。
- 素材形态和画幅不是用途类型；保留用户的排序、风格与删改边界。

## 最小输入与公共协议

- 最少需要可访问素材或可靠逐段观察记录、目标用途、总时长、排序约束、声音条件与授权范围。
- 清单记录素材 ID、实际文件/来源、时长、画幅、内容观察、收音、可用区间及是否已看；没看过不写“开场/高潮/互动”。
- 用户已明确完整 AIGC_Lab 工作区时，先核对该根的 `README.md`、`AGENTS.md`、`spec/harness-engineering.md` 与 `skills/catalog.json`，确认项目契约和本叶 skill 的归属；优先读取该根 `skills/aigc-creator/references/`，不让旧全局入口覆盖指定工作区。
- 脱离项目时，从当前包的实际安装根或 `aigc-creator`（全链路创作总控） 元数据定位总控，比较叶节点与总控的 metadata.bundle / metadata.bundle_version 确认版本配套；缺文件、版本不符或无法确认同版本时报告，不猜路径或静默回退。
- 按以上规则定位总控后，以其目录为基准读 `references/handoff.md`、`references/prompt-language.md`；需分析截图读 `references/screenshot-analysis.md`。
- 生成补充片段才按需读其 `references/model-adaptation.md`；缺依赖时报告，不臆测文件或素材内容。
- 每个选段写相机/原始机位、人物/主体、画面及入出状态；主体、关键动作和不能改变的事实前置，已有素材不必重写生成提示词。

视频提示词交付：用户本步要求生成视频提示词时，在同一交付中由 `aigc-video-prompts`（视频提示词） 按同版总控 `references/clip-prompts.md` 后台编译，每条 Clip 只交一个保留完整六区块与 STYLE LOCK 八项的主复制稿，不让用户再调用一次。平台未知时交完整通用稿，框外注明适配未执行，不另给扁平化稿；只有已核验入口明确要求格式编译/字段分流，或用户明确要另版时，才额外提供对应平台适配版。以下导演表达或输入分工片段不是 Clip 发送稿；用户只要策划或图片时保持本步范围，图片提示词不套六区块。

## 节点取舍

| 条件 | 节点与交接 |
|---|---|
| 用途、时长或排序目标未知 | `aigc-prd`（创作需求）；已有剪辑 brief 则只核对可用素材 |
| 全部使用现有素材 | `aigc-script`（剧情脚本） 写编辑结构，`aigc-storyboard`（分镜设计） 写选段，再 `aigc-editing`（剪辑时间轴） |
| 不生成任何新画面 | 跳角色资产、人物调度、关键帧与视频生成节点；素材 ID 仍持续使用 |
| 音轨、原声、J/L-cut | `aigc-audio`（声音制作） 记来源与声音跨接，不能让声音暗示错误现场关系 |
| 素材确认存在缺口 | 先找同场原素材或提出补拍；用户批准生成装饰段才调用`aigc-video-prompts`（视频提示词），仅首帧/首尾帧入口或明确端点控制调用`aigc-keyframes`（静态关键帧） |
| 交付 | Codex自检剪辑表算术与事件描述；用户在LibTV观看实际衔接及完整成片并反馈 |

## 专用创作判断

1. 先看素材并记录实际内容，再给选段功能。用户文字描述作为间接依据标注，不能改写成 Agent 已亲眼看到。
2. 入点和出点采用同一时间码规则；明确出点是否排他、帧率是否已知。秒级计划不伪装成精确帧级 EDL。
3. 每段记录源入点、源出点、源时长、速度、时间线入出与理由；变速后时长和转场重叠都要计入总长。
4. 先保证动作完整和空间可读，再决定动作匹配、形状匹配、节奏或声音桥。相似手势不能证明两人真实互相回应。
5. 记录前段出画状态与后段入画状态：方向、动作阶段、视线、构图重心、声音持续；无法连续时选择明确转场或承认时间跳转。
6. 镜头数由可用素材、行动完整性与观看节奏决定；不能为凑总长平均分配每段，也不强设“三段素材各六秒”。
7. 缺口具体写“哪项叙事信息未被哪段素材支持”；没看素材时缺口是待判断。生成补充不能冒充同场录像，补拍注明时间变化。

## 已填文字示例

教学夹具，以下为题目给定的观察清单，并非声称已查看用户文件；三段均已获此教学用途授权，同一工作坊依真实时间先后拍摄，无转场重叠、全段 1 倍速。

| 素材 | 总长与可用内容 | 可用源区间 |
|---|---|---|
| A01 | 12秒，固定广角，空教室与工作台，无人声 | [2,8)秒，构图稳定 |
| A02 | 14秒，固定桌面近景，双手折纸，无需完整呈现教程 | [3,11)秒，折叠动作从展开到压平 |
| A03 | 10秒，固定中景，完成的纸作摆在桌上，轻微环境声 | [1,7)秒，无人进入遮挡 |

目标 20 秒回顾，用 3 段是为建立地点、展示过程、落在成果；时长 6+8+6 秒，折叠过程获得更长观看时间。

| 镜头 / 时间线 | 源入出 / 速度 | 相机、主体、画面与前态 → 后态 |
|---|---|---|
| EP01_SH001 / [0,6) | A01 [2,8)，1× | 固定广角、工作台、空教室；静止环境 → 静止环境 |
| EP01_SH002 / [6,14) | A02 [3,11)，1× | 固定桌面近景、双手纸张、桌面居中；展开纸 → 压平折痕 |
| EP01_SH003 / [14,20) | A03 [1,7)，1× | 固定中景、完成纸作、工作台；作品静止 → 保持静止 |

转场：两处硬切，广角→近景为视点变化，折纸→成果为明确省略过程，不宣称完整折纸教程。原声分别保留低音量，不从其他时间拼入欢呼；本例没有生成画面，因此无需可发送生成提示词。

## 专用验收与交付

- 交付素材清单、实际已看/未看状态、源入出点、速度/转场、时间线总长、衔接理由与缺口；未证实的素材不可标可用。
- 文字审查计算总时长与源范围、出点规则一致、排序不制造错误因果；实际检查切口跳动、声音突变、音量和完整播放。
- 只有剪辑表时导出/播放为 NOT_RUN；静态截图和上传成功不能证明最终混剪节奏或声音通过。

## 训练题

- 正常：用上述 A01/A02/A03 观察清单完成 20 秒剪辑表，给源入出与时间线，解释三段时长和从过程跳到成果的含义。
- 边界：用户只说“三段已授权活动素材，做 20 秒”，尚未提供或描述。登记未看与必要素材字段，给条件式结构预算；不将素材命名为开幕、互动、高潮，不编时间码或已确认缺口，也不先生成假现场补镜。
