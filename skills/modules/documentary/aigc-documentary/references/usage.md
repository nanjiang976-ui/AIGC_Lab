# 纪实与生成重建：我的调用模板

在 AIGC_Lab 内读取本项目同版本 Skill 源码和配套协议，不混用旧全局安装副本。

这是我发给 Codex 的调用模板，用来整理真实来源与视觉重建边界。`【填入】` 是调用字段；最终旁白、来源说明和生成正文必须展开。

## 什么时候用，最少说什么

- 我要讲真实事件、历史、人物经历，或在纪实中插入生成重建时使用。
- 最少说：主题、时间地点范围、现有来源、时长、是否允许重建、本次范围。
- 完整调查材料直接交给 Codex 核对；只问影响事实叙述的关键缺口。
- 短口令：**“按这些来源做纪实方案，每镜标清真实记录还是生成重建。”**

## 可复制调用模板

```text
请使用本项目源码中的 $aigc-documentary。
主题与范围：【事件／人物、时间、地点；争议范围】。
受众与时长：【给谁看、总时长、画幅】。
现有来源：【原文、真实链接或可访问资料；各自支持什么】。
核验状态：【亲见原件／转述／待核实；冲突和未知】。
可用影像与声音：【真实素材、原声、使用条件；没有写没有】。
允许重建的范围：【哪些段可重建；哪些必须用真实材料】。
叙述边界：【必须保留的事实、不能补写的行为或心理】。
本次做到：【资料核对／事实脚本／逐镜方案／重建Clip文字】。
请分清真实记录、后来补拍、示意图和生成重建，并给标识方案。
只准备文字，不生成或发布媒体。
```

## 已填例子

以下为虚构教学夹具，S01、S02是本段给定文本记录，未提供真实档案或文件。

```text
请使用本项目源码中的 $aigc-documentary。
练习18秒纪实结构：虚构事件是社区图书室因漏水暂停阅读区开放。
S01：2012年6月3日的管理记录文字“阅读区暂时关闭”。
S02：题目描述一张次日照片显示两只接水桶；没有照片原件可看。
请将S01视为给定摘录、S02视为间接观察记录，不声称你看过真实材料。
没有当天录像，不知道恢复开放时间，也没有居民抢救图书的证据。
可提出漏水环境的生成重建方案；持续标注“情景重建，非现场影像”。
请交事实来源矩阵、逐镜身份、旁白和待补资料，保留两条来源的时间差。
这个练习只检查文字流程，不把虚构事件当真实历史，也不编下载路径。
只准备文字，不生成媒体。
```

## 我会得到什么，接着怎么用

1. 来源清单、事实对应关系、冲突与未知，区分原始资料和间接转述。
2. 逐镜素材身份、旁白和声音来源，以及重建段持续标识与视觉限制。
3. 补齐资料再确认叙述；只有允许重建的部分进入资产或 Clip，真实档案直接进入剪辑。

## 这个类型要先备好什么

- 来源应能定位到原文、页码或时间；仅写“网上看到”不能作为已核实依据。
- 生成重建只能表现有依据的范围，不能反过来证明真实人物的行为、心理或台词。
- 现场原声、后配旁白和拟音分别记录；剪辑也不能制造错误的时间或因果关系。
- 不生成的真实档案段跳过首帧；重建段按平台入口或端点控制决定关键帧。
- 文本核对与实际标识可读、完整播放分别验收；没有媒体就保留未执行。
