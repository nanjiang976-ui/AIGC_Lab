# 商业广告与品牌短片

先确定观众需要记住或采取的行动，再让每项产品主张对应证据和镜头。

## 适用边界

- 适用：品牌认知、促销、产品亮相、使用情境广告；传播目标为主。
- 不适用：教用户完成真实软件操作的教程以 `aigc-product-demo` 为主；无产品或品牌目标的抽象影像用 `aigc-visual-art`。
- 剧情广告可叠加 `aigc-narrative`，但人物戏不能改变产品外观或把虚构情节当使用证明。
- 2D、3D、竖屏只是表现约束；本模块不声称覆盖所有商业片形态，也不替用户决定品牌定位。

## 最小输入与公共协议

- 最少需要产品身份与外观依据、目标观众、传播目的、时长、核心主张及可用证据、交付范围。
- 资料缺少时仍可做明确标注的概念方案；真实产品外观和性能没有依据时不能宣称“可正式投放”。
- 用户已明确完整 AIGC_Lab 工作区时，先核对该根的 `README.md`、`AGENTS.md`、`spec/harness-engineering.md` 与 `skills/catalog.json`，确认项目契约和本叶 skill 的归属；优先读取该根 `skills/aigc-creator/references/`，不让旧全局入口覆盖指定工作区。
- 脱离项目时，从当前包的实际安装根或 `aigc-creator` 元数据定位总控，比较叶节点与总控的 metadata.bundle / metadata.bundle_version 确认版本配套；缺文件、版本不符或无法确认同版本时报告，不猜路径或静默回退。
- 按以上规则定位总控后，以其目录为基准读取 `references/handoff.md`、`references/prompt-language.md`；外观措辞按需读 `references/lexicon.md`。
- 需要平台参数时再读其 `references/model-adaptation.md` 并核验当前能力；找不到依赖时报告，不猜目录。
- 每镜头写相机、角色/主体、画面三要素及前后状态；主体、动作、外观/文案硬约束前置，不宣称提示词位置普遍决定模型权重。

## 节点取舍

| 条件 | 节点与交接 |
|---|---|
| 传播目标、受众或行动未定 | `aigc-prd`；已有完整 brief 时只核对冲突 |
| 主张和镜头功能 | `aigc-script` 写“主张—证据—可见表达—行动” |
| 真实产品复现 | `aigc-visual-assets` 锁型号、轮廓、材质、颜色、Logo 与参考角度 |
| 人手使用或拆装 | `aigc-blocking` 检查持握、接触、开合、受力；静物旋转可直接进 `aigc-storyboard` |
| 外观可控性重要 | `aigc-keyframes` 校对再到 `aigc-video-prompts`；已有批准镜头则不重建 |
| 旁白、字幕与转化信息 | `aigc-audio`、`aigc-editing`、`aigc-review`；无口播可跳配音，但仍检查实际音轨 |

## 专用创作判断

1. 给每条 claim 一个证据槽：原句、来源、适用型号/条件、允许表达、禁越范围。数字、排名、对照与可视化暗示一起检查。
2. 区分事实卖点、可观察外观和品牌情绪。“带侧把手”可由图像确认，“全天保温”不能由外观或蒸汽推导。
3. 缺证据的主张提出删除、降为可证实描述或待补依据的选项；不要为维持广告力度自行替换成另一条无据卖点。
4. 产品锁定到可比较特征：盖型、接缝、开口、比例、颜色、Logo 位置。相机旋转不等于产品变形；背面未知时不编造结构。
5. 主镜头显示一个主要利益或动作；先让观众看懂产品，再安排氛围。镜头数由信息量、动作可读性与品牌停留时间决定并解释。
6. 使用效果、前后对比、顾客证言和实验画面须与依据相符；生成画面不能冒充真实测试记录。
7. Logo、价格、型号、活动时间与 CTA 精确字形交后期；保留版式安全区，核对实际发布规格而非固定套用比例。

## 已填文字示例

教学虚构产品 C01：无品牌浅灰陶瓷杯，圆口、直筒杯身、杯高约为杯口直径的 1.2 倍、单个右侧环形把手；本例输入有批准正面参考，未提供性能测试。目标：15 秒传达“给自己一刻停顿”。

| 主张 | 依据与表达决定 |
|---|---|
| 浅灰杯身、侧把手 | 本例批准参考可见；允许忠实表现 |
| 给自己一刻停顿 | 创意邀请，不作为性能或健康效果承诺 |
| 保温 100 小时 | 无依据；本方案不使用，也不以计时器暗示 |

选 3 镜、4+6+5 秒：产品识别、一次使用动作、品牌信息停留各有任务，最后 5 秒给文案阅读。

| 镜头 | 相机 / 主体 / 画面 | 前态 → 后态 |
|---|---|---|
| EP01_SH001，4秒 | 固定正面近景；C01 静止；右把手完整、后景柔化 | 空白后期文字区保留 → 产品仍居中，不变形 |
| EP01_SH002，6秒 | 固定侧前方中近景；手握把手将杯平移靠近自己；桌面水平线稳定 | 杯在桌面中央 → 杯仍接触桌面并停在人物前，手未离开 |
| EP01_SH003，5秒 | 同方向固定近景；手放开退出；产品左侧留文案区 | 手仍持杯 → 杯静止、手退出，后期加入创意文案 |

第二镜可发送草案：

```text
一只无品牌浅灰陶瓷杯，圆形杯口、直筒杯身，杯高约为杯口直径的 1.2 倍，右侧只有一个环形把手。一只成年人的右手握住把手，将杯沿水平桌面缓慢拉近并停住，全程不抬杯、不改变杯型与比例。固定侧前方中近景，杯与桌面接触处可见，柔和窗光，背景安静。杯身不出现 Logo、性能数字或装饰文字。
```

## 专用验收与交付

- 输出主张/证据表、外观锁定表、镜头目的与时长、三要素/状态及后期文案；未核验的型号、价格、活动信息明确留待确认。
- 文字检查确认每个主张及视觉暗示有相应依据，CTA 与原目标一致，卖点没有靠生成画面“自证”。
- 媒体检查逐帧比较外观、接触和文字，再在目标尺寸连播核对阅读；无实际媒体时为 NOT_RUN，不宣称投放审核通过。

## 训练题

- 正常：用上述 C01 资料写 15 秒概念广告，保留用户文案，给主张/证据表与完整分镜；检查三镜为何必要、产品外观如何锁定。
- 边界：用户只给正面图并要求“杯身转 360 度，展示全网第一且保温 100 小时”。交付可做的正面展示草案，分别列出背面结构和性能依据缺口；不虚构背面与测试结果，不把未经证实的断言放进发送稿。
