# aigc-commercial（商业广告）｜调用模板与使用方法

在 AIGC_Lab 内读取本项目同版本 Skill 源码和配套协议，不混用旧全局安装副本。

这是我发给 Codex 的调用模板，用来把传播目标、产品外观和可证实主张组织成广告。`【填入】` 供调用时替换，不能留在生成模型正文中。

## 什么时候用，最少说什么

- 我要做产品广告、品牌短片、商品亮相或使用情境展示时使用。
- 最少说：产品是什么、给谁看、希望对方记住或做什么、时长、主张与依据、本次范围。
- 已有完整 brief 直接贴上；只补影响本次表达或外观的冲突与缺口。
- 短口令：**“给这件产品做15秒概念广告，先检查卖点证据，再写调度。”**

## 可复制调用模板

```text
请使用本项目源码中的 $aigc-commercial。
产品与型号：【名称、型号；虚构产品请写明】。
外观依据：【实际参考图／已确认文字设定；缺少角度请说明】。
目标观众与传播目的：【给谁看；记住什么或采取什么行动】。
主张与证据：【卖点原句；来源、适用条件；无依据写待核实】。
时长与表现：【总时长、画幅、视觉风格】。
必须保留：【产品结构、颜色、品牌文案、CTA】。
现有资料：【brief、包装、素材实际位置；没有写没有】。
本次做到：【概念／广告脚本／完整调度／Clip文字包】。
请区分外观事实、性能主张和情绪表达；精确Logo与文字给后期方案。
只准备文字；不要调用媒体生成或投放工具。
```

## 已填例子

以下产品是本次虚构创意设定；文字设定不代表已有产品照片或性能证据。

```text
请使用本项目源码中的 $aigc-commercial。
为虚构无品牌浅灰陶瓷杯做15秒、9:16、写实概念广告。
外观设定：圆口、直筒杯身、右侧单个环形把手，杯高约为杯口直径的1.2倍。
目标观众是忙碌的上班族；希望记住“给自己一刻停顿”，没有购买链接。
本次只使用上述外观设定和这句创意邀请，不宣称保温、健康或效率效果。
没有产品参考图，也没有性能测试；请将外观复现所需资料列为后续依赖。
我想先识别杯子，再看手将杯沿桌面拉近，最后给文案停留时间。
请检查每条主张与视觉暗示的依据，再写完整调度和镜头时长理由。
杯子接触桌面的状态要清楚，Logo和精确文字交后期，不在画面中生成字形。
平台待定，只准备文字，不生成或发布广告。
```

## 我会得到什么，接着怎么用

1. 主张与证据对应表、产品外观约束、缺失依据和允许表达的范围。
2. 按本轮范围得到概念、广告脚本或调度，包含产品接触动作和后期文案位置。
3. 补齐实际产品参考后，可继续做参考资产或 Clip；正式投放另核对真实产品与发布资料。

## 这个类型要先备好什么

- 真实产品需要型号一致的外观依据；只有正面图时不凭空补出背面结构。
- 数字、排名、对比与使用效果都需要相应证据；生成画面本身不能证明性能。
- Logo、价格、活动时间和 CTA 要有准确原文；未确认项不冒充最终信息。
- 首帧只是平台入口或外观端点控制的一种支路；身份／产品参考不自动等于首帧。
- 文字方案通过不表示产品复现、媒体效果或平台投放审核已经通过。
