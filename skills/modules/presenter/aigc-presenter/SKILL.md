# 主持人与数字人口播

先让话说得自然、重点听得清楚，再用克制动作服务表达。

## 适用边界

- 适用：讲师口播、主持开场、虚构数字人、出镜解说和以说话人为中心的介绍。
- 不适用：角色冲突推动情节时用 `aigc-narrative`；需科学机制解释时叠加 `aigc-explainer`。
- 真人出镜素材可沿用，但身份、声线与肖像来源需明确；未给身份时使用原创虚构角色，不虚构职业资质或真人背书。
- 是否出镜、真人还是虚构人物、口音与性格由用户决定，不把数字人口播当所有知识内容的默认形式。

## 最小输入与公共协议

- 最少需要讲给谁听、核心信息/现有讲稿、总时长、人物身份来源、声音偏好及交付范围。
- 完整稿件先保留事实与意图；只在影响可说性、时长或表达清晰时提出具体改句，不擅自更改承诺。
- 用户已明确完整 AIGC_Lab 工作区时，先核对该根的 `README.md`、`AGENTS.md`、`spec/harness-engineering.md` 与 `skills/catalog.json`，确认项目契约和本叶 skill 的归属；优先读取该根 `skills/aigc-creator/references/`，不让旧全局入口覆盖指定工作区。
- 脱离项目时，从当前包的实际安装根或 `aigc-creator` 元数据定位总控，比较叶节点与总控的 metadata.bundle / metadata.bundle_version 确认版本配套；缺文件、版本不符或无法确认同版本时报告，不猜路径或静默回退。
- 按以上规则定位总控后，以其目录为基准读 `references/handoff.md` 和 `references/prompt-language.md`；表演措辞按需读 `references/lexicon.md`。
- 具体工具的音色、口型、输入时长等由其 `references/model-adaptation.md` 和当前官方能力核对；缺依赖不假定平台支持。
- 每镜头记录相机、人物/主体、画面及前后状态；人物、发言/动作、身份与视线硬约束前置，不声称跨模型位置权重。

## 节点取舍

| 条件 | 节点与交接 |
|---|---|
| 受众、身份或表达目的不清 | `aigc-prd`；现有完整讲稿不重新全问卷 |
| 声音稿与说话节奏 | `aigc-script` → `aigc-audio`，实际声音优先决定可用时长 |
| 讲师持续复现 | `aigc-visual-assets` 锁脸、发型、服装；已有授权可用母版直接引用 |
| 坐姿固定、无复杂互动 | 调度可在 `aigc-storyboard` 内写清手势/视线，不单独展开 `aigc-blocking` |
| 走位、持物或与屏幕互动 | `aigc-blocking` 锁定轨迹与指向，再做分镜 |
| 静态驱动或视频生成 | 按平台条件选 `aigc-keyframes`、`aigc-video-prompts`，已有完整实拍可跳生成 |
| 字幕、插图、口型验收 | `aigc-editing` → `aigc-review`；只交文本不宣称配音、口型已验证 |

## 专用创作判断

1. 先按意群断句，再标重音、停顿、语气转折。把说明书式长句拆成能一口说清的句子，保留用户明确措辞。
2. 用试读或实际音轨测时；按字数估算只作为计划，不承诺“多少字一定等于多少秒”。过长时优先删冗余，再由用户决定改时长或信息量。
3. 声音说明用音域、速度、力度、咬字与情绪距离；“专业、亲切”要落到可听表现，不借真实名人姓名暗示已授权音色。
4. 每个手势对应一个信息转折，记录开始、峰值、收回；避免每个字都点头、摆手或同步字幕逐字跳动。
5. 眼神对准镜头或已定义提示对象，指屏幕时手指目标与画面位置一致；插入素材后回到主持人的身体状态也应连贯。
6. 镜头数量由信息章节、表演持续性和补充画面需求决定。单镜口播也可成立，不能为了活泼强塞切镜。
7. 生成头像与配音分别合格不等于口型合格；实际检查辅音闭口、长元音、停顿、吞音、齿唇异常和声画偏移。

## 已填文字示例

教学虚构讲师 P01：原创成年人物，椭圆脸、深棕色眼睛、短黑发、无胡须、中等偏暖肤色，浅蓝无标识衬衫，普通话自然中低音，无真人参照；30 秒介绍“今天只先推进一件事”。

声音稿：

```text
每天一打开电脑，消息就把注意力拉走了？今天先试一件小事。
把最想推进的任务写在纸上，再写下现在能做的第一步。
比如，先列三个提纲，不急着写完全文。
给这一步留一段安静时间。做完以后，再决定下一步。
```

停顿指导（不朗读）：第一句问号后稍停；“纸上”“三个提纲”后的逗号轻停；“安静时间”句末稍停，再进入结尾。

计划用 1 个 30 秒固定中近景，保持交流感，后期在中段短暂叠加纸卡；这是一段建议示范，不宣称效率效果已验证。实际音轨若不足或超时再调节停顿与稿件。

| 时间计划 | 相机 / 人物 / 画面 | 前态 → 后态 |
|---|---|---|
| 0–8秒 | 固定中近景；P01 看镜头、手自然放腹前；浅灰背景 | 放松站姿 → 说“试一件小事”时轻抬右手 |
| 8–22秒 | 同机位；右手开放手势后收回；右侧出现后期纸卡 | 手略抬 → 手收回、视线仍向镜头；纸卡不遮脸 |
| 22–30秒 | 同机位；轻微点头结束；纸卡渐隐 | 双手自然 → 保持自然姿势，结尾留静止尾量 |

画面可发送草案：

```text
一位原创虚构成年讲师，椭圆脸、深棕色眼睛、短黑发、无胡须、中等偏暖肤色，穿浅蓝无标识衬衫，面向镜头自然说话。固定中近景，双手起初自然放于腹前，说话期间右手缓慢做一次开放手势并收回，结束后保持自然姿势。浅灰背景，人物左侧留字幕安全区，柔和正面光，表情克制，不添加身份徽章或背景文字。
```

## 专用验收与交付

- 交付声音稿、意群/重音/停顿、声音身份来源、镜头与动作时间计划、字幕文字及实际测时状态。
- 文字审查关注信息准确、读起来顺畅、动作与语义相符；实际音频检查发音、噪声、节奏，媒体检查口型和字幕对齐。
- 未生成时口型/试听/身份使用确认按真实进度记录；虚构讲师不冒充真人或已持有资格的专家。

## 训练题

- 正常：基于上述 30 秒虚构讲师题给声音稿、一个镜头和动作安排，指出哪些时间只属计划，哪些要用实际音轨测量。
- 边界：用户交来约 300 字稿并要求 15 秒慢速亲切口播，同时说“长得像某位真人，没他的授权”。指出节奏冲突，给保留核心信息的短稿与原创身份方案供选择；不把未授权真人作为已批准母版，不声称口型可直接通过。
