# 主持人与数字人口播：我的调用模板

在 AIGC_Lab 内读取本项目同版本 Skill 源码和配套协议，不混用旧全局安装副本。

这是我发给 Codex 的调用模板，用来安排可说的稿件、声音与手势。`【填入】` 只给调用时填写，实际朗读稿和生成正文须去掉字段说明并展开。

## 什么时候用，最少说什么

- 我要做讲师、主持、数字人或以说话人为中心的介绍时使用。
- 最少说：给谁听、讲什么、时长、人物与声线来源、本次交付范围。
- 已有完整讲稿先保留原意，检查可说性和时长；不重新采访整部作品。
- 短口令：**“把这段稿改成自然口播，标停顿和手势，先不生成。”**

## 可复制调用模板

```text
请使用本项目源码中的 $aigc-presenter。
受众和表达目的：【讲给谁；听完记住什么】。
讲稿或核心信息：【贴原稿；可改与不可改部分】。
时长与画面：【总时长、画幅、站／坐姿、背景】。
人物来源：【原创虚构／本人／已有授权人物；实际参考说明】。
声音偏好与来源：【语言、音域、语速、力度；实际音轨或待制作】。
动作约束：【视线、手势、持物；没有可写请设计克制动作】。
平台和现有材料：【已知平台、图、音频、实拍；没有写没有】。
本次做到：【口播稿／声音方案／镜头动作／完整文字包】。
请把朗读文本与不朗读的表演指导分开；估算时间与实测状态分开。
只准备文字，不制作头像、配音或视频。
```

## 已填例子

以下人物为原创虚构，尚无参考图和音轨。

```text
请使用本项目源码中的 $aigc-presenter。
做30秒、9:16的原创成年讲师口播，讲给容易被消息打断的办公人群。
核心信息：先写下最想推进的任务，再选现在能做的第一步。
例子使用“先列三个提纲”；结尾保持建议口吻，不承诺效率提升。
人物设定为短黑发、椭圆脸、深棕眼睛、浅蓝无标识衬衫，无真人参照。
声音用普通话自然中低音，清楚但不播音腔，意群间留短停顿。
固定中近景，视线向镜头，只在提出第一步时做一次开放手势并收回。
请写朗读稿、停顿重音、手势时间计划和字幕文字，指出时长只是估算。
没有音轨和头像，平台待定；不要声称口型或试听已经通过。
本次只准备文字，不生成媒体。
```

## 我会得到什么，接着怎么用

1. 可朗读稿，以及单独的意群、重音、停顿、音色与动作指导。
2. 镜头和手势计划、字幕文本、声音身份来源和实际测时状态。
3. 获得真实音轨后再调整节奏；媒体生成后逐段查发音、口型、声画偏移和字幕。

## 这个类型要先备好什么

- 人物和声音来源要明确；没有真人参照时可采用原创虚构设定，不虚构职业资质。
- 实际音轨决定可用时长，字数估算不能证明30秒一定装得下全部内容。
- 角色身份与本片衣装分别定义；参考图或现成头像是否可用，要按实际入口检查。
- 只有平台要求静态驱动／首尾帧或我明确要求端点时，才需要对应关键帧支路。
- 头像与声音分别可用不等于口型合格；没有播放检查时保持未验证。
