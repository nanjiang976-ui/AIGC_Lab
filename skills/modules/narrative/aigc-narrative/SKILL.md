# 剧情与 AI 漫剧

用人物的可见选择推动事件变化；风格、画幅和模型不替代戏剧目的。

## 适用边界

- 适用：虚构剧情、AI 漫剧、由人物行动承载的品牌故事或音乐叙事段。
- 不适用：只有氛围变化的循环画面；转 `aigc-visual-art`。真实事件考证以 `aigc-documentary` 为主。
- 混合任务按主要验收目的选主模块；广告故事可叠加 `aigc-commercial` 检查产品与主张。
- 本模块是常见用途之一，不把九类当作行业完整分类；保留用户选择的叙事结构与结局。

## 最小输入与公共协议

- 最少需要人物当前目标、阻力或关系、希望发生的变化、时长及本轮交付范围；完整 PRD 直接消费，只补决定因果的缺口。
- 尚未给出的过错、关系、伤害、台词与结局标为提案，不写成已确认剧情。一个问题只解决当前最关键分歧。
- 用户已明确完整 AIGC_Lab 工作区时，先核对该根的 `README.md`、`AGENTS.md`、`spec/harness-engineering.md` 与 `skills/catalog.json`，确认项目契约和本叶 skill 的归属；优先读取该根 `skills/aigc-creator/references/`，不让旧全局入口覆盖指定工作区。
- 脱离项目时，从当前包的实际安装根或 `aigc-creator` 元数据定位总控，比较叶节点与总控的 metadata.bundle / metadata.bundle_version 确认版本配套；缺文件、版本不符或无法确认同版本时报告，不猜路径或静默回退。
- 按以上规则定位总控后，以其目录为基准按需读取 `references/handoff.md` 与 `references/prompt-language.md`；缺依赖时报告，不猜安装路径。
- 空间与表演问题再读其 `references/continuity.md`；需要摄影措辞或真实案例时读 `references/lexicon.md`、`references/film-cases.md`，保留案例来源边界。
- 每镜头记录相机、角色/主体、画面三要素及前后状态；最重要主体、动作、硬约束前置，这是编排原则而非所有模型的位置权重保证。

## 节点取舍

| 条件 | 节点与交接 |
|---|---|
| 只有一句创意 | `aigc-prd` 确认核心变化，再由 `aigc-script` 写行动因果 |
| 人物或场景复现 | `aigc-visual-assets` 建固定身份；已有适用母版则引用版本 |
| 多人互动、跨轴、交接道具 | `aigc-blocking` 先锁世界位置、接触点和可见动作，再到 `aigc-storyboard` |
| 单人静态短对白 | 调度可压缩为分镜内的站位/视线记录，不另造完整空间表 |
| 需要图生视频或关键姿态控制 | `aigc-keyframes` → `aigc-video-prompts`；仅文生视频时可省独立关键帧生成 |
| 对白、环境声、成片 | `aigc-audio` → `aigc-editing` → `aigc-review`；只交文字时不生成或播放 |

## 专用创作判断

1. 将每场写成“想要什么 → 什么阻止 → 做出什么选择 → 状态如何改变”。相邻段能用“因此/但是”连接，避免仅有“然后”。
2. 为每个镜头指定主要功能：建立关系、增加阻力、暴露信息、完成选择或呈现后果；同功能重复时说明重复带来的变化。
3. 张力来自观众知道什么、人物能否实现目标及代价，不能只靠更快切镜。标明起点、转折和缓释位置。
4. 把心理词翻译为呼吸、视线、重心、手部、距离和动作迟疑；“委屈哭泣”先有可见触发，再有反应，不逐句堆微动作。
5. 多人互动分别写发起、接收、回应与接触状态。手已伸出但未接住，不跳写成牵手完成；真实生成状态优先于原计划。
6. 根据可读动作和停顿分配镜头数与时长，给本片理由；不默认每片三镜或固定五秒。动作过载时拆镜或删动作，由用户决定改剧情。
7. 对白不重复画面已表达的信息；沉默也有时长。估算读速后标明实际配音仍需复核。

## 已填文字示例

教学虚构设定：18 秒，无对白，两位成年朋友因借伞未还而冷战；用户已选择克制和解。A 穿米色外套，B 穿深蓝外套，伞 P01 完好。

选 3 镜是为了让“归还的尝试 → 对方犹豫 → 接纳”各有可读变化，时长 6+7+5 秒；这是本例的节奏决定。

| 镜头 | 相机 / 人物或主体 / 画面 | 前态 → 后态与因果 |
|---|---|---|
| EP01_SH001，6秒 | 固定双人中景；A 在左、B 在右，A 持伞；长椅保持后景 | 两人避开视线 → A 将收拢的伞递到中间，B 尚未接；归还启动修复 |
| EP01_SH002，7秒 | 同轴较近双人景；A 稳住伞，B 看向伞柄；两人的手同框 | 伞悬在中间 → B 从抱臂转为右手伸出但尚未接触；保留犹豫 |
| EP01_SH003，5秒 | 固定手部近景；B 先握稳、A 后松手；背景长椅虚化 | 两手未接触 → 伞柄归 B、A 手退出；道具交接兑现选择 |

第二镜可发送草案：

```text
两位成年朋友面对面站在长椅前，左侧米色外套的人保持将收拢雨伞递向中间，右侧深蓝外套的人从抱臂缓慢放下右手，视线从伞柄移向对方，再伸手靠近伞柄，结尾尚未触碰。固定较近双人景，始终看见伞柄和双方手部；不换边、不拥抱、不提前完成交接。阴天柔光，克制停顿，无对白。
```

## 专用验收与交付

- 交付因果链、每镜功能/时长理由、三要素/状态、可发送正文及下游交接；用户未确认的剧情决定单列。
- 文字审查检查触发与反应是否可见、张力是否有变化、接触/视线/轴线是否连续，不能仅按“有三幕”打勾。
- 生成后逐镜核对真实姿态，再连播核对表演节奏；无媒体时这些项目为 NOT_RUN，不把剧本通过当作成片好看。

## 训练题

- 正常：按上述 18 秒借伞设定交付 3 镜及第二镜正文；检查归还行为如何引发 B 的变化，时长理由和未接触状态是否清楚。
- 边界：上一镜实际结果是 B 已握住伞且两人位置对换，用户要求接下一段但保留和解结局。先对照实际结果修订交接/轴线与受影响镜头，不覆盖旧版本、不重演原定伸手过程；说明是否需要补桥接镜。
