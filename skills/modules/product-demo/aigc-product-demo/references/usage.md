# aigc-product-demo（产品演示）｜调用模板与使用方法

在 AIGC_Lab 内读取本项目同版本 Skill 源码和配套协议，不混用旧全局安装副本。

这是我发给 Codex 的调用模板，用来把真实操作证据编排成教程。`【填入】` 只给调用时替换；教程旁白与生成包装正文须完整展开。

## 什么时候用，最少说什么

- 我要教会一个真实软件任务或实物操作，重点是能按步骤复现时使用。
- 最少说：产品／版本／平台、起始状态、要完成的任务、实际录屏或步骤证据、时长和本次范围。
- 已有完整教程资料直接核对，不重新设计产品功能或访谈整部作品。
- 短口令：**“按真实录屏做教程，先给步骤证据表、旁白和剪辑方案。”**

## 可复制调用模板

```text
请使用本项目源码中的 $aigc-product-demo。
产品版本与平台：【准确名称、版本、桌面／手机／网页】。
要教会的任务：【从什么状态做到什么可见结果】。
必要条件：【账号权限、已打开页面、输入数据】。
操作证据：【实际可访问录屏／截图／可靠步骤；各自核验状态】。
时长与画幅：【总时长、画幅、观众基础】。
必须保留：【控件原名、关键等待、真实结果、不能剪掉的步骤】。
可做包装：【片头／指示框／放大；没有就写只用真实录屏】。
本次做到：【证据核对／教程脚本／录屏分镜／剪辑表】。
请标清观察事实和未验证因果，缺证据时先列素材依赖。
只准备文字，不操作账号、不重绘UI、不生成媒体。
```

## 已填例子

以下是虚构应用的教学观察记录，没有真实产品、录屏文件或已验证功能。

```text
请使用本项目源码中的 $aigc-product-demo。
练习为虚构“便笺盒”桌面版1.0写20秒新建便笺教程。
本题给定观察：0–2秒列表页有“新建”；2–5秒点击后编辑页打开。
5–10秒输入“周报提纲”；10–12秒点“保存”；12–14秒显示“已保存”。
14–18秒返回列表看到同名卡片。起始条件是已经进入可编辑的列表页。
请以这份间接记录做文字草案，不声称你看过录屏或实测过应用。
保留保存等待和结果确认，不补出云同步、分享或AI整理等功能。
只用未来待补的真实录屏，后期加指示框和两秒结果停留，不重绘界面。
本次交步骤证据表、录屏分镜、旁白及素材清单，明确真实复现仍待执行。
只准备文字，不操作产品，不生成媒体。
```

## 我会得到什么，接着怎么用

1. 起始条件、步骤与证据位置、观察／待验证状态，以及需补素材的清单。
2. 真实录屏的视窗安排、旁白、提示框与剪辑时间；包装段按需单列。
3. 提供真实录屏后核对步骤；只为明确需要的包装段编写生成提示词。

## 这个类型要先备好什么

- 截图只能证明可见状态；动作如何导致结果要有录屏、验证或可靠步骤依据。
- 没有真实 UI 时先做结构草案，不能凭产品名字编按钮、页面与完成提示。
- 重要等待和确认可以压缩，但要让观众知道有时间跳转，避免暗示瞬时完成。
- 真实录屏路线跳过参考图、首帧和视频生成；包装段才按模型入口选关键帧。
- 文字剪辑表不证明产品可复现；真实操作验证、导出与播放要分别记录。
