# AIGC_Lab · AI 影像创作实验室

将想法转化为剧情脚本、角色与场景设定、分镜，以及可直接发送的 AI 图片/视频提示词。覆盖单张图片、图片系列、短片和 AI 漫剧。

当前状态：项目基础设施已建立，尚无真实作品。模板中的占位内容和测试夹具不属于创作成果。验证进展见 [初始化验收记录](06_实验与复盘/2026-09-28_项目初始化验收.md)。

## 从这里开始

本仓库提供 [aigc-creator（AIGC 创作助手）](skills/aigc-creator/SKILL.md)，支持“给一个想法 → 逐轮提问 → 设定/分镜/提示词 → 自动分类积累”。视频使用连续性台账和分段衔接计划，并附带 [12 类、60 条初始提示词模块](02_提示词库/分类模块/00_使用索引.md)。模块均为未实测模板，不代表平台效果保证。

首次使用按 [安装与使用说明](05_工具与模型适配/AIGC创作Skill使用说明.md) 安装 Skill，在 Codex 中打开本仓库，然后输入：

```text
请使用 $aigc-creator。我想做【图片/视频/漫剧】，大体想法是【内容】。
请每次问我一个关键问题，逐步丰富内容，最后生成可复制的提示词。
本轮只准备文字材料，并将可复用模块查重后归入提示词库。
```

也可以直接描述创作需求，由 Codex 按 Skill 描述自动匹配。安装、续作、直接交付、停止入库和更新方式均见使用说明。

对 Codex 说：

> 在这个项目中创建一部作品。类型是【图片/视频/漫剧】，想表达【想法】，目标受众是【受众】，预期【张数或时长】。本轮只交付脚本、分镜和提示词，暂不调用生成工具。请使用项目模板，列明待确认事项，并在完成后运行项目校验。

也可以将 [作品模板](01_创作模板/作品模板) 复制到 `04_作品项目/WORK-001_作品简称/`，填写 `project.json` 与创作资料。已有 WORK-001 时使用下一个未占用编号。只有用户要求媒体生成时，才将 `scope` 改为 `media`。

最短路径：需求卡 → 设定与脚本 → 分镜 → 本次发送版 → 校验与复查。图片任务可以在不需要的剧本部分写明“不适用：单张静态图片，无叙事对白”。

## 常用检查

在本项目根目录使用 PowerShell，依赖 Python 3.10 或更新版本的标准库。当前初始化使用 Python 3.12。

```powershell
# 检查结构，以及每部作品声明的状态是否满足规则
python -X utf8 scripts/validate_project.py

# 第一部作品填写完成后：检查提示词准备情况
python -X utf8 scripts/validate_project.py --work "04_作品项目/WORK-001_作品简称" --phase prompts

# 核验相应交付范围的验收记录
python -X utf8 scripts/validate_project.py --work "04_作品项目/WORK-001_作品简称" --phase delivery

# 修改校验脚本后运行回归测试
python -X utf8 -m unittest discover -s scripts/tests -v
```

无真实作品时只能通过基础结构检查；提示词/交付检查不能用“空项目”冒充完成。具体工作目录名以实际创建的作品为准。

## 怎样判断完成

- `scope=prompts`：完成脚本、分镜、发送版提示词并有审查记录，即可交付文字材料；不意味着已经出图或生成视频。
- `scope=media`：还须记录实际生成工具、模型、当前版本结果和验收证据。
- 校验脚本核验文件、字段与关联；叙事效果、角色一致性、画面质量与可用性仍需看实际内容。详见 [验收标准](spec/acceptance.md)。

## 版本与维护

采用本地 Git 保存文本资料和小型参考图。大型视频/音频/工程文件默认忽略；生成记录仍需记下实际路径、工具和版本，媒体备份单独管理。复制仓库到另一台电脑后，必须补齐媒体再做交付检查，不得把记录当成媒体本身。

每次任务结束更新计划和复盘；只有出现跨作品可复用的经验才精简更新公共模板。当前未设置定时任务或自动发布。远程仓库为 [nanjiang976-ui/AIGC_Lab](https://github.com/nanjiang976-ui/AIGC_Lab)，默认分支为 `main`。

管理方法来源：[OpenAI Harness Engineering](https://openai.com/index/harness-engineering/)。本项目的状态、目录和创作验收规则是针对影像创作制定的本地约定。
